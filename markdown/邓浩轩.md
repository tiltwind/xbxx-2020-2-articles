# 没想到我如此坚持 邓浩轩

以前的我，只要遇到一点困难就想退缩。我总觉得自己做不到，也没必要硬撑。可那节体育课上的400米跑，却让我没想到自己如此坚持

那天阳光灼热，跑道被晒得发烫。老师一声令下：“今天测试400米！”我的心一下子沉到了底——这正是我最害怕的项目。看着同学们一个个站上起跑线，我只能硬着头皮跟上去，心里默念：“这次肯定又是倒数。”

哨声响起，大家像离弦的箭一样冲了出去。我咬紧牙关，努力跟着队伍。刚开始还能保持节奏，可刚跑完半圈，呼吸就开始紊乱，双腿像灌了铅一样沉重。眼看小赵已经领先大半圈，而我却被甩在最后。耳边只有风声呼啸，心跳和喘息声交织在一起，后背的衣服被汗水浸透，紧紧黏在皮肤上，喉咙干涩得像要冒烟。

我想停下，真的想放弃。可就在这时，妈妈的话突然在耳边响起：“孩子，别怕慢，就怕停。坚持到底，就是胜利！” 

那句话像一道光，照亮了我快要熄灭的意志。

我深吸一口气，挺直腰杆，用力摆动双臂，迈开脚步。一步，两步……我开始加速，超过了一个，又一个同学！场边传来惊呼声，有人惊讶地睁大了眼睛，连我自己都不敢相信——我竟然还在跑，而且越跑越有力！

进入最后一百米，我的视线有些模糊，汗水滑进眼角，火辣辣的。但我死死盯着终点线，心里只有一个念头：再坚持一下，再坚持一下就好！ 

五十米、十米、五米、一米！我拼尽全身力气，向前猛地一跃——冲过了终点！

那一刻，掌声响起。同学们围了过来，眼里满是敬佩。体育老师走过来，轻轻拍了拍我的肩膀：“不错，进步了十五秒。”他脸上露出欣慰的笑容。我也扬起了嘴角：那是胜利的笑，是拼搏换来的甜。

终点线不是奇迹的开始，而是坚持的证明。那一刻我终于明白：人最大的对手不是别人的速度，而是那个想要放弃的自己。没想到我如此坚持，现在每当我遇到难题，脑海中都会浮现出那滴落的汗水和冲线的一跃——它们提醒我，原来我真的可以坚持到最后一秒。

# 没想到我如此坚持  邓浩轩

以前的我，只要遇到一点困难就想退缩。体育课跑步时总找借口少跑一圈，比赛输了就觉得自己不行。可那一次站在操场上的四百米跑道上，没想到我如此坚持。

那天阳光火辣，晒得塑胶跑道都泛着热气。主席台上的老师拿着麦克风宣布：“今天测试四百米！”我的心“咯噔”一下，像被什么重重压住。周围同学纷纷起步，我也只好硬着头皮跟了上去。

刚开始还行，我稳稳地跟在队伍中间，呼吸也挺均匀。可第二圈一过，我的脚步越来越慢，开始大口喘气。到了第三圈，双腿像灌了铅一样沉，校服紧贴背上，湿得透透的。我每迈一步都像踩在棉花上，真想停下来。

就在这时，我看见队伍最后有几个人悄悄拐向厕所方向，显然是想偷偷少跑一圈。我心里一动：反正我也快撑不住了，不如也躲进去歇会儿？老师应该不会发现吧……想到这儿，我的脚步渐渐慢了下来，身子也不自觉偏向了路边。

可就在快要转身的一瞬间，脑子里突然响起妈妈常说的话：“孩子，坚持就是胜利。”我猛地顿住。余光一扫，看见身边的小朱——他比我还要矮小，脸涨得通红，头顶冒着热气，可他的脚步没有停下，牙关紧咬，一步一步往前冲。那一刻，我忽然觉得羞愧：他都没放弃，我又凭什么退缩？

我深吸一口气，重新摆动手臂，用力迈出脚步。第四圈开始了，汗水流进眼睛，火辣辣地疼，视线都有些模糊了。肚子也开始一阵阵抽痛，像有人在里面打结。但我死死盯着前方的终点线，心里默念：只剩一圈了，再坚持一下！

我咬紧牙关，拼命摆臂，脚步虽乱却不肯停下。耳边是自己的喘息声、脚步声，还有远处隐约传来的加油声。我顾不上别的，只知道必须冲过去！

当我的脚终于跨过终点线时，整个人几乎瘫倒在地上。可就在这疲惫不堪的时刻，心里却涌起一股暖流，像阳光照进了心底。

这是我第一次一口气跑完四百米。没有偷懒，没有停下，我靠自己冲过了终点。那一刻，我真正懂得了什么是坚持——不是不累，而是明明累到想哭，却还是选择了继续向前。

没想到，我如此坚持。

# 这一精彩时刻带给我的影响  邓浩轩

在成长的画卷里，有些瞬间如流星划过，短暂却耀眼。而那一次400米跑道上的奋力冲刺的精彩时刻，给我带来了深远的影响。

那是一节体育课，老师宣布：“今天跑400米。”我的心猛地一沉——400米，正是我最害怕的项目。看着同学们一个个站上起跑线，我也只好硬着头皮加入。哨声响起，大家像离弦的箭般冲了出去，我咬紧牙关紧跟其后。起初还能保持节奏，可刚跑完半圈，体力就开始不支，脚步越来越沉，仿佛双腿灌满了铅。眼看着小赵已经领先我大半圈，而我却被远远甩在最后，耳边只剩下自己急促的呼吸声。

就在我几乎想停下脚步时，一声呐喊划破空气：“小邓，坚持住！还有最后两百米！”是同学的声音。那一刻，“坚持”两个字像一道光，照进我快要熄灭的心里。我深吸一口气，重新挺直腰背，用力摆动双臂，一步、两步……越跑越快，风在耳边呼啸，我超越了一个、两个、三个同学！场边的同学惊讶地睁大眼睛，连我自己都不敢相信。

进入最后一百米，汗水顺着脸颊滑落，衣服紧贴后背，喉咙干涩得像要冒烟。但我没有停下。五十米、十米、五米、一米！我拼尽全身力气向前一跃，冲过了终点线！

那一刻，我的耳边想起了热烈的掌声，同学们纷纷围过来，眼里满是敬佩。体育老师走来，轻轻拍了拍我的肩：“不错，进步了15秒。”他脸上露出欣慰的笑容，而我也忍不住扬起了嘴角——那是胜利的笑，是拼搏换来的甜。

从那以后，这份坚持的力量一直铭刻在我心中。写作业遇到难题时，我不再轻易说“不会”；遇到困难时，我也总会提醒自己：“别放弃，还能追！”原来，精彩时刻是属于每一个咬牙坚持到底的人。

如今，每当我面对困难想要退缩时，耳边总会响起那天的呐喊，眼前浮现出老师欣慰的笑容。那一刻的拼搏与突破，早已不只是体育课上的成绩，而是我生命里最闪亮的一笔——它教会我：只要不放弃，终点终会抵达。

# 误会     邓浩轩
春风轻拂，校园里的丁香花开了，一簇簇淡紫色的小花藏在绿叶间，香气悄悄钻进每个人的鼻子。阳光洒在操场上，像撒了一地的碎金子。几个同学在花影里追逐打闹，笑声蹦蹦跳跳地飞向天空。
张明蹲在一丛丁香花前，眼睛亮亮的。他顺手摘下一枝丁香花，用花瓣挡住蚂蚁的路，把小蚂蚁赶到花枝上。蚂蚁左转右转，急得团团转，逗得张明咯咯直笑。突然，一只手轻轻拿走花枝，放回地上——是班长王寒冰！她皱着眉说：“老师让我看着你，你倒好，摘花还欺负小蚂蚁？快去办公室！”张明嘟囔着不情愿地走，忽然大喊：“哇，那边有蝴蝶！”班长一回头，他撒腿就跑，只留下她在后面气得直跺脚。
“我不就逗个蚂蚁嘛……”张明边走边嘀咕。话音未落，“啪”的一声，一个鸟窝从树上掉了下来，里面还有两只毛茸茸的小鸟，叽叽叫着。原来是一个别的班的同学用长杆掏了鸟窝，转身就跑了。
这时，王寒冰带着班主任李军赶来了。她一看地上的鸟窝，又看看张明，脸都红了，声音一下子高了起来：“张明！你怎么能掏鸟窝？太不像话了！”“不是我！”张明急得直拍裤腿，“真是别的同学干的！”“别狡辩了，除了你还能是谁？”班长瞪着他。张明眼圈红了，声音发抖：“真不是我……我发誓。”他的声音轻轻的，却让风也安静了一瞬。
李老师说：“走，咱们看监控去。”画面一清二楚：一个陌生身影举着木杆，把鸟窝捅了下来。班长低下了头，小声说：“张明，对不起……我错怪你了。”张明笑了：“没事，现在咱们把鸟窝送回去吧。”
他找来梯子，刚要往上爬，李老师拦住他：“危险，我来爬，你扶梯子。”老师三两下爬上树，轻轻把鸟窝放回原处。阳光穿过花枝，照在大家脸上。
张明仰头望着，鼻尖飘来熟悉的丁香香。这一次，香味甜甜的，像春天悄悄对他眨了眨眼。

# 为坚持与善良点赞 邓浩轩

生活中有许多事值得点赞，但最让我想点赞的，是那一次坚持跑完五圈，还有同学小张伸出援手的那一刻。

那天，主席台上的老师宣布，六年级今天要跑五圈。我紧张得手心直冒汗，还没来得及多想，同学们已经排好队出发了，我也只好跟了上去。开始，我的脚步轻快，还能和旁边的同学说笑。我开始集中精神，努力保持节奏；可到了第三圈，体力渐渐不支，双腿变得沉重，一个个同学从我身边超过。渐渐地我已经落到了队伍末尾，后背早已被汗水浸湿，呼吸也急促起来。

到了最后一圈，我几乎跟不上队伍的脚步，双腿像灌了铅一样沉重。我想停下，可脑海里突然浮现出妈妈的话：“只要坚持，就是胜利。”这句话像一束光，照亮了我快要放弃的心。我咬紧牙关，一步一步往前挪，渐渐加快速度，终于跟上了大部队。冲过终点那一刻，汗水顺着脸颊滑落，但脸上的笑容如烟花般绽放。那一刻，我为坚持到底的自己，点了一个大大的赞。

除了坚持，助人为乐也值得点赞。那天下午，我低头看了看手表：13:58！快要迟到了！我拔腿就跑，却没注意脚下，一下子绊倒在地上，膝盖磕破了皮，鲜血渗了出来。我用力撑起身子，可手臂发软，怎么也站不起来。周围的同学匆匆走过，没人停下脚步。就在我又疼又委屈、快要绝望的时候，一只手伸到了我面前——是小张。他皱着眉头，眼神里满是担心，用瘦小的身体使劲把我拉了起来，还轻声问：“你没事吧？”那一刻，他的身影仿佛比阳光还要明亮。我望着他，心里默默点了个赞。

那一次次坚持，那一双双温暖的手，都在我心中留下了光。我为勇敢的自己点赞，也为善良的小张点赞。我们每个人都可以成为别人生命里那个值得点赞的人。

# 甜（甜，不止是味道） 邓浩轩

生活就像一盒五味糖，酸过、苦过，但最让我难忘的，是那一次次咬牙努力、坚持后涌上心头的“甜”。它是从心底漫出来的喜悦与满足。

那天，我从地铁站出来，阳光洒在身上，额头上沁出细密的汗珠——不是因为天气炎热，而是因为紧张。我要参加一场奥数考试，听别人说这里的考试特别难，只有及格才能进入下一阶段的学习。我的心怦怦直跳，像揣了只小兔子。

走进教室，老师发下试卷。我低头一看，密密麻麻的题目像蚂蚁排成了行。心里顿时打起退堂鼓：“这么多难题，我真的能行吗？算了吧，还是不考了。”可就在这时，我看见周围的同学都在认真答题，没有一个人放弃。我又想起了妈妈期待的眼神，想起了自己曾经许下的诺言。“不行！不能退缩！”我心里默默告诉自己，“再难也要试一试！”于是，我深吸一口气，拿起笔，一道题一道题地啃下去。

时间一到，老师收走试卷，对着电脑一道道批改。一个个红叉如雨点般落下，我的心也一点点沉下去。可最后，老师点点头：“接近70分了，你通过了！”那一刻，我心里像灌了蜜一样甜，那是是我不曾放弃换来的甜！

还有一次，我也尝到了甜。

那是体育课，我们要跑400米。跑步一直是我的弱项，一听口令，我就慌了神。哨声一响，同学们像离弦的箭冲了出去，我拼尽全力跟上，一开始还超过了几个同学。可跑到一半，双腿像灌了铅，呼吸也变得急促，一个又一个身影从我身边掠过。

就在我快撑不住时，耳边传来同学的喊声：“加油！只剩50米了！”“你能行！”我深吸一口气，拼尽全力冲刺——100米、50米、10米、五步、一步！冲过终点的那一刻，脸上露出胜利的微笑，心里像灌了蜜一样甜。

原来，甜从来不是天上掉下的糖果，而是我一步一个脚印跑出来的回甘。每一次想放弃时没有放手，每一次累到极点仍选择前行，才让这“甜”如此真实、如此动人。

# 激动人心的接力赛 邓浩轩

阳光洒在红色的跑道上，像铺了一层金粉。操场上彩旗飘扬，呐喊声一浪高过一浪——我们学校举行了激动人心的接力赛。我的心砰砰直跳，眼睛紧紧盯着第一棒的小林，只等那一声清脆的哨响。

“预备——啪！”小林像离弦的箭一样冲了出去！他起跑迅猛，一下子抢到了领先位置。台下的我们挥舞着双手，大声喊着：“加油！加油！”声音如潮水般涌向赛道。虽然其他班的同学紧追不舍，但小林咬紧牙关，第一个把接力棒交到了下一棒同学手中。

转眼间，第五棒的小白接过了棒子。他像脱缰的野马般飞奔而出，双臂快速摆动，脚步如风。同学们齐声高喊：“小白！世界第一！加油！”他听见欢呼，跑得更猛了。三米、两米、一米……太好了！他成功反超！我们全班都跳了起来，欢呼声响彻操场。

可就在这时，意外发生了——接力棒掉了！时间仿佛静止，我的心一下子揪紧了。可小白没有慌张，迅速捡起棒子，稳稳传给了下一位同学。

最后一棒是小赵。他接过棒，像流星划过天空，飞快冲向终点。眼看前面的同学突然掉棒却浑然不知，小赵抓住机会冲到最前！可就在最后几步，他竟因着急摔倒了！我屏住呼吸，只见他立刻爬起，拼尽全力冲过终点线！

那一刻，我们全班抱成一团，又跳又叫，眼里闪着泪光。那根小小的接力棒，不只是速度的传递，更是信任、坚持与团结的象征。我终于明白：一个人能跑得很快，但一群人，才能跑完漫长的征程。

# 我的拿手好戏（抓鱼小能手） 邓浩轩

夏日的阳光洒在老家的小河上，波光粼粼，像撒了一地碎银。岸边的孩子们嬉笑着跑过，而我却悄悄卷起裤腿，目光如鹰般扫视水面——因为我知道，这片水域藏着我的拿手好戏：抓鱼。

小时候，我最爱吃奶奶煮的鱼汤，那鲜美的味道总让我回味无穷。一次，爷爷提着桶要去抓鱼，我立刻跟了上去。来到水塘边，已经有几位长辈和一个和我年纪相仿的男孩在那儿了。我心想：正好比一比！我们约定谁抓得多谁就赢。

第一次下水，我信心满满，可那鱼实在太机灵了。它尾巴一甩，水花四溅，就从我指缝间溜走了。有一次我好不容易抓住一条，它身子滑溜溜的，拼命扭动，我手一松，它又逃了。再看我的对手，已经稳稳捉住一条活蹦乱跳的鱼。这下我气坏了，心里暗暗发誓：一定要赢！

就在这时，我发现一条大黑鱼被困在一个浅水坑里，正焦急地甩尾挣扎。机会来了！我慢慢蹲下，屏住呼吸，双手迅速探入水中，一把抓住它的上半身。它用力翻腾，可我不肯松手，终于将它放进桶里。那条鱼比我对手的还大一圈！他不服气地说：“这不算，换我也能抓到！”我笑着说：“那咱们再来一场！”

第二次比赛开始了。我静下心来，仔细观察水面动静。很快，我锁定了一条在水中游得飞快的大鱼。我这次不再莽撞，而是悄悄绕到它身后，轻轻逼近，等它游向浅滩时猛然包抄。那鱼见前方无路，想转头从我胯下钻过去，我眼疾手快，双手如网，准确一兜——抓住了！

那一刻，连对手都忍不住竖起大拇指。爷爷也笑着点头：“这孩子，真有两下子！”回家后，奶奶用黑鱼炖了一锅奶白的鱼汤，香气扑鼻。喝着热腾腾的汤，我心里满是自豪。

# 有你，真好 邓浩轩

“哇，真漂亮！”我忍不住欢呼。那一刻，您的笑容映在灯光里，温暖又明亮。那光不仅照亮了房间，也驱散了我心头的阴霾。我的笑容重新绽开，像花儿迎着阳光绽放。

# 及时雨 邓浩轩

在我的生活中，有许多人来来往往，但最让我难忘的，是我的同学小叶——他就像一场温暖的“及时雨”，落在我最着急的那一刻。

我们拼尽全力往回跑，风在耳边呼啸。当顺利穿过校门，没被督导队员发现时，我忍不住转头看向小叶。没想到他也正看着我，眼里闪着光，笑得那么灿烂。

如今，我也学会了在别人需要时伸出援手。因为我知道，每一份微小的善意，都可能成为别人心中的一场及时雨。

# 美（美，藏在细节里） 邓浩轩

我们总习惯用眼睛寻找美——看一朵花开，望一片云霞。可真正打动人心的美，往往藏在无人注意的角落，藏在一个陌生人的动作里，藏在一句轻声的“你等等”中。

刚走到小区门口，忽然听见身后有人喊：“哥哥，你等等！”我回头一看，是肠粉店的小弟弟，手里攥着五块钱，气喘吁吁地说：“一份肠粉是五块，你给了十块半，妈妈让我把钱还你。”我接过钱，指尖还带着他手心的温度，心里像被阳光照过一样暖。

原来，诚信也是一种美。那五块钱虽少，却像一颗闪亮的小星星，照亮了清晨的街角。老板一家在忙碌中不忘诚实，这份朴素的坚持，比任何香味都更动人。

真正的美不是被阳光镀上金边的晚霞，而是那个比我矮一头的小男孩默默扶起我的背影；不是香气扑鼻的肠粉，而是那五块钱背后一家人的诚实与温暖。美，从来不在远处，它就藏在人间最朴素的善意里。我也要成为别人心中“美”的人。
