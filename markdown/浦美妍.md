# 当课本有了心跳 浦美妍

黑暗中，我沉睡在油墨与纸香编织的梦里。忽然，一阵喧闹声将我从睡梦中惊醒，四周被黑暗笼罩，密不透风，像被关进了一个布做的小牢房。紧接着，外面“啪”地一响，光洒了进来——我睁开了“眼”，发现自己竟是一本崭新的语文书，正躺在一个男孩摊开的手掌中。

他把我翻来翻去，手心黑乎乎的，灰尘像小雨点一样落在我的身上，留下一个个灰扑扑的手印。我想挣脱，可身子一动也不能动，只能被他塞进鼓鼓囊囊的书包里。

再醒来时，他正慌慌张张地抽出我，耳边传来老师的声音：“快把书拿出来！”老师翻开我，发现一页字都没有，皱着眉把我扔回桌上。他赶紧从夹层里掏出一支黑笔，在我的第一页写上名字。那歪歪扭扭的两个字，像爬行的小虫，破坏了我洁白的封面，仿佛艺术品上的一道裂痕。

起初他还用我在课文上认真做笔记，可没过多久，心思就飘走了。他拿起彩笔，在我身上画起火柴人。原本干净的书页上，渐渐爬满了涂鸦、线条和零食碎屑。我的书角卷了边，书页也掉了几张，像折断翅膀的小鸟，再也飞不起来。

终于有一天，老师发现了我伤痕累累的模样，严厉地批评了他，再也不许他在书上乱画。我终于安静了，不再被撕扯、被涂抹。可我已经支离破碎，连合上都变得困难。我静静地躺在讲台上，望着天花板，心里轻轻叹了一口气：当一本书，真的太不容易了。

书本是知识的小船，载着我们航行在学习的海洋里。它不该被丢弃成地上的碎纸片，而应被温柔以待，用心珍藏。
