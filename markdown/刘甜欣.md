# 没想到我如此坚强 刘甜欣

我以为自己会半途放弃，却没想到，那个在跑道上鲜血直流却仍站起来的人，竟然是我，没想到我如此坚强。

那是我人生第一次参加校运会400米长跑。阳光洒满操场，红色的塑胶跑道被晒得微微发烫，像一条燃烧的路。看台上人声鼎沸，我的心也随着裁判举起的发令旗一点点提到了嗓子眼。枪声“砰”地响起，我像离弦的箭一样冲了出去，脚步轻快，风在耳边呼啸。一圈、两圈……我竟然跑在了队伍前列！喜悦在我心里悄悄开花，仿佛胜利已经在向我招手。

可就在我准备加速冲刺时，左脚忽然一滑，右脚绊住了左脚——“啪！”我重重摔倒在地！手掌擦破了皮，火辣辣地疼；膝盖磕在地上，鲜血慢慢渗了出来。我趴在那里，喘着粗气，喉咙像被刀割一样疼。眼看一个个选手从我身边跑过，我心里涌起一阵绝望：算了吧，真的撑不下去了……

我坐在地上，眼泪在眼眶里打转。我想起了妈妈每天陪我晨跑的身影，想起了体育老师对我说：“跑不完不要紧，但一定要走完全程。”就在这时，观众席突然爆发出一阵呐喊：“加油！站起来！”“你能行！”一个熟悉的声音特别清晰：“别停，我们都在看你！”那一瞬间，我的心猛地一颤，好像有一股力量从泥土里钻出来，直冲头顶。我咬紧牙关，双手撑地，一点一点，站了起来。

腿在抖，呼吸像破风箱，但我迈出了第一步。一步，再一步，像是从泥潭里拔出双腿，但每一步都踏在尊严之上。我拖着虚脱的身体奋力向前挪动，心里只有一个念头：不能停，必须走到终点！100米，80米，50米……奇迹发生了——在最后几十米，我竟然反超了两名选手！当我压低身子冲过终点线时，全场响起了掌声和欢呼声。

那一刻，成了我心中不灭的火种。自那以后，我的骨子里多了一份不服输的韧劲。每当我遇到困难想放弃时，眼前总会浮现自己蹒跚前行的身影。原来我的体内，藏着一个不肯认输的灵魂。

直到今天我才明白，真正的精彩，不是从不跌倒，而是跌倒后依然选择前行。那一次，没想到我如此坚强。

# 没想到我如此胆小  刘甜欣

在我的成长道路上，总有一些事情让我印象深刻。以前，我还经常笑话同学不敢看恐怖片，觉得他们太胆小。可经过那一次经历，没想到我如此胆小。

那天爸妈出差，姐姐也出去了，家里只剩我一个人。闲着无聊，我翻到一部大家都在议论的恐怖片。心想：这有什么可怕的？我肯定能扛住！于是我把大灯关掉，只留一盏小灯，点开手机就开始看了。

画面刚亮起，阴森的背景音乐就缓缓响起，像是从地底爬出来的低语。我的心一下子揪紧了，手心开始冒汗，连握着手机的指节都微微发白。屏幕上出现了一个又一个可怕的场景：破旧的玩具屋、满地的血迹、……我的心跳咚！咚！咚！一声比一声急，仿佛要冲出胸口。突然，“呯——！”的一声巨响炸开，我整个人猛地一抖，像被电流击中，抓起旁边的枕头死死捂住眼睛。

等我颤抖着把枕头拿开，脑海里却浮现出刚才的画面，怎么甩也甩不掉。我咬着牙，心想：不能再看了，快去开灯！我鼓起勇气，脚慢慢往下一伸——哎呀！脚下碰到一个东西，冰凉冰凉的。我“啊”地缩回脚，脑袋“嗡”地一下炸开了：不会吧？该不会有鬼吧，我呼吸都快停了，整个人缩进沙发角落，抓起被子一头钻进去，嘴里不停地念：“救命啊……救命啊……”

更可怕的是，电视里那个从小丑盒子蹦出来的小丑又出现了！他咧着血红的嘴，眼睛空洞地盯着屏幕外，好像在看我！每次他靠近受害者，我都忍不住往后退，直到背贴上了墙。就在这时，门“吱呀——”一声被推开了！

“啊——！”我尖叫出声，全身的汗毛都竖了起来，脑子里只有一个念头：小丑真的来了！他从电视里爬出来了！

刹那间，灯亮了。原来是姐姐回来了！她笑得前仰后合：“你捂被子干嘛？演木乃伊吗？”那一刻，我又羞又恼，脸烧得通红。原来什么鬼、小丑吃人，全是我自己吓自己。那短短几十分钟，几乎耗尽了我所有的镇定。

没想到我如此胆小，真正的勇敢不是不害怕，而是知道害怕，却依然愿意面对。

# 诚信让生活更美好 刘甜欣

“言必行，行必果。”诚信是中华民族的传统美德，当我终于鼓起勇气说出那句“对不起”时，我才明白——真正的安心，来自诚实。原来，诚信真的能让生活更美好。

记得那天，妈妈要出门，临走前叮嘱我：“你在家看好弟弟妹妹啊！”姐姐和爸爸也出去了，家里就剩下我和表弟表妹。妈妈刚走，妹妹就嚷着要看动画片。我赶紧打开电视哄她，然后溜进厨房找零食吃。

我正拿着苹果在水龙头下冲洗，突然听见客厅传来一阵大笑。我吓了一跳，手一抖，胳膊不小心碰到了旁边的柜子。“啪——”一声清脆的响，我回头一看，心一下子沉到了底——妈妈最心爱的那个蓝边碗，碎了一地！

我呆住了，脸都白了。那是妈妈最喜欢的碗，爸爸送她的礼物。我蹲下来，手发抖地把碎片一片片捡起来，塞进一个塑料袋里，悄悄藏在床底下。我坐在床边，小声嘀咕：“要是妈妈问起来，我就说不知道吧……”

没过多久，妈妈回来了。她走进厨房，翻了翻柜子，忽然问：“你们看见我的碗了吗？”我低着头，装作没事地说：“没看见，是不是放错地方了？”妈妈叹了口气，皱着眉头继续找。看着她失望的样子，我心里像压了块石头，越来越沉。

后来舅舅来接表弟表妹了。他们走后，我鼓起勇气，从床下拿出那个袋子，走到妈妈面前，声音发颤地说：“妈妈，对不起……是我不小心打碎了你的碗。”

我闭上眼，等着责骂。可妈妈轻轻抱住我说：“没关系，碗碎了还能买新的，但诚信丢了就难找回来了。你能主动承认，妈妈很欣慰。”

# 破碎的眼镜 刘甜欣
校园里，丁香花开得正旺，一簇挨着一簇，淡紫色的小花在春风中轻轻晃动。阳光透过玻璃窗洒进教室，落在讲台桌上那副闪着光的黑框眼镜上，像撒了一层金粉。
“叮铃铃——”下课铃一响，教室顿时热闹起来。这节课是大家最喜欢的，正是由充满活力的年轻班主任李军老师执教。他高高的鼻梁上架着一副黑色眼镜，平时总笑眯眯的，可一旦摘下眼镜，就说明他要上厕所去了。这不，他刚把眼镜轻轻放在桌上，转身走了出去。
这时，淘气包张明可坐不住了。他抓起篮球，和几个朋友在教室后排你扔我传，笑声不断。突然，一个球猛地飞来，张明一接一扔，“哗啦！”一声脆响，全班瞬间安静——讲台桌上的眼镜，碎了！
张明瞪得眼睛溜圆，冲过去一看，心一下子掉到了地上。“啊！”他吓得一屁股坐在地上，脸涨得通红。“完了完了！李老师最爱这副眼镜了！他会骂死我的！”他抓起篮球，拔腿就跑，躲进了厕所。
外面，风突然大了起来，树枝哗哗作响，落叶满地翻滚，好像连天空都在生气。李老师回来一看，火冒三丈：“谁干的？站出来！”同学们都不敢出声，这是李老师第一次发这么大的火。
班长王寒冰猛地站起来：“我去叫张明。”她脚步坚定地走出教室。躲在厕所里的张明正哆嗦着：“现在回去肯定挨骂……可不回去，会不会更惨？”正想着，一只冰冷的手搭上他的肩，他吓了一跳——是王寒冰！“跟我回去！”“我回去不是自投罗网吗？”“越晚越糟！”王寒冰不由分说，把他拉回教室。
张明低着头，声音发抖：“李……李老师，是……是我打碎的……对不起……”话没说完，眼泪就掉了下来。
没想到，李老师笑了：“没事！你能主动承认，老师很高兴！”他轻轻摸了摸张明的头。阳光重新洒进来，风停了，丁香的香味又飘满了校园。

# 点赞的力量 刘甜欣

在成长的旅途中，总有一些微小的瞬间，像星光般悄然照亮我们的心。不是惊天动地的壮举，也不是万众瞩目的荣誉，而是在某个平凡的角落，一个选择、一次行动，让“赞”字轻轻落在我心头。

记得那一次跑操，只剩最后一圈了，我的脚步变得轻快，心里欢呼着：“终于要解放了！”阳光洒在跑道上，映出我们奔跑的身影。突然，前面一位同学脚下一滑，重重地摔在地上。我猛地一惊，本能地往旁边一闪，目光却立刻被她吸引过去——她的膝盖擦破了皮，渗出血丝，裤子也裂开一道口子，脸上写满了疼痛与羞怯。

我的心一下子揪紧了，脑海里飞快闪过两个念头：扶，还是不扶？如果扶了，老师会不会误会是我撞倒她的？可如果不扶，她一个人疼得站不起来，又该怎么办？风轻轻吹过脸颊，仿佛也在催促我做决定。最终，我深吸一口气，迈步上前，轻轻拍了拍她的肩膀：“别怕，我扶你去医务室。”

她抬起头，眼里闪着感激的光，点了点头。我一手撑住她的肩膀，另一手稳稳扶住她的胳膊，小心翼翼地陪她一步步走上楼梯。当我终于将她安全送到医务室，放下她时，她轻声说：“谢谢你。”我摇摇头：“这是我应该做的。”转身离开时，我心里默默为自己点了个赞。

我还要为大哥哥的言行点赞。那天上学路上，一个小同学随手把饮料瓶扔在路边。我皱了皱眉，正想着要不要去捡，忽然看见一位高年级的大哥哥快步走过去，弯腰拾起瓶子，三步并作两步追上那个小同学，温和却坚定地说：“小朋友，垃圾要扔进垃圾桶哦。”声音不大，却像春风拂过树梢。小同学愣了一下，脸“唰”地红了，接过瓶子，低着头，几步走到旁边的垃圾桶，认真地扔了进去。

大哥哥笑了，轻轻拍了拍他的后背，便转身走进校园。那一幕像一幅画，定格在我心里。我站在原地，望着他们的背影，心中不由自主地为他点赞。

这两件小事平凡却温暖，让我深深为之点赞。。从那以后，每当我看到别人需要帮助，或地上有垃圾，我都会主动上前。因为我相信，小小的善举，也值得被点赞。

# 悔（懊悔的重量） 刘甜欣

“悔”不像眼泪那样汹涌，也不像疼痛那样尖锐，但它会在某个瞬间突然浮现，提醒你曾经错过的那一秒、那一句话、那一次选择。

那天清晨，我睡过头，出门时已经很迟了。我一路狂奔冲向学校，脚步声在空荡的走廊里回响。正当我冲到二楼楼梯口时，一个小小的身影蜷缩在拐角处，挡住了我的去路。是个低年级的小女孩，满脸泪水，左手紧紧捂着右脚，脚踝肿得像个小馒头。我下意识地伸出手，想扶她去医务室。可就在这时，我瞥见手表上的指针——糟了！还有两分钟就要上课了！要是扶她，肯定迟到；可如果不扶……我的心跳猛地加快，时间一分一秒地溜走，仿佛催命般飞转。“你等一下，我一定会来！”我丢下这句话，转身拼命冲向教室。

整节课，我的眼睛总忍不住望向窗外的楼梯口。阳光斜照在那里，空荡荡的，只有风轻轻吹动一片落叶。下课铃一响，我立刻冲出去，可那里早已没人。我心中无比自责：那位小妹妹伤得严重吗？我当时为什么没有为她多停留一会？我应该扶她去有医务室呀。那一刻，我真后悔，心里像压了一块石头——那句“我一定会来”，像一张空头支票，风一吹就散了。

还有一次，我和同桌吵完架，心情很差。她把涂改带借给我时，我没好气地一把拿过，重重扔在桌上。就在那一瞬间，我越想越气，猛地按了一下涂改带，“咔”的一声——坏了！我的心一下子沉到底。“怎么办？告诉她吗？她会不会更生气？我会不会彻底失去这个朋友？”我犹豫了很久，最后还是把坏掉的涂改带还给她，小声说：“你的涂改带……不知道怎么坏了。”她笑了笑说：“没事，我再买一个。”可她越是宽容，我心里就越难受，越后悔。那笑容像一面镜子，照出了我的胆小和逃避。

这两次经历，让我真正尝到了“悔”的滋味。它不是一时的情绪，而是藏在心里的刺，时不时提醒你：曾经，你可以做得更好。现在，每当我看到有人需要帮助，或是面对诚实的选择时，我都会做出更好的选择。

# 无声的情意 刘甜欣

姐姐的爱从不挂在嘴上，而是藏在行动里。那份无声的情意，我一直记得。

我姐姐平时话很少，总是一副冷冷的样子，连妈妈都说她“不懂关心人”。小时候我甚至觉得，她大概真的没有感情吧。可那一次的事，却让我彻底改变了想法。

那天，我和姐姐正坐在客厅看电视，看得入迷，谁也没注意茶几上的那套茶具。忽然，“哐当”一声，我一脚不小心踢到了桌腿，由于用力太猛，桌上的茶杯晃了两下，接着摔在地上——碎了一地。我和姐姐猛地跳起来，呆呆地看着满地的碎片，心一下子提到了嗓子眼。“完了完了！”我脑子里一片空白，“这可是爸爸最宝贝的东西，他花大价钱买回来的！”我越想越怕，手心直冒汗。更糟的是，门外突然传来“吱呀”一声——爸爸提前回家了！

爸爸一进门就看见地上的碎片，脸色立刻沉了下来，吼道：“谁干的？这么贵的东西，你们竟敢打碎？说！到底是谁？”我吓得说不出话，腿都在抖，刚想迈出一步承认，姐姐却突然开口：“我摔的。”我愣住了，简直不敢相信自己的耳朵。那是我第一次听见她替我说话。爸爸立刻转过头狠狠批评她，而她只是低着头，一句话也不辩解。我躲在门后看着她沉默的背影，鼻子一酸，眼泪忍不住一颗颗掉了下来。后来，我悄悄问她为什么替我承担，她只轻轻说：“你害怕的样子，像极了小时候的我。”那一刻，我终于明白，姐姐的爱从不挂在嘴上，而是藏在行动里。

多年过去，那套碎裂的茶具早已被清理干净，可姐姐那句轻得像风、却重如山的“我摔的”，一直在我心里回响。她用沉默为我挡下责骂，也用行动教会我什么是守护。这份无声的情意，我会永远记得，并在未来的某一天，悄悄传递给需要的人。

# 乐（乐在其中） 刘甜欣

“乐”不只是嘴角上扬的笑容，更是摔倒时伸出的手、风中扶起的一辆辆单车。它像一颗种子，在一次次微小的行动里悄悄发芽，长成了我心中最温暖的模样。

记得一次大课间跑操，阳光洒在跑道上，我们排着队奔跑。只剩最后一圈了，我脚步轻快，仿佛胜利就在前方。忽然，前面的同学一个踉跄，重重地摔在地上。我赶紧刹住脚步——她的膝盖擦破了皮，渗出细小的血丝。

我的心猛地揪紧：扶吗？扶了会迟到，老师会不会误会？可如果不扶……风从耳边吹过，仿佛也在催促我做决定。“扶！”我咬了咬牙，走上前去，“我扶你去医务室。”她点点头，眼里闪着感激。我小心搀着她，一步一步爬上楼梯，汗水顺着额头滑落，衣服也湿透了。到了医务室，她轻声说：“谢谢你，要不是你，我真不知道怎么办。”我摆摆手：“没事，举手之劳。”转身离开时，脚下仿佛踩着一朵幸福的云，心里像喝了蜂蜜水一样甜。那一刻，我明白了——乐，是伸手的勇气，是分担的温度。

还有一次清晨，我出门散步。看到一辆辆共享单车倒在停放点旁，不仅挡住了行人通道，还堵住了盲道。第一反应是绕道走。可刚迈出一步，回头看见那一片歪斜的单车，想到行人的不便，特别是盲人经过，多危险啊！我还是把它们扶起来吧。我跑过去，一辆一辆地扶正、摆好在停放点。等全部整理完，我已经气喘吁吁，胳膊酸得抬不起来。回家的路上，太阳升得更高了，路边的小花随风轻轻摇曳，仿佛也在对我点头微笑。我知道，我不是为了谁表扬才这么做，但这份累里的甜，比糖果更真实。那一刻，我又尝到了“乐”的滋味——原来，乐不仅是帮一个人，也可以是为一座城出一份力。

# 为坚持而奔跑 刘甜欣

奔跑，让人收获自由，让人心情舒畅。而我，在奔跑中磨砺意志，在汗水中悄然成长。那一次，我为坚持而奔跑。

那是一次1000米体测，发令枪声一响，同学们如脱缰的野马般冲了出去。我紧随其后，调整呼吸，渐渐地竟跑到了队伍前列，心中涌起一阵藏不住的喜悦。然而，就在距离终点只剩一百多米，我准备全力冲刺时，意外发生了。我的左脚不慎绊住了右脚，身体猛地一个踉跄，差点重重摔在地上。虽然我赶紧稳住身形继续奔跑，但刚才的失误几乎耗尽了我所有的体力。顿时，双脚像灌了铅一般沉重，每一步都艰难无比；粗重的呼吸声在耳边轰鸣，喉咙里弥漫着尘土的味道。眼看一位位同学从我身边掠过，我的步伐越来越慢，绝望感如潮水般袭来。

“都最后一名了，还跑什么？”放弃的念头在心中疯狂滋长，我的脚步愈发迟缓。就在我即将停下时，一阵熟悉的呐喊穿透燥热的空气钻进我的耳朵：“加油！别停下！继续跑！”抬头望去，好友们正站在终点线前焦急地向我招手。那一刻，脑海里忽然浮现出往日清晨练习的画面：想起那天早晨腿酸得连楼梯都下不了，但我依然咬牙系紧鞋带，迎着寒风出发。如果连这次测试都无法坚持，那昔日的汗水岂不是白费？想到这里，放弃的念头顿时烟消云散。

我深吸一口气，眼神重新变得坚定，使出全身力气迈出了第一步，紧接着是第二步、第三步……我再次奔跑起来，用力摆动着双臂，耳畔是同学们此起彼伏的鼓励声。离终点线越来越近了！在最后十几米时，天地间仿佛只剩下了我与那条白色的终点线。跨过线的那一刻，听着老师按下秒表的声响，积压的压力瞬间释放，取而代之的是难以言喻的激动与自豪。

那一次奔跑，不仅让我突破了身体的极限，更让我收获了成长的礼物。它让我明白：人生漫漫，无论遭遇怎样的荆棘与坎坷，只要心怀坚持，便能抵达梦想的彼岸。从那以后，不论面对何种困难，我都会带着那份奔跑的力量，坚定地走下去。

# 雨幕中的那抹暖光 刘甜欣

在我的成长路上，有一束光始终照亮着我前行的方向。那束光，就藏在一把普通的雨伞里。每当看见它，我的记忆便悄然回到那个雨天。

那天放学，原本晴朗的天空像打翻的墨汁，转眼间便下起了倾盆大雨。我没带伞，家长也抽不开身来接。我只好呆呆地站在学校雨棚下，看着同学们一个个撑伞离开，心里又急又闷。

就在这时，一只温暖的手轻轻搭在我肩上。我猛地回头，是常在校门口值勤的志愿阿姨。她穿着红色马甲，笑得眼睛弯弯，像两枚温润的月牙。“没人接呀？”她声音不高，却稳稳地落进我耳朵里，像一块暖石头沉进水底。她没等我回答，已把伞撑开——那是一把宽大的蓝伞，伞面印着几朵小小的白云，像晴天偷偷藏进雨里的梦。

我们并肩走进雨幕。雨点密密敲打伞面，可我的头顶却干爽如初。我悄悄抬眼：伞柄正悄悄往我这边倾斜，她右肩的马甲早已深了一大片，水珠顺着袖口往下淌，可她脚步轻快，仿佛淋湿的不是自己。我小声说：“阿姨，您肩膀都湿了……”她侧过脸，睫毛上沾着细小的水珠，目光却亮得像含着阳光：“小孩子骨头嫩，淋不得，咱们大人皮实！”她说话时嘴角上扬，声音软软的，像刚蒸好的糯米团子，又暖又甜。

突然，一辆车呼啸而过，车轮碾过积水，“哗啦”一声溅起半人高的水花！我下意识闭眼缩肩，可预想的冰凉没来——阿姨已迅速转身，用整个后背挡住我。水花劈头盖脸扑在她裤腿上，深色水痕迅速蔓延。我怔怔望着她湿透的后颈，还有那双转过来时依然含笑的眼睛，心里像被什么轻轻撞了一下，又热又胀，眼眶一下子潮热起来。

到了路口，我们该分开了。她望望连绵的雨，又看看我，把伞塞进我手里：“我家就在对面，你还要走一段，没伞会淋透的。这把伞送给你！”话音未落，她已转身跑进雨幕中。

那一次，雨伞里的光照亮了我不断前行的路，也让我明白：原来最暖的光，不是来自太阳，而是来自一颗愿意为他人遮风挡雨的心。从今往后，当看到别人遇到困难时，我也要像阿姨那样，及时伸出援手，将这份温暖传递下去，让爱的光芒在更多人心中点亮。

# 感恩有你 刘甜欣

在我的成长道路上，发生过许许多多事情，它们犹如夜空中闪烁的繁星，其中有一件事，发出最亮的光，让我至今难忘。小妍，感恩有你！

那是一个阴沉的下午，妈妈将伞送到保安室。我去取伞回来时正赶着上课，便匆匆跑上楼梯。谁知左脚忽然一拐，绊住了右脚，整个人重重摔在台阶上，又往下滚了两阶，最后坐在楼梯中间，脚腕钻心地疼，连站起来的力气都没有了。

就在我惊慌失措时，一个熟悉的身影出现在视线尽头。是你，小妍！还没等我开口呼救，你便三步并作两步冲到我面前。看着狼狈的我，你眉头紧锁，眼神中满是焦急与关切：“你怎么了？怎么这么不小心！疼不疼？”你那略带责备却充满温情的话语，瞬间化作一股暖流，涌遍我的全身，驱散了所有的恐慌，让我一时竟哽咽得说不出话来。

你二话不说，紧紧拉住我的手，用力将我扶起：“别怕，我送你去医务室。”在你的搀扶下，我们一步步艰难地挪动。短短几百米的路程，此刻仿佛变得漫长无比。你一只手牢牢架着我，另一只手时刻护着我受伤的腿，每走一步都小心翼翼，生怕弄疼了我。渐渐地，细密的汗珠爬满了你的额头，顺着脸颊滑落，你的呼吸也变得急促起来，但你从未有过一丝不耐烦，眼神始终专注而坚定。那一刻，我觉得自己就像是一件易碎的瓷器，被你温柔而坚定地守护着。

终于到了医务室，你累得气喘吁吁，却顾不上休息，一直守在门外焦急地张望。当我包扎好走出来时，你又立刻迎上来扶住我，生怕我再有闪失。我感激地看着你，轻声说道：“这次真是多亏了你！”你却绽放出灿烂的笑容，摆摆手说：“都是好朋友，这是应该的。”回教室的路上，雨后的空气格外清新，小鸟在枝头欢快地歌唱，花草随风摇曳，仿佛也在为我们的友谊喝彩。

那一次，一件小小的搀扶，却在我心里种下了温暖的种子。小妍，感恩有你！你让我懂得：当他人需要帮助时，要毫不犹豫地给予温暖。这份同窗情谊，将成为我毕业行囊中最珍贵的礼物，伴随我走向更远的未来。

# 我的理想 刘甜欣

每个人心中都有一颗理想的种子，有的想成为救死扶伤的医生，有的想成为探索宇宙的宇航员。而我的心愿，是成为一名守护道路安全的交警。

这个心愿的种子，是在那个寒风凛冽的冷雨天悄悄埋下的。那天放学，天空像漏了个大洞，雨水如调皮的精灵般噼里啪啦地砸在我的伞面上。当我路过十字路口时，一抹荧光黄的身影牢牢抓住了我的视线——那是一位交警叔叔。他站在积水的指挥台上，雨水顺着帽檐汇成小溪，浸透了他的衣衫，可他纹丝不动，眼神如鹰隼般锐利地注视着车流。

这时，一位老奶奶拄着拐杖站在路边，望着飞驰而过、溅起层层水花的车辆，显得手足无措，仿佛风雨中一片飘摇的落叶。交警叔叔立刻注意到了这一幕，他毫不犹豫地吹響哨子，示意车辆暂停，随即大步流星地跑向老奶奶。他伸出那双有力的大手，轻轻扶住老人的胳膊，眼神瞬间变得无比温柔，轻声说道：“阿姨，别怕，我扶您过去。”在他的护送下，老奶奶安全通过了马路。老人感激地连声道谢，交警叔叔却只是抹了一把脸上的雨水，微笑着说：“这是我们应该做的。”说完，他又像一棵风雨中的松柏，坚定地回到了岗位上。那一刻，敬佩之情在我心中油然而生，当一名交警的理想也愈发清晰。

光有理想是不够的，更要付诸行动。我知道，交警不仅要有强健的体魄，更要有钢铁般的意志。以前，我遇到难题总想打退堂鼓，可现在，每当想放弃时，脑海中就会浮现出那位叔叔在风雨中坚守的身影。于是，我咬牙坚持，攻克了一道道数学难关；为了培养专注力，我在课堂上强迫自己紧跟老师的思路，不再走神；为了锻炼毅力，我坚持每天晨跑，哪怕双腿酸痛也不停歇。因为我明白，未来的道路上，无论是烈日炎炎还是大雪纷飞，我都必须能扛得住。

或许现在的我，离一名优秀的交警还有很长的路要走。但我坚信，只要我从点滴小事做起，磨砺自己的意志，终有一天，我也能穿上那身帅气的制服，站在十字路口。那时，我不仅仅是在指挥交通，更是在守护这座城市的温度，守护每一个归家人的平安。

# 一次特别的体育课 刘甜欣

在我的成长道路上，发生过许许多多特别的事情。其中有一件事，宛如夜空中最闪亮的星，始终照亮着我前行的方向。那，真是一次特别的体育课。

那天，太阳火辣辣地烤着操场，塑胶跑道烫得像要冒烟。老师宣布要测400米，我的心“咚咚”直跳，像揣了只小兔子，手心直冒汗。

同学们如脱缰的野马般冲了出去，我也咬紧牙关，奋力追赶。渐渐地，我竟然跑到了队伍的前头！心中涌起一阵藏不住的喜悦。然而，就在我准备加速冲刺时，左脚不慎踩进了一个隐蔽的小坑。顿时，身体猛地一歪，我踉跄了一下，差点摔倒在地。虽然身子迅速俯低又强行正了起来，但这一摔几乎耗尽了我所有的力气，也打乱了我的节奏。喉咙像着了火一样干痛，双腿沉重得仿佛灌了铅，脚步越来越慢。看着一位位同学从身边反超而过，放弃的念头瞬间布满了脑海：“哎——都最后一名了，还跑什么？反正也没名次了。”

就在我脚步渐缓、准备停下时，一阵震耳欲聋的呐喊声在耳边炸响：“加油！别停！你能行！”我抬眼望去，是已经跑完的同学们。班长小明涨红了脸，挥舞着双臂拼命为我鼓劲；好朋友小华急得直跺脚，眼神里满是关切与期待。那一声声真诚的呼喊，如同清凉的甘泉，瞬间浇灭了我心中的焦躁。脑海里浮现出平日里挥洒汗水刻苦练习的画面，放弃的念头顿时烟消云散。

我深吸一口气，尽管肺部像要炸开，汗水流进眼睛带来阵阵刺痛，但我用尽全力摆动手臂。一步，两步……我又跑起来了！快到终点时，周围的喧嚣仿佛都消失了，天地间只剩下我和那条白色的终点线。我屏住呼吸，俯低身子，向着终点拼命冲去。在压线的那一刻，在老师按下秒表的瞬间，我激动地跳了起来。那一刻，所有的疲惫与压力都已释放，化作满满的成就感。

那次，真是一次特别的体育课。它不仅让我体验了身体的极限，更让我明白了坚持的意义。从那以后，每当我遇到挫折或困难想要退缩时，那天的呐喊声总会回响在耳畔，激励我咬牙坚持下去，直到抵达终点。

# 美好的瞬间 刘甜欣

六年的时光即将画上句号，回首这段成长岁月，无数美好的瞬间如夜空中闪烁的星星，照亮了我的记忆。其中有一颗格外明亮，那便是雨天里陈阿姨送我回家的那个瞬间。

记得那天放学，天空突然变脸，倾盆大雨哗哗而下。雨点像断了线的珠子砸在地上，溅起层层水花，天地间仿佛挂起了一道厚重的雨帘。我没带伞，呆呆地站在雨棚下，看着同学们一个个撑伞离去，身影渐渐消失在雨幕中，心里顿时涌起一阵失落与无助。爸妈还没下班，我该怎么办呢？就在我焦急万分时，一只温暖的大手轻轻搭在了我的肩上。我吓了一跳，回头一看，原来是每天在校门口值勤的邻居陈阿姨。她慈祥地看着我，关切地问：“小刘，怎么还没回家呀？”我低声嗫嚅道：“我……我没带伞。”陈阿姨沉思片刻，眉头微皱，随即又舒展开来，温和地说：“这雨一时半会儿停不了，要不坐我的车回去吧？”我心里顿时纠结起来：这样会不会太麻烦阿姨了？万一她家里也有事等着呢？可看着这漫天大雨，我又实在不敢独自冲出去。陈阿姨似乎看穿了我的心思，拍拍我的肩膀笑道：“放心，顺路就把你送到家门口，别让你爸妈担心。”

我坐上电动车后座，陈阿姨利落地穿好雨衣，递给我一把大伞。一路上，风雨交加，冷风刮在脸上生疼，但陈阿姨依旧笑着跟我聊起家常，声音在风雨中显得格外温暖。我努力将手中的大伞向前倾斜，稳稳地架在陈阿姨的头顶，为她遮挡风雨。那一刻，仿佛周围的狂风暴雨都静止了，只有陈阿姨如阳光般的笑容，源源不断地温暖着我的心房。

那个瞬间，陈阿姨在风雨中为我遮风挡雨的身影，深深定格在我的脑海里，成为了我心中最美好的画面。

那份温暖，不仅照亮了我的童年，更在我心中种下了一颗种子。它让我明白：当别人遇到困难时，我们要毫不犹豫地伸出援手。愿这份爱不断传递，让我们都能成为别人记忆中，那个定格在美好瞬间里的人。

# 跨越自己 刘甜欣

跨越，是历经一次次克服重重困难，战胜怯懦，重塑真实自我的过程。那一次，我不仅战胜了身体的极限，更在精神上完成了一次真正的跨越。

记得那一堂体育课，滚烫的太阳无情地烘烤着大地，空气仿佛都在扭曲，红色的跑道似被烤熟了一般散发着热气。当老师宣布这节课要进行 400 米测试时，我的心猛地一紧，双腿竟不由自主地微微颤抖，恐惧像野草般在心中蔓延。

随着一声清脆的哨响，同学们如离弦之箭般冲了出去，我也咬紧牙关紧跟其后。渐渐地，我竟然冲到了队伍前列！喜悦如潮水般涌上心头。然而，就在距离终点最后一百多米，我准备全力冲刺时，意外发生了——左脚不慎绊住了右脚，整个人猛地一踉跄，差点重重摔在地上。虽然勉强稳住身形，但这一跌打乱了我的节奏，更耗尽了我积攒的体力。脚步瞬间变得沉重无比，速度急剧下降。

看着一个个身影从我身边掠过，我渐渐落到了最后。“都已经是最后一名了，还要继续跑吗？”放弃的念头在脑海中疯狂滋长。就在我脚步迟疑、几乎要停下时，一阵熟悉的呐喊声穿透燥热的空气传入耳中：“加油！别停下！”那是好友们焦急而坚定的声音。那一刻，风似乎停了，世界只剩下那声鼓励在耳边回荡。脑海中浮现出往日刻苦练习的画面，羞愧与不甘交织，让放弃的念头烟消云散。

我深吸一口气，喉咙里像冒着火，双腿像灌了铅一样沉重，但我依然用尽全力跨出第一步、第二步……我咬着牙再次奔跑起来，汗水早已湿透衣背，顺着脸颊滑落。最后十几米，仿佛整个操场只剩下我和那条白色的终点线。当我奋力跨过终点的那一刻，所有的疲惫与压力瞬间释放。我知道，这一次，我不仅跑完了全程，更突破了内心的软弱，跨越了自己。

那次奔跑，让我见证了最真实的自己。它让我明白，跨越自己就是要在想要放弃时再坚持一步。从此以后，无论生活中遇到怎样的坎坷与困难，我都会鼓起勇气去克服，不断超越，去迎接下一个更好的自己。

# 这就是幸福 刘甜欣

幸福，是冬日里的一抹暖阳，驱散严寒；是沙漠中的一泓清泉，滋润心田。在我心中，幸福并非惊天动地的壮举，而是那次考试失利后，妈妈用温柔与智慧为我重拾信心时的那一刻。那一刻，我真正明白了：这就是幸福。

记得那天放学，夕阳虽温柔地洒在脸上，我却无心欣赏。往日里生机勃勃的小花小草，此刻都耷拉着脑袋，无精打采；耳边小鸟的欢唱也变得刺耳无比，仿佛在无情地讥笑我的无能。是的，那张只有 77 分的数学试卷，像一块巨石压在我的心头，让我喘不过气来。

拖着沉重的步伐回到家，我本想躲进房间逃避现实，可妈妈还是从厨房走了出来，轻声问道：“这次考试怎么样？”我低着头，双手紧攥着衣角，一言不发。妈妈似乎猜到了什么，她没有责备，只是默默解下围裙，轻轻挽起我的手，将我引到书桌前。

灯光下，妈妈的眼神温柔如水，瞬间抚平了我内心的焦躁。她拍拍我的肩膀，接过那张布满红叉的试卷，仔细端详后，紧紧握住了我的手。那一瞬间，一股暖流顺着指尖涌遍全身，我心中的冰层仿佛被融化了，取而代之的是满满的感动与愧疚。妈妈柔声说道：“孩子，别灰心。一次考差并不代表永远失败。人生路上难免有风雨，哪有谁的一生是完美无缺的呢？你看那些名人，背后都藏着数不尽的挫折。失败乃成功之母，我们不能被困难打倒。”说着，她拿起红笔，指着那道最难题，耐心地为我画图分析。“你看，这是不是就清晰多了？”她一边比划，一边引导我思考，直到我紧锁的眉头舒展开来，眼中重新闪烁出光芒。

妈妈那专注而温柔的眼神，那句句充满力量的话语，如同一盏明灯，照亮了我前行的路。那次，妈妈没有批评，只有耐心的鼓励与引导。这份沉甸甸的爱，让我深刻懂得：只要从失败中汲取经验，勇敢突破，成功就在不远处。这份温暖的陪伴，就是我最珍贵的幸福。

# 风景这边独好 刘甜欣

在我们的人生画卷中，曾掠过无数美丽的风景：有壮丽的山河，有绚烂的民俗，也有温暖的瞬间。然而，最让我难以忘怀的，却是那道源自内心的独特风景。在我心中，唯有那一次的坚持，可谓“风景这边独好”。

那是一个烈日炎炎的午后，滚烫的太阳无情地烘烤着大地，空气仿佛都被蒸熟了，连跑道都散发着灼人的热气。就在那场令人挥汗如雨的体测中，全班同学的目光都被一个人紧紧吸引——她是我们班擅长跑步的小陈。

随着发令枪清脆的响声划破长空，她如离弦之箭般冲了出去，很快便占据了领先位置。就在距离终点仅剩一百米，准备全力冲刺的关键时刻，意外发生了：她的左脚突然一拐，绊住了右脚，整个人重重地摔在了粗糙的跑道上。我们的心猛地一紧，皱紧了眉头，焦急地注视着她。只见她的膝盖擦破了皮，渗出了细密的血丝。她双手撑地，一次次试图站起，却因剧痛又一次次失败。就在大家以为她要放弃时，人群中突然有人喊道：“看！她站起来了！”我们的目光再次聚焦在她身上：汗水早已浸透了她的衣衫，她的眼神中闪过一丝倔强与不甘，用尽全身力气，缓缓挺直了腰杆。当她迈出艰难的第一步时，我们心中的希望之火重新被点燃，呐喊声此起彼伏：“加油！坚持住！”她仿佛听到了这份力量，咬紧牙关，再次奔跑起来！

我们早已在终点线翘首以盼，呐喊声从未停歇。最后五十米，她咬着牙，双眼死死盯着终点，俯低身子，像一位顽强的战士向终点发起最后的冲锋。越来越近了她的身影终于冲过了那条白线！就在裁判员按下秒表的那一刻，我们比她还要激动，一拥而上紧紧拥抱住她。那时的她，体力早已透支，膝盖的疼痛也未曾消退，但她凭借顽强的意志力，完成了这场与自我的较量。

那次体测，小陈忍着伤痛坚持到底的身影，成为了我记忆中最美的风景。这道风景之所以“独好”，不仅因为她突破了身体的极限，更因为她用行动诠释了坚持的真谛。这道内心的风景，将永远激励着我：无论未来遇到怎样的挫折与困难，都要咬牙坚持，永不放弃。
