# 没想到我如此坚强 刘甜欣

我以为自己会半途放弃，却没想到，那个在跑道上鲜血直流却仍站起来的人，竟然是我，没想到我如此坚强。

那是我人生第一次参加校运会400米长跑。阳光洒满操场，红色的塑胶跑道被晒得微微发烫，像一条燃烧的路。看台上人声鼎沸，我的心也随着裁判举起的发令旗一点点提到了嗓子眼。枪声“砰”地响起，我像离弦的箭一样冲了出去，脚步轻快，风在耳边呼啸。一圈、两圈……我竟然跑在了队伍前列！喜悦在我心里悄悄开花，仿佛胜利已经在向我招手。

可就在我准备加速冲刺时，左脚忽然一滑，右脚绊住了左脚——“啪！”我重重摔倒在地！手掌擦破了皮，火辣辣地疼；膝盖磕在地上，鲜血慢慢渗了出来。我趴在那里，喘着粗气，喉咙像被刀割一样疼。眼看一个个选手从我身边跑过，我心里涌起一阵绝望：算了吧，真的撑不下去了……

我坐在地上，眼泪在眼眶里打转。我想起了妈妈每天陪我晨跑的身影，想起了体育老师对我说：“跑不完不要紧，但一定要走完全程。”就在这时，观众席突然爆发出一阵呐喊：“加油！站起来！”“你能行！”一个熟悉的声音特别清晰：“别停，我们都在看你！”那一瞬间，我的心猛地一颤，好像有一股力量从泥土里钻出来，直冲头顶。我咬紧牙关，双手撑地，一点一点，站了起来。

腿在抖，呼吸像破风箱，但我迈出了第一步。一步，再一步，像是从泥潭里拔出双腿，但每一步都踏在尊严之上。我拖着虚脱的身体奋力向前挪动，心里只有一个念头：不能停，必须走到终点！100米，80米，50米……奇迹发生了——在最后几十米，我竟然反超了两名选手！当我压低身子冲过终点线时，全场响起了掌声和欢呼声。

那一刻，成了我心中不灭的火种。自那以后，我的骨子里多了一份不服输的韧劲。每当我遇到困难想放弃时，眼前总会浮现自己蹒跚前行的身影。原来我的体内，藏着一个不肯认输的灵魂。

直到今天我才明白，真正的精彩，不是从不跌倒，而是跌倒后依然选择前行。那一次，没想到我如此坚强。

# 没想到我如此胆小  刘甜欣

在我的成长道路上，总有一些事情让我印象深刻。以前，我还经常笑话同学不敢看恐怖片，觉得他们太胆小。可经过那一次经历，没想到我如此胆小。

那天爸妈出差，姐姐也出去了，家里只剩我一个人。闲着无聊，我翻到一部大家都在议论的恐怖片。心想：这有什么可怕的？我肯定能扛住！于是我把大灯关掉，只留一盏小灯，点开手机就开始看了。

画面刚亮起，阴森的背景音乐就缓缓响起，像是从地底爬出来的低语。我的心一下子揪紧了，手心开始冒汗，连握着手机的指节都微微发白。屏幕上出现了一个又一个可怕的场景：破旧的玩具屋、满地的血迹、……我的心跳咚！咚！咚！一声比一声急，仿佛要冲出胸口。突然，“呯——！”的一声巨响炸开，我整个人猛地一抖，像被电流击中，抓起旁边的枕头死死捂住眼睛。

等我颤抖着把枕头拿开，脑海里却浮现出刚才的画面，怎么甩也甩不掉。我咬着牙，心想：不能再看了，快去开灯！我鼓起勇气，脚慢慢往下一伸——哎呀！脚下碰到一个东西，冰凉冰凉的。我“啊”地缩回脚，脑袋“嗡”地一下炸开了：不会吧？该不会有鬼吧，我呼吸都快停了，整个人缩进沙发角落，抓起被子一头钻进去，嘴里不停地念：“救命啊……救命啊……”

更可怕的是，电视里那个从小丑盒子蹦出来的小丑又出现了！他咧着血红的嘴，眼睛空洞地盯着屏幕外，好像在看我！每次他靠近受害者，我都忍不住往后退，直到背贴上了墙。就在这时，门“吱呀——”一声被推开了！

“啊——！”我尖叫出声，全身的汗毛都竖了起来，脑子里只有一个念头：小丑真的来了！他从电视里爬出来了！

刹那间，灯亮了。原来是姐姐回来了！她笑得前仰后合：“你捂被子干嘛？演木乃伊吗？”那一刻，我又羞又恼，脸烧得通红。原来什么鬼、小丑吃人，全是我自己吓自己。那短短几十分钟，几乎耗尽了我所有的镇定。

没想到我如此胆小，真正的勇敢不是不害怕，而是知道害怕，却依然愿意面对。

# 诚信让生活更美好 刘甜欣

“言必行，行必果。”诚信是中华民族的传统美德，当我终于鼓起勇气说出那句“对不起”时，我才明白——真正的安心，来自诚实。原来，诚信真的能让生活更美好。

记得那天，妈妈要出门，临走前叮嘱我：“你在家看好弟弟妹妹啊！”姐姐和爸爸也出去了，家里就剩下我和表弟表妹。妈妈刚走，妹妹就嚷着要看动画片。我赶紧打开电视哄她，然后溜进厨房找零食吃。

我正拿着苹果在水龙头下冲洗，突然听见客厅传来一阵大笑。我吓了一跳，手一抖，胳膊不小心碰到了旁边的柜子。“啪——”一声清脆的响，我回头一看，心一下子沉到了底——妈妈最心爱的那个蓝边碗，碎了一地！

我呆住了，脸都白了。那是妈妈最喜欢的碗，爸爸送她的礼物。我蹲下来，手发抖地把碎片一片片捡起来，塞进一个塑料袋里，悄悄藏在床底下。我坐在床边，小声嘀咕：“要是妈妈问起来，我就说不知道吧……”

没过多久，妈妈回来了。她走进厨房，翻了翻柜子，忽然问：“你们看见我的碗了吗？”我低着头，装作没事地说：“没看见，是不是放错地方了？”妈妈叹了口气，皱着眉头继续找。看着她失望的样子，我心里像压了块石头，越来越沉。

后来舅舅来接表弟表妹了。他们走后，我鼓起勇气，从床下拿出那个袋子，走到妈妈面前，声音发颤地说：“妈妈，对不起……是我不小心打碎了你的碗。”

我闭上眼，等着责骂。可妈妈轻轻抱住我说：“没关系，碗碎了还能买新的，但诚信丢了就难找回来了。你能主动承认，妈妈很欣慰。”

# 破碎的眼镜 刘甜欣
校园里，丁香花开得正旺，一簇挨着一簇，淡紫色的小花在春风中轻轻晃动。阳光透过玻璃窗洒进教室，落在讲台桌上那副闪着光的黑框眼镜上，像撒了一层金粉。
“叮铃铃——”下课铃一响，教室顿时热闹起来。这节课是大家最喜欢的，正是由充满活力的年轻班主任李军老师执教。他高高的鼻梁上架着一副黑色眼镜，平时总笑眯眯的，可一旦摘下眼镜，就说明他要上厕所去了。这不，他刚把眼镜轻轻放在桌上，转身走了出去。
这时，淘气包张明可坐不住了。他抓起篮球，和几个朋友在教室后排你扔我传，笑声不断。突然，一个球猛地飞来，张明一接一扔，“哗啦！”一声脆响，全班瞬间安静——讲台桌上的眼镜，碎了！
张明瞪得眼睛溜圆，冲过去一看，心一下子掉到了地上。“啊！”他吓得一屁股坐在地上，脸涨得通红。“完了完了！李老师最爱这副眼镜了！他会骂死我的！”他抓起篮球，拔腿就跑，躲进了厕所。
外面，风突然大了起来，树枝哗哗作响，落叶满地翻滚，好像连天空都在生气。李老师回来一看，火冒三丈：“谁干的？站出来！”同学们都不敢出声，这是李老师第一次发这么大的火。
班长王寒冰猛地站起来：“我去叫张明。”她脚步坚定地走出教室。躲在厕所里的张明正哆嗦着：“现在回去肯定挨骂……可不回去，会不会更惨？”正想着，一只冰冷的手搭上他的肩，他吓了一跳——是王寒冰！“跟我回去！”“我回去不是自投罗网吗？”“越晚越糟！”王寒冰不由分说，把他拉回教室。
张明低着头，声音发抖：“李……李老师，是……是我打碎的……对不起……”话没说完，眼泪就掉了下来。
没想到，李老师笑了：“没事！你能主动承认，老师很高兴！”他轻轻摸了摸张明的头。阳光重新洒进来，风停了，丁香的香味又飘满了校园。

# 点赞的力量 刘甜欣

在成长的旅途中，总有一些微小的瞬间，像星光般悄然照亮我们的心。不是惊天动地的壮举，也不是万众瞩目的荣誉，而是在某个平凡的角落，一个选择、一次行动，让“赞”字轻轻落在我心头。

记得那一次跑操，只剩最后一圈了，我的脚步变得轻快，心里欢呼着：“终于要解放了！”阳光洒在跑道上，映出我们奔跑的身影。突然，前面一位同学脚下一滑，重重地摔在地上。我猛地一惊，本能地往旁边一闪，目光却立刻被她吸引过去——她的膝盖擦破了皮，渗出血丝，裤子也裂开一道口子，脸上写满了疼痛与羞怯。

我的心一下子揪紧了，脑海里飞快闪过两个念头：扶，还是不扶？如果扶了，老师会不会误会是我撞倒她的？可如果不扶，她一个人疼得站不起来，又该怎么办？风轻轻吹过脸颊，仿佛也在催促我做决定。最终，我深吸一口气，迈步上前，轻轻拍了拍她的肩膀：“别怕，我扶你去医务室。”

她抬起头，眼里闪着感激的光，点了点头。我一手撑住她的肩膀，另一手稳稳扶住她的胳膊，小心翼翼地陪她一步步走上楼梯。当我终于将她安全送到医务室，放下她时，她轻声说：“谢谢你。”我摇摇头：“这是我应该做的。”转身离开时，我心里默默为自己点了个赞。

我还要为大哥哥的言行点赞。那天上学路上，一个小同学随手把饮料瓶扔在路边。我皱了皱眉，正想着要不要去捡，忽然看见一位高年级的大哥哥快步走过去，弯腰拾起瓶子，三步并作两步追上那个小同学，温和却坚定地说：“小朋友，垃圾要扔进垃圾桶哦。”声音不大，却像春风拂过树梢。小同学愣了一下，脸“唰”地红了，接过瓶子，低着头，几步走到旁边的垃圾桶，认真地扔了进去。

大哥哥笑了，轻轻拍了拍他的后背，便转身走进校园。那一幕像一幅画，定格在我心里。我站在原地，望着他们的背影，心中不由自主地为他点赞。

这两件小事平凡却温暖，让我深深为之点赞。。从那以后，每当我看到别人需要帮助，或地上有垃圾，我都会主动上前。因为我相信，小小的善举，也值得被点赞。

# 悔（懊悔的重量） 刘甜欣

“悔”不像眼泪那样汹涌，也不像疼痛那样尖锐，但它会在某个瞬间突然浮现，提醒你曾经错过的那一秒、那一句话、那一次选择。

那天清晨，我睡过头，出门时已经很迟了。我一路狂奔冲向学校，脚步声在空荡的走廊里回响。正当我冲到二楼楼梯口时，一个小小的身影蜷缩在拐角处，挡住了我的去路。是个低年级的小女孩，满脸泪水，左手紧紧捂着右脚，脚踝肿得像个小馒头。我下意识地伸出手，想扶她去医务室。可就在这时，我瞥见手表上的指针——糟了！还有两分钟就要上课了！要是扶她，肯定迟到；可如果不扶……我的心跳猛地加快，时间一分一秒地溜走，仿佛催命般飞转。“你等一下，我一定会来！”我丢下这句话，转身拼命冲向教室。

整节课，我的眼睛总忍不住望向窗外的楼梯口。阳光斜照在那里，空荡荡的，只有风轻轻吹动一片落叶。下课铃一响，我立刻冲出去，可那里早已没人。我心中无比自责：那位小妹妹伤得严重吗？我当时为什么没有为她多停留一会？我应该扶她去有医务室呀。那一刻，我真后悔，心里像压了一块石头——那句“我一定会来”，像一张空头支票，风一吹就散了。

还有一次，我和同桌吵完架，心情很差。她把涂改带借给我时，我没好气地一把拿过，重重扔在桌上。就在那一瞬间，我越想越气，猛地按了一下涂改带，“咔”的一声——坏了！我的心一下子沉到底。“怎么办？告诉她吗？她会不会更生气？我会不会彻底失去这个朋友？”我犹豫了很久，最后还是把坏掉的涂改带还给她，小声说：“你的涂改带……不知道怎么坏了。”她笑了笑说：“没事，我再买一个。”可她越是宽容，我心里就越难受，越后悔。那笑容像一面镜子，照出了我的胆小和逃避。

这两次经历，让我真正尝到了“悔”的滋味。它不是一时的情绪，而是藏在心里的刺，时不时提醒你：曾经，你可以做得更好。现在，每当我看到有人需要帮助，或是面对诚实的选择时，我都会做出更好的选择。

# 无声的情意 刘甜欣

姐姐的爱从不挂在嘴上，而是藏在行动里。那份无声的情意，我一直记得。

我姐姐平时话很少，总是一副冷冷的样子，连妈妈都说她“不懂关心人”。小时候我甚至觉得，她大概真的没有感情吧。可那一次的事，却让我彻底改变了想法。

那天，我和姐姐正坐在客厅看电视，看得入迷，谁也没注意茶几上的那套茶具。忽然，“哐当”一声，我一脚不小心踢到了桌腿，由于用力太猛，桌上的茶杯晃了两下，接着摔在地上——碎了一地。我和姐姐猛地跳起来，呆呆地看着满地的碎片，心一下子提到了嗓子眼。“完了完了！”我脑子里一片空白，“这可是爸爸最宝贝的东西，他花大价钱买回来的！”我越想越怕，手心直冒汗。更糟的是，门外突然传来“吱呀”一声——爸爸提前回家了！

爸爸一进门就看见地上的碎片，脸色立刻沉了下来，吼道：“谁干的？这么贵的东西，你们竟敢打碎？说！到底是谁？”我吓得说不出话，腿都在抖，刚想迈出一步承认，姐姐却突然开口：“我摔的。”我愣住了，简直不敢相信自己的耳朵。那是我第一次听见她替我说话。爸爸立刻转过头狠狠批评她，而她只是低着头，一句话也不辩解。我躲在门后看着她沉默的背影，鼻子一酸，眼泪忍不住一颗颗掉了下来。后来，我悄悄问她为什么替我承担，她只轻轻说：“你害怕的样子，像极了小时候的我。”那一刻，我终于明白，姐姐的爱从不挂在嘴上，而是藏在行动里。

多年过去，那套碎裂的茶具早已被清理干净，可姐姐那句轻得像风、却重如山的“我摔的”，一直在我心里回响。她用沉默为我挡下责骂，也用行动教会我什么是守护。这份无声的情意，我会永远记得，并在未来的某一天，悄悄传递给需要的人。

# 乐（乐在其中） 刘甜欣

“乐”不只是嘴角上扬的笑容，更是摔倒时伸出的手、风中扶起的一辆辆单车。它像一颗种子，在一次次微小的行动里悄悄发芽，长成了我心中最温暖的模样。

记得一次大课间跑操，阳光洒在跑道上，我们排着队奔跑。只剩最后一圈了，我脚步轻快，仿佛胜利就在前方。忽然，前面的同学一个踉跄，重重地摔在地上。我赶紧刹住脚步——她的膝盖擦破了皮，渗出细小的血丝。

我的心猛地揪紧：扶吗？扶了会迟到，老师会不会误会？可如果不扶……风从耳边吹过，仿佛也在催促我做决定。“扶！”我咬了咬牙，走上前去，“我扶你去医务室。”她点点头，眼里闪着感激。我小心搀着她，一步一步爬上楼梯，汗水顺着额头滑落，衣服也湿透了。到了医务室，她轻声说：“谢谢你，要不是你，我真不知道怎么办。”我摆摆手：“没事，举手之劳。”转身离开时，脚下仿佛踩着一朵幸福的云，心里像喝了蜂蜜水一样甜。那一刻，我明白了——乐，是伸手的勇气，是分担的温度。

还有一次清晨，我出门散步。看到一辆辆共享单车倒在停放点旁，不仅挡住了行人通道，还堵住了盲道。第一反应是绕道走。可刚迈出一步，回头看见那一片歪斜的单车，想到行人的不便，特别是盲人经过，多危险啊！我还是把它们扶起来吧。我跑过去，一辆一辆地扶正、摆好在停放点。等全部整理完，我已经气喘吁吁，胳膊酸得抬不起来。回家的路上，太阳升得更高了，路边的小花随风轻轻摇曳，仿佛也在对我点头微笑。我知道，我不是为了谁表扬才这么做，但这份累里的甜，比糖果更真实。那一刻，我又尝到了“乐”的滋味——原来，乐不仅是帮一个人，也可以是为一座城出一份力。

经历了这一切，我才明白，外表并不重要，重要的是我能否发出光，照亮前方的路。或许，这就是我的使命。即使被砸、被毁，只要我还亮着，就能为黑夜中的人们带来希望。”

# 美（美一直都在） 刘甜欣

美，不是挂在墙上的画，也不是橱窗里闪亮的饰品。它悄悄藏在一场突如其来的雨中，藏在一只被弯腰捡起的饮料盒里。只要你愿意停下脚步，用心去看，就会发现——美，从未远离。

那天放学，天空突然下起了雨。我没带伞，爸爸妈妈又没空来接我。我站在学校雨棚下，看着同学们一个个撑伞离开，心里一阵发慌。

就在这时，一只温暖的手轻轻落在我的肩上。我吓了一跳，抬头一看——是那位每天在校门口值勤的阿姨。她低头问我：“小朋友，怎么还不回家？”我低着头小声说：“没带伞……家长也来不了。”她沉默了一下，说：“那我送你回去吧。”我连忙摆手拒绝，可她笑了笑，语气坚定：“别怕，就送到家门口。” 

她推出电动车，把唯一的伞递给我：“你撑着，别淋湿了。”我犹豫地接过伞，坐上了后座。雨点打在伞上噼啪作响，风夹着冷意吹过脸颊。她穿着单薄的外套，帽子压得低低的。直到我家楼下，我才看清——她的后背被雨水淋湿了。那一刻，我心里猛地一颤：原来她说“没关系”，是为了让我安心；她不撑伞，是怕我淋雨。我鼻子一酸，只挤出两个字：“谢谢……”她回头笑了笑：“快回家吧，孩子！”那笑容像一道阳光，穿透了雨幕，也照进了我心里。那一刻，我觉得她真美。

还有一次上学路上，一个小男孩喝完饮料，随手把空盒子扔在地上。我皱了皱眉，心想：怎么这么不讲文明？正想着，一个高年级同学快步走上前，弯腰捡起瓶子，追上小男孩，轻声说：“小朋友，垃圾要扔进垃圾桶哦。”男孩愣了一下，脸红了，接过瓶子飞快跑向路边的垃圾桶。回来时，那位同学笑着拍拍他的头：“知错能改，就是好孩子。”说完便转身走进校园。阳光洒在他身上，那一瞬间，我看到的不只是一个动作，而是一颗纯净的心——那才是真正的美。

原来，真正的美在每一次选择善良的瞬间。那位阿姨淋湿的背影，那位同学弯腰的身影，都像一颗颗星星，落进我心里。从此我知道，只要我也愿意伸手、弯腰、说一句温暖的话，我，也能成为别人眼中那一抹动人的美。
