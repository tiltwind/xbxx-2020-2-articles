# 没想到我如此坚持 熊茁铭

生活中，有许多精彩的瞬间，它们像星星一样点缀着我的成长之路。而那一次800米跑道上的奔跑，让我第一次看清了自己——原来，我有这么坚持的一面。没想到，我如此坚持。

那天上午，学校运动会热闹非凡。阳光洒在操场上，彩旗飘扬，加油声此起彼伏。我作为800米项目的参赛选手，站在起跑线前，双腿微微发抖。风轻轻吹过脸颊，带着初夏的暖意。随着发令枪响，我像离弦的箭一样冲了出去。第一圈，我跑在最前面，脚步轻快，心里暗暗给自己鼓劲：“加油！我一定能行！”

可好景不长。进入第二圈后，力气一点点被抽走。呼吸越来越急促，胸口像压了块大石头，每一次吸气都像在挣扎。脚步也变得沉重，仿佛鞋底灌满了铅，抬一下都那么吃力。更让人慌乱的是，身后传来一阵阵急促的脚步声——对手追上来了！他们越逼越近，那节奏像一群不肯放弃的野狼，步步紧逼，几乎要把我吞噬。我的脑子一片空白，一个声音在心底响起：“算了吧，放弃也没关系……”

就在我快要撑不住的时候，看台上突然爆发出整齐的呐喊：“加油！坚持住！”那声音像一道光，劈开了我心中的黑暗。我仿佛看见同学们挥舞的手臂，看见老师期待的眼神，想起训练时一次次咬牙跑完的清晨。不行！我不能在这里停下！正因成功来之不易，我怎能在此刻放手？我咬紧牙关，挺直身子，重新攥紧拳头，拼尽全力向前奔跑。

还有三十米！我闭上眼睛，什么都不管了，只凭着一股信念往前冲。二十米，十米……终点就在眼前！我用尽最后一丝力气，猛地扑过终点线，整个人瘫倒在地，大口喘着气，汗水浸透了衣服，连手指都在发抖。

我赢了！第一名！同学们围上来欢呼，老师冲我竖起大拇指，眼里满是赞许：“好样的，坚持到底才最棒！”那一刻，眼里闪着光，不是因为胜利，而是因为我没有向自己低头。

从那以后，每当我遇到困难想退缩时，耳边就会响起那天的脚步声和加油声。我明白了：真正的精彩，不是站在领奖台上的荣耀，而是明明已经筋疲力尽，却还是选择再跑一步。没想到，我如此坚持。

# 没想到我如此坚强 熊茁铭

在生活中，有许多事情连自己都想不到，而那一次，没想到我如此坚持。

那天太阳火辣，跑道被晒得发烫，我站在起跑线上，心跳如鼓，手心出汗。枪声响起，我像离弦的箭一样冲了出去。风在耳边呼啸，脚步轻快有力，我稳稳地跑在最前面。那一刻，我仿佛握住了胜利的钥匙，心里默念：第一名，一定是我的！可没过多久，身后脚步逼近，一个身影从我身旁掠过，第一的位置丢了。我不甘心，咬紧牙关紧紧跟上。

第二圈，我依然紧跟领先者。忽然，耳畔传来熟悉的声音：“小铭，加油！坚持住！”是班长，是同桌，是全班同学齐声呐喊！那声音像一股暖流涌进心底，我猛地加快步伐，再次冲到前面。可刚过第二圈终点，力气就像被抽空了一样。阳光炙烤着跑道，汗水顺着脸颊滑落，滴在滚烫的地面上仿佛都要蒸发。双腿越来越沉，呼吸越来越急，但我一遍遍告诉自己：再撑一下，再撑一下就好！

第三圈，只剩最后一段直道。100米、90米……我回头一看，对手还差几十米，胜利似乎触手可及。可就在这时，脚下一绊，整个人重重摔在地上！膝盖火辣辣地疼，像是被火烧过一样。我趴在地上，脑袋嗡嗡作响，像泄了气的气球，只想停下。可就在这时，我心里有个声音响起：“加油！小铭，你一定行的！”那是我每天早晨训练时对自己说的话，此刻竟成了支撑我的力量。

我慢慢撑起身子，一瘸一拐地向前跑。身后的脚步声越来越近，但他们不再是野狼，而是提醒我不能停下的鼓点。30米、20米……脑子里只剩下两个字：冲啊！我拼尽全力，跌跌撞撞跨过终点线。

我没有站上领奖台，只拿到了第三名。但当我喘着粗气抬头时，却发现掌声从四面八方涌来——不为名次，而为坚持。我心里涌起一阵自豪，一种前所未有的充实感告诉我：这一次，我没有放弃，因为我坚持到了最后。

那一次，没想到我如此坚强。原来，真正的胜利不是第一个冲线，而是在摔倒后还能站起来继续奔跑。这场比赛让我明白，我比自己想象中更有力量。这份坚持，藏在每一次想放弃却咬牙挺住的瞬间里。

# 这一精彩时刻带给我的影响  熊茁铭

生活中，有许多精彩的瞬间，它们像星星一样点缀着我的成长之路，而其中一次特别的时刻，深深影响了我。

那天上午，学校运动会热闹非凡。我作为800米项目的参赛选手，站在起跑线前，双腿微微发抖。四周是此起彼伏的加油声，风轻轻吹过脸颊，带着初夏的温度。“三、二、一——开始！”随着发令声响起，我一马当先，像离弦的箭冲了出去。耳边是呼呼的风声，脚下仿佛装了马达，每一步都充满力量。第一圈，我领先许多，心中暗暗给自己打气：“加油！我一定能赢！”

可到了第二圈，体力渐渐不支。呼吸变得急促，胸口像被压了块石头，脚步也越来越沉，仿佛灌了铅一般。更糟的是，身后传来一阵阵急促的脚步声——对手追上来了。他们越逼越近，那节奏像一群紧追不舍的野狼，逼得我几乎喘不过气。我想放慢脚步，甚至冒出一个念头：“要不放弃吧？输了也没关系。” 

就在这时，我听见看台上同学们齐声呐喊：“加油！坚持住！”那声音像一道光，照进我快要熄灭的心里。我咬紧牙关，心里默念：“不行！我不能放弃！任何成功都不是轻而易举得来的，我又怎能轻易认输？”那一刻，我忽然明白：真正的胜利，不是第一个冲过终点，而是即使想放弃，也依然选择继续奔跑。

我重新挺直身子，眼神坚定，拼尽全力向前冲刺。还有三十米，我闭上眼，什么都不管了，只凭着一股信念往前冲。二十米，十米……终于，我冲过了终点线，整个人瘫倒在地，大口喘着气，汗水浸湿了衣裳。

我赢了！第一名！同学们为我欢呼，老师也笑着夸我：“坚持就是胜利！”那一刻，我的眼里闪着光，心里热乎乎的。

从那以后，每当我遇到困难想退缩时，耳边就会响起那天的脚步声和加油声。我明白了：真正的精彩，不是站在领奖台上，而是明明想放弃，却还是选择了坚持。这一精彩时刻，给我带来了很大的影响。它像一颗闪亮的星星，一直照亮我前进的路。

# 爱让生活更美好 熊茁铭

爱，是一盏明灯，照亮黑暗中的路；爱，是一个温暖的港湾，抚慰疲惫的心灵；爱，更是一缕阳光，悄悄融化寒冷与孤独。爱让生活更美好。

那天原本晴空万里，我放学后在操场打完球，已是晚上九点多。天空不知何时悄悄布满了乌云，我毫无察觉。刚走出校门，轰隆一声雷响，大雨倾盆而下。我急忙跑到路边一家烧烤店屋檐下躲雨，浑身早已湿透，头发还在滴水。我不敢进店，怕弄脏人家干净的地板。可店主叔叔看见我，立刻打开门喊道：“小朋友，快进来！别淋着了！”

我犹豫地走进去，水珠不停地往下掉。叔叔不但没责怪我，反而拿出吹风机，一边帮我吹头发，一边轻声说：“别感冒了。”他那双温暖的手轻轻摸着我的头，我的心也一点点暖了起来。吹完头发，他还贴心地给我妈妈打了电话。

就在这时，我的肚子不争气地“咕咕”叫了起来。叔叔听了只是笑了笑，转身进了厨房。不一会儿，他端来一碗热腾腾的蛋炒饭：“来，吃点东西暖暖身子。”我红着脸小声说：“叔叔，我没带钱……”他摆摆手：“孩子，不用给钱，吃饱要紧。”我眼眶一热，慢慢吃了起来。那一碗普通的蛋炒饭，却让我尝到了最温暖的味道。

吃完饭，我们聊了几句。他问我上几年级，将来想考哪所中学。我有些迷茫，他却鼓励我说：“只要努力，梦想一定能实现。”不久后，妈妈赶来接我，雨也停了，仿佛连天空都被这份善意感动了。我临走时回头望了望，小声说了句：“谢谢您，叔叔。”

从那以后，我明白了什么是爱——是在别人困难时伸出援手，是不求回报的温柔与善良。我也开始学着关心同学，帮助需要帮助的人。因为我知道，正是这点点滴滴的爱，让世界变得更温暖、更美好。爱，真的让生活更美好。

# 温暖的街头   熊茁铭
冬日的黄昏像一块冷却的灰烬，风卷着落叶在街角打转。车灯划破暮色，人影匆匆。陆天和参加志愿者的徐明并肩走着，羽绒服裹得严严实实，却在一片不起眼的草丛边，停下了脚步——那里，一双湿漉漉的大眼睛正静静地望着他们。
那是一只橙白色的猫，蜷缩在枯草间，怯生生地望着他们，胡须微微颤抖，像是冷极了，又像是在等待什么。徐明搓了搓手：“天都黑了，再不回家，我妈该着急了。”说完转身要走。陆天却站在原地没动，心里像被什么东西轻轻扯了一下。他低声说：“你先回去吧，我想帮它一下。”
他走进超市，盯着货架上的火腿肠出神。手表屏幕亮起，余额只有0.5元——远远不够买一根六块钱的火腿肠。他攥紧口袋，正想转身离开，抬头却看见徐明走了进来。“我就知道你会来。”徐明笑了笑，掏出钱递给收银员：“六块，对吧？”两人拿着火腿肠，一路小跑回街角。
寒风中，路灯拉长了他们的影子。小猫还在原地，像一座小小的、毛茸茸的雕像。陆天蹲下身，小心翼翼地撕开包装，把火腿肠一点点放在掌心。小猫先是迟疑，随后凑近，轻轻嗅了嗅，终于开始小口吃起来。它的尾巴微微摇了摇，眼神也不再那么惊慌。
“你看，”陆天轻声说，“它脖子上有块牌子。”徐明凑近一看，铁牌已经有些生锈，但上面两个字清晰可见：真理。
就在这时，一个女孩从远处飞奔而来，声音带着哽咽：“真理！我总算找到你了！”小猫抬起头，耳朵竖起，突然蹦跳着扑进她怀里。女孩紧紧抱着它，眼泪落在猫柔软的毛上。
风依旧冷，天依旧黑，但陆天的心里却像揣着一团火。那只叫“真理”的猫终于回到了主人怀里，而他和徐明，也在这个寒冷的街头，悄悄种下了一颗名为善良的种子。原来，温暖从不需要惊天动地，它就藏在一根火腿肠、一次回头、一句“我回来啦”里。

# 我为他们点赞 熊茁铭

在生活中，有许多精彩的时刻值得我们点赞。有时是为自己点赞，有时是为他人点赞。

有一次，期中考试成绩公布了。教室里安静极了，我的心砰砰直跳，像有只小鹿在乱撞。当老师念到“小铭，91分，有进步，继续努力”时，我顿时手舞足蹈，激动得不得了。这让我下定决心要更加认真听课。可当老师讲到选择题第十二题时，我发现不对——老师的答案是B，而我的是C。一开始我以为是老师批错了，但听着老师的讲解，思路清晰严密，一点漏洞也没有。我这才明白：是我被改对了，其实错了。要不要告诉老师呢？说了，90分以上的奖励糖果就没了，老师刚给的表扬也可能收回；可不说，我心里真的能踏实吗？诚信不是做人的根本吗？最终，我决定下课后去找老师。

下课后，我鼓起勇气走向办公室。明明只有几步路，脚下却像绑了铅块，每一步都沉重无比。站在门口，我深吸一口气，推开门，低着头小声说：“老师，这道题您改错了，我不该拿90分的糖果。”老师先是一愣，随即笑了：“谢谢你选择了诚实，这颗糖，你更配得上。”说着，又递给我一颗糖。那一刻，我心里的石头终于落了地，阳光仿佛重新洒满了心田。我忍不住在心里为自己点了一个大大的赞——这不是为了分数，而是为了那个没有向虚荣低头的自己。

还有一次放学，我留下来排完桌椅后，已经很晚了。我赶紧跑回家，可一不小心被石头伴了一下。重重摔在地上。膝盖火辣辣地疼，鲜血流了出来。正当我又痛又怕时，一位叔叔走了过来，看见我受伤，说：“别怕，我不是坏人，我背你去旁边药店吧！”我本想拒绝，可腿几乎动不了，只好点头答应。

到了药店，叔叔买了碘伏和棉签，蹲下身，一点一点轻轻帮我擦拭伤口，动作温柔得让我几乎感觉不到疼。涂完药，他说：“碘伏给你，记得每天涂，伤口好得快。”说完便匆匆离开了。我望着他的背影，默默比了一个大大的赞。那一刻，伤口似乎也不那么疼了。这是助人之赞。

当诚实被守护，当善良被传递，我们每个人，都可以成为那个值得被点赞的人。

# 甜（心中的甜） 熊茁铭

糖果的甜转瞬即逝，而心底涌起的那股暖流，却能久久不散。原来，甜不只是舌尖上的滋味，更是心灵深处的一抹光亮。

记得一次月考后，教室里安静得连笔尖划过试卷的声音都清晰可闻。我的心像小鹿乱撞，直到老师念到我的名字——95分！那一刻，我几乎要跳起来，脸上抑制不住地扬起笑容。这分数不仅代表进步，还意味着我能拿到老师奖励的糖果。可就在翻看试卷时，我发现一道选择题明明做错了，老师却没扣分。我的心一下子揪紧了：说，还是不说？如果说出来，95分会变成93分，那颗象征鼓励的糖果也许就不再属于我了；可如果不说，我心里真的能踏实吗？诚信，不正是做人的根本吗？终于，我下定决心——下课后去找老师。

走到办公室门口，明明只有几步路，可脚下就像灌了铅似的，抬起来都费劲。我深吸一口气，推开门，低着头小声说：“老师，这道题我错了，您没扣分……我不该拿满分的糖果。”老师接过试卷看了看，微笑着改成了93分，轻声说：“谢谢你选择了诚实，这颗糖，是你应得的。”说着，又递给我一颗糖。走出办公室，阳光洒在肩上，心里那块沉甸甸的石头终于落地。窗台上的绿叶轻轻摇晃，仿佛在向我点头，为我鼓掌。虽然没拿到95分，但我挺直了背，脚步也轻快起来。因为我知道，有一种甜，叫诚实后的安心。

还有一次，生日那天，妈妈送我一辆崭新的自行车。我高兴得丢下遥控器就冲出门去。本以为骑车是件轻松的事，可刚一上车，车身就歪向一边，“啪”地摔在地上。膝盖火辣作痛，手心全是汗，可我没有放弃。我想起一句话：失败是成功之母。于是，一次次摔倒，一次次爬起。夕阳把我的影子拉得很长很长，像一个不肯认输的小战士。我慢慢摸索出方法——车子往右倒，身体就往左倾斜，双手紧紧握住把手，眼睛盯着前方。终于，我能稳稳地骑出几十米了！风从耳边掠过，像在为我欢呼。那一刻，我笑了，笑得那么甜。因为我知道，还有一种甜，叫坚持后的突破。

一次是诚信的选择，一次是坚持的胜利。它们没有给我带来满分或奖赏，却给了我比糖更珍贵的东西——内心的踏实与成长的喜悦。原来，真正的甜，是灵魂被照亮时的那一瞬间。

# 风火轮上的冲刺 熊茁铭

操场上人声鼎沸，呐喊如潮水般一波接一波。阳光洒在红色的跑道上，映出我们紧张又兴奋的脸庞——这是一场决定班级荣誉的10×50米接力赛，而我的心跳，早已随着发令枪的影子狂奔而去。

比赛开始了！“砰”的一声，我们班的林天宇像离弦的箭一样冲了出去，起跑迅猛，一马当先。三班的小张也不甘示弱，双臂用力摆动，脚步飞快，仿佛脚下装了马达，紧紧咬住不放。第二棒是小王，他稳稳接过接力棒，像一匹脱缰的野马，脚下踩着风火轮般冲了出去，很快就把其他选手甩在身后。啦啦队的同学们挥舞着小旗，大声喊：“加油！加油！”整个操场都沸腾了！

可就在这时，意外发生了——三班交接棒时手一滑，接力棒“啪”地掉在地上！但他们没有放弃，立刻捡起棒子继续奔跑。而我们班的最后一棒小赵，却在最后直道上慢了下来，眼看对手一个个从他身边超过。我的心一下子提到了嗓子眼，急得直跺脚。

“小赵，加油！你一定能行！”我们全班齐声呐喊。那声音像一阵风，吹进了他的耳朵，也点燃了他眼中的火焰。只见他咬紧牙关，双臂疯狂摆动，脚步越来越快，十米、五米……他一个接一个地超越对手！

终点就在眼前！小赵猛地冲过终点线，反超小张，夺下第一！那一刻，欢呼声炸裂了整个校园。我激动得一蹦三尺高，和全班同学一起冲上前，紧紧抱住造子成。“你太厉害了！”泪水和汗水混在一起，喜悦在每个人脸上绽放。

这场接力赛让我明白：一个人也许能跑得很快，但只有一群人同心协力，才能跑得更远。这份团结的力量，将永远刻在我的童年记忆里。

# 我的拿手好戏 熊茁铭

每当厨房飘出阵阵香气，我就忍不住想露一手——不是为了炫耀，而是因为那一盘金黄喷香的煎鸡蛋，藏着我无数个夜晚的练习与坚持。它，就是我的拿手好戏。

我喜欢香喷喷的饭菜，更喜欢亲手做出美味的感觉。经过一次次练习，我终于把这道看似简单的小菜，变成了我的“绝活”。

那天晚上，妈妈正在厨房炒着菜，香味一阵阵钻进鼻子，勾得我手痒痒的。我站在一旁等她做完一道菜，五分钟、十分钟过去了，时间不长，可我心里焦急得仿佛过了好几个小时。“差一道煎鸡蛋就可以吃饭了，”妈妈笑着回头，“那不是你的拿手好戏吗？”我眼睛一亮，立刻冲上前去。

从冰箱里取出三个鸡蛋，轻轻在碗边一磕，蛋液滑入碗中，清亮的蛋清裹着圆润的蛋黄，像小月亮落进了银河。我快速搅拌，加入适量的盐和酱油，直到冒出细密的小泡。接着倒油，待油微微冒烟时，把蛋液缓缓倒入锅中。“滋啦——”一声，蛋液迅速膨胀，边缘泛起一圈金黄的花边，像一朵盛开的向日葵。

待鸡蛋底部成形后，我用铲子小心地翻了一个面，再煎三十秒，转成小火慢煎。趁热，我顺手洗了些葱花撒进锅里，香气“噌”地一下蹿了出来，满屋都是诱人的味道。最后，用铲子将蛋切成几块，盛进盘子里，一盘香喷喷的煎蛋就完成了！

我迫不及待尝了一口，外焦里嫩，咸淡正好，连我自己都忍不住夸一句：“真香！”赶紧叫来妈妈和妹妹品尝。他们刚吃一口，就异口同声地说：“好吃！太好吃了！”看着他们满足的笑容，我心里比吃了蜜还甜。

那盘煎得恰到好处的鸡蛋，不只是晚餐的一道菜，更是我用心打磨出的“作品”。它让我明白：真正的拿手好戏，不在于多稀有，而在于你为它流过的汗、受过的烫、尝过的失败，和最终端上桌时，家人眼中闪出的光。

# 乐（乐在其中） 熊茁铭

“乐”不是短暂的欢笑，而是帮助他人时的安心，是跌倒后重新站起的勇气。两个平凡的日子，让我真正明白了“乐”的分量。

那天放学，夕阳把小路染成金黄色。忽然，一个小小的身影从我身旁跑过，没跑多远，“扑通”一声摔倒在地。我赶紧跑过去，只见一个小弟弟坐在地上，一只手紧紧捂住膝盖，眼泪像豆子一样滚落下来。我蹲下身轻声问：“小弟弟，你没事吧？”发现他膝盖擦破了皮，渗着血丝。我连忙说：“别怕，我带你去旁边的药店，我不是坏人。”他抽泣着点点头。我一边快步走着，一边扶稳他，生怕他再受一点伤。

到了药店，我认真地向医生说明情况。医生用碘伏为他消毒时，我站在旁边轻轻安慰：“马上就好了，不疼了，别哭。”涂完药后，我又细心地帮他拨通妈妈的电话。不一会儿，他妈妈匆匆赶来，连声道谢。我摇摇头笑着说：“不用谢，看到别人有困难去帮忙，是应该的。”回家的路上，晚风温柔，我的嘴角时不时上扬——原来，助人的快乐，比糖果还甜。

还有一次下午，我推着自行车来到楼下，心想：骑车一定很简单！可刚一上车，车身就歪歪扭扭，还没蹬两下，就连人带车摔在地上。膝盖火辣辣地疼，手掌也磨红了。但我咬咬牙站起来，心里默念：“再来一次！”太阳一点点西沉，我不知摔了多少回，手心全是汗，衣服沾满灰尘。可我坚持着，一遍遍练习平衡，一次次尝试转弯……终于，我能稳稳地骑出好几十米了！

我悟出了要领：如果车子往左倒，身子就要往右倾，才能保持平衡。掌握了这个方法，我越骑越顺。晚风拂面，像在为我鼓掌。那一刻，我笑了，笑得那么灿烂。这不仅是因为学会了骑车，还是因为我没有放弃。

原来，“乐”从不只藏在笑声里，它躲在一次搀扶中，藏在一次次摔倒又爬起的身影里。当善良与坚持化作行动，快乐便不再是瞬间的情绪，而是一种成长的回响——那正是“乐”字最深的含义。

# 有你，真好 熊茁铭

在那个寒冷的冬天，发生了一件让我深深感动的事。那件事像一束光，驱散了刺骨的寒风，温暖了我的心，也让我永远记住了你。店主叔叔，有你，真好。

那个冬夜，寒风刺骨，雨像断了线的珠子砸向大地。我狼狈地躲在烧烤店屋檐下，浑身湿透，冷得直发抖。头发还在滴水，衣服紧贴在身上，鞋子也咕叽咕叽地响着。我不敢进店，生怕弄脏了人家干净的地板。就在我进退两难时，一扇门轻轻打开，一束暖黄的灯光洒了出来——“快进来吧！别淋感冒了！”你探出头，朝我招手。

我低着头走进店里，身上的水“滴答，滴答”落在地板上。可你不但没有生气，还立刻拿来吹风机帮我吹头发。你粗糙却温暖的大手轻轻摸着我的头，像爸爸一样。那一刻，明明是冬天，我却感觉不到一丝寒冷。吹完头发，你还细心地给我妈妈打了电话。

就在这时，我的肚子不争气地“咕咕”叫了起来。你听了笑了笑：“饿了吧？等着！”说完转身进了厨房。不一会儿，你端来一碗热气腾腾的蛋炒饭，金黄的蛋花裹着米饭，香气扑鼻。“来，吃点东西暖暖身子。”我红着脸小声说：“叔叔……我没带钱。”你摆摆手：“孩子，不用给钱，吃饱要紧。”我眼眶一热，慢慢吃了起来。那碗普通的蛋炒饭，却让我尝到了从未有过的温暖味道。

吃完饭，我们聊了几句。你问我上几年级，将来想考哪所中学。我低着头，声音很小：“还不知道……”你却笑着说：“没关系，只要努力，梦想一定实现。”那句话像一束光，照进了我心里。

不久后，妈妈赶来接我，雨也停了。月亮悄悄从云里钻出来，洒下淡淡的光。临走前，我回头望了望你忙碌的身影，小声说了句：“谢谢你，店主叔叔。”

每当寒风吹起，我总会想起那晚的灯光、那碗热饭、那只温暖的大手。你不知道，你的一句“快进来吧”，一次不求回报的善意，早已在我心里种下了一颗温柔的种子。如今，我也学会了在别人淋雨时，递出一把伞。因为有你，我才懂得：原来一个人，真的可以温暖一座城。

# 及时雨 熊茁铭

需要帮助时有人伸出援手，伤心难过时得到安慰和关心......这些都是及时雨。那一次，在我这最无助的时刻，一位夜跑的叔叔出现了——他就像一场及时雨，落进了我的世界。

那天放学很晚，我急着回家，怕妈妈担心。刚跑出校门没多远，脚下一绊，“扑通”摔倒在地。膝盖火辣辣地疼，低头一看，血已经渗了出来。我坐在地上，眼泪止不住地往下流，四周静悄悄的，天也渐渐黑了，心里又疼又怕。

# 成长的滋味（跌倒之后的坚持） 熊茁铭

人生就像一场长跑，有起跑时的兴奋，也有中途跌倒的疼痛。而真正让人成长的，往往不是站在领奖台上的那一刻，而是跌倒后咬牙爬起来继续前行的那一段路。那一次，我尝到了成长的滋味。

那是一个阳光明媚的上午，学校举行了一场热闹的运动会。我参加了二百米短跑比赛，这是我第一次站在起跑线上，心怦怦直跳。发令枪“砰”的一声响起，我像离弦的箭一样冲了出去，一开始还稳稳领先，心里乐开了花，仿佛冠军已经属于我了。可就在这时，我的脚不知被什么绊了一下，整个人重重摔在跑道上。膝盖火辣辣地疼，鲜血慢慢渗出来，我呆呆地趴在地上，看着其他选手从我身边飞奔而过，眼泪忍不住在眼眶里打转。

我想放弃了，真的想躺下不动了。可就在这时，我听见了熟悉的声音：“熊茁铭，站起来！你能行！”抬头一看，是我的同学们，他们挥着手，大声为我加油。那一刻，我心里突然涌出一股力量：我不能就这样认输！我咬着牙，慢慢爬起来，一瘸一拐地继续向前跑。

每一步都疼，但我没有停下。风擦过耳边，我仿佛听见了自己心跳的声音。终于，我跨过了终点线。我是最后一名，可我却没有难过，反而挺起了胸膛——因为我坚持到了最后。

赛后，同学把我送去了医务室，老师给我擦了药，说休息几天就好。虽然只是擦伤，但这次经历却深深印在了我心里。

那次运动会没有奖牌，也没有掌声，但当我一瘸一拐跨过终点线时，我知道，我赢得了一场更重要的比赛——战胜了想要放弃的自己。那一次，我尝到了成长的滋味：苦涩中带着甘甜，失败里藏着骄傲。从此以后，我面对失败和挫折，都不轻易放弃。

# 我得到了表扬 熊茁铭

成长的路上，有人得到帮助，有人得到教训.....而我得到了表扬。

今天，教室里格外安静，试卷一张张发下来。我的心怦怦直跳，手心都冒了汗，眼睛紧紧盯着讲台，生怕听到一个难看的分数。突然，老师念到：“熊茁铭，91分！”什么？我竟然考了91分！这是我第一次跨过90分的大门，喜悦像小泡泡一样从心里冒出来，我差点跳起来。阳光照进教室，窗外的小花随风轻轻点头，像是在为我祝贺；树枝摇晃着，好像也在为我竖起大拇指。 

可就在这时，我忽然发现——一道选择题被老师改错了！要扣掉两分，我的分数就会变成89。刚才的光鲜瞬间暗了下来，心情像从山顶一下子跌进深谷。同桌悄悄看了我一眼，小声问：“你要不要去告诉老师？”我的心开始打鼓：如果不说，我还是91分，能被表扬；可如果说了，分数没了，但我心里踏实。我想了又想，终于下定决心：诚实比高分更重要！ 

下课后，我走到老师办公室门口，手放在门把手上，却迟迟不敢推开。走廊静静的，我能听见自己的心跳。我深吸一口气，咬咬牙，推开门走了进去。话一出口，心里的石头“咚”地落了地。老师看了看题目，微笑着拿起红笔，在91上轻轻划了一道，写上了89。然后她抬起头，温柔地说：“你是个诚实的好孩子，老师要表扬你。” 

那一刻，我得到了表扬，我心里轻松极了，像飞起来一样。虽然手里拿着89分的试卷，可我觉得它比91分还亮。原来，有些表扬不来自分数，而来自一颗诚实的心。

# 我是一只蜜蜂 熊茁铭

我是千万只蜜蜂中的一员，身披黄黑相间的外衣，每日穿梭于花海之间。我们用勤劳的双手建造家园，却一次次被无情的力量摧毁。这，是我变形为蜜蜂后的真实经历。

我身穿黄黑相间的外衣，每天和同伴们一起忙碌地建造蜂巢。我们用辛勤的劳动编织着属于蜜蜂的温暖家园。可是有一天，我正在蜂巢里休息，突然觉得像地震一样，整个巢摇摇晃晃。我赶紧飞出来一看，原来是几个小孩正拿着石头砸我们的家。蜂巢“砰”的一声掉在地上，碎成了好几块。我们还没来得及追上他们，破坏者就跑得无影无踪了。

我们只好重新开始建巢。这次我们选了一个花草繁茂的地方，继续用尽全力搭建。过了几个小时，我看见巢才建到一半，翅膀却被大山蜂压住了。从那以后，我每天不是在采蜜，就是在采蜜的路上。终于，新的蜂巢建好了。我躺在里面，像躺在棉花上一样柔软舒适。那一刻，我感觉自己像一位伟大的工程师，自豪感涌上心头。

蜂巢建好后，生活变得轻松了许多。清晨，我用露珠洗脸；下午，我与伙伴们一起快乐地玩耍。有的比谁飞得快，有的在争论建巢时谁的功劳大，还有的在空中四处闲逛。那段日子是那样宁静而美好。

直到有一天，这份宁静被打破了。一群人开着卡车来到这里。我本以为他们是来游玩的，没想到他们是来砍树的。树木一棵接一棵倒下，连我们住的那棵树也被无情地砍倒。我愤怒极了，用尽最后的力气把毒刺扎进人类的皮肤里。我知道，这将是我生命的终点，但也是我最后的抗争。

当我将最后一根刺扎入人类的皮肤，我知道这是我生命的终点，也是我最后的抗争。我想告诉所有破坏自然的人：每一个生命都在努力生存，每一份劳动成果都值得尊重。蜜蜂虽小，但它们的世界同样有家、有梦、有希望。

# 美（美，藏在细微处） 熊茁铭

美，不只是花儿的香味，也不只是镜子中甜甜的笑容。它是一双手的温暖，是一句话的轻柔，是某个瞬间让你心里亮起的一盏灯。只要我们愿意停下脚步看一看，就会发现——美，一直都在。

那天放学，我值日打扫完，摆好教室的桌椅，已经六点二十分了。我背起书包飞快地往家跑。谁知一不小心被路边的石头绊倒，整个人重重摔在水泥地上。膝盖火辣辣地疼，鲜血直流，泪水也不受控制地滚了下来。就在我又疼又怕的时候，一位叔叔走了过来：“小朋友，你没事吧？”他看见我膝盖上的血，立刻蹲下来说：“别怕，我不是坏人，我背你去前面药店！”我有点犹豫，可腿实在动不了，只好点点头。

叔叔把我背起来，一路小跑到了药店。他认真地向医生说明情况，又拿来碘伏和棉签，蹲在地上，一点一点帮我擦药，动作轻轻的，生怕弄疼我。涂完药，他还把碘伏送给我：“记得每天消毒哦。”说完，他就匆匆离开了。我望着他的背影，小声说了句“谢谢”。那一刻，伤口好像真的不疼了。原来，善良的人，心里藏着最美的光。

美不仅藏在善良里，也藏在诚信里。

还有一次，同桌小张数学考了95分，能得一颗小糖果。我能明显感觉到，他上课比平时专注了许多。可当老师讲到第11题时，他突然低下了头，偷偷看我的卷子，又瞄了一眼黑板。我一看，原来他这道题做错了，老师却打了个勾。他皱着眉，我知道他在挣扎：说，还是不说？说了，糖果没了；不说，心里就不踏实。终于，下课铃响后，他叹了口气，走向办公室。不一会儿，他走出来，脸上的神情像个考了满分的孩子，眼睛亮亮的，嘴角微微上扬。那一刻，我觉得他特别美——不是因为分数，而是因为他选择了诚实。

真正的美不在外表，而在心灵。美是伸出的手，是诚实的心，是平凡日子里悄悄开出的花。我也想成为这样美的人。
