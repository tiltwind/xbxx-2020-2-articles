# 没想到我如此坚持  孙雨轩

太阳当空照，操场上热浪滚滚，我奋力奔跑的身影，至今仍清晰地印在我的脑海里。那时的我，根本没想到，自己竟然可以如此坚持。

那天是学校一年一度的运动会，我参加的是“河上搭桥”比赛。我站在两块砖上，裁判一声哨响，我立刻把手中的砖块向前放好，左脚迅速踏上，再把后面的砖捡起往前递，动作一气呵成。我拼尽全力向前推进，很快就把一班和三班的选手甩在了身后。脚步坚定，呼吸有力，风仿佛都在为我让路。

可渐渐地，手臂开始发酸，双腿像灌了铅一样沉重。汗水顺着额头流下来，后背的衣服早已湿透。我咬紧牙关继续前进，但速度还是慢了下来。就在这时，一班和三班的选手见我落后，立刻加快步伐，一个接一个从我身边超过去。他们脸上露出得意的笑容，我的心里也闪过一丝想放弃的念头——多想停下来歇一会儿啊……

“加油！别停！我们相信你！”突然，一阵响亮的呐喊传进耳朵，像黑暗中的一束光，点燃了我快要熄灭的斗志。那是同学、老师、朋友的声音，汇聚成一股力量，把我从崩溃边缘拉了回来。

我深吸一口气，闭上眼睛稳住心神，再睁开眼时，眼神已变得坚定。我重新加速，手脚配合默契，双手有力地抓起砖块，跨出最大步子，动作快得几乎来不及思考。一块、两块……我像一阵风，再次冲到了最前面。

终于，我冲过了终点线，整个人瘫倒在地，酸痛瞬间席卷全身。那一刻，耳边响起雷鸣般的掌声，笑容也不由自主爬上脸庞。我真正尝到了努力的滋味——是先苦后甜，像一杯浓茶，入口微涩，回味却甘香悠长。我也尝到了胜利的甜头，那是一种用汗水换来的踏实与骄傲。

这一瞬间，不仅定格在运动会上，更刻进了我的生命里，成为我面对困难时最有力的声音：“再坚持一下，你能！”

从此以后，每当我遇到困难想放弃时，那个烈日下的身影总会浮现在眼前，我便会坚持下去。我知道，只要不认输，就没有真的失败。那一刻，我没想到，我竟如此坚持。这一时刻，更让我明白：人生路上，拼过，才无悔。

# 宠物让生活更美好 孙雨轩

宠物，是我生活中最温暖的陪伴。它们不会说话，却用行动默默安慰我、鼓励我，让我在难过时重拾笑容，在孤单时感受温情。尤其是我家那只小乌龟，它虽小小的，却让生活更美好。

那天，天空灰蒙蒙的，我的脚步也像灌了铅一样沉重。刚上完补习班，因为一件小事在同学面前出了丑，满腹委屈憋在心里，一句话也不想说。一进家门，我把书包随手一扔，整个人瘫在床上，连呼吸都变得闷闷的。我机械地走到龟缸前，撒了一点龟粮，眼神空空的，仿佛世界只剩下灰色。

可就在这时，小龟动了。它拼尽全力爬上最高的那块石头，伸长脖子望着我，黑亮的眼睛像是在问：“你怎么啦？”见我没反应，它竟把头猛地缩进壳里，还故意转过身，用屁股对着我，好像真的在赌气。我忍不住“扑哧”笑出声——这小家伙，怎么这么会演？我轻轻挠了挠它的背壳，它立刻扭来扭去，像在跳舞，可爱得让我心都化了。

接着，它滑入水中，绕着石头游了一圈又一圈，像是在表演专属我的水上芭蕾。我把食物挡了一下，它立刻明白了我的意思，急匆匆地游过来，爪子一扒一扒地把粮推到嘴边，吃得认真又满足。吃完后，它就在水里打起转来，一圈、两圈……像个得到冰淇淋的孩子一样手舞足蹈。我坐在旁边看着，嘴角一直往上扬，刚才的难过不知不觉飞走了。

那一刻，窗外的天似乎也亮了些。我就这样静静地看着它，仿佛整个世界都安静了，只剩下我和这只小小的生命。临走前，我轻声说了句：“谢谢你呀，小龟。”然后一步三回头地回到房间。那一晚，我不再纠结于白天的尴尬，心里暖暖的，重新有了向前走的勇气。

原来，让生活变得更美好的，不一定是什么轰轰烈烈的大事。有时，只是一个小小的脑袋从壳里探出来，用湿漉漉的眼睛望着你——那一刻，世界安静了，心也暖了。

# 诚信让生活更美好 孙雨轩

诚信是为人之本。在我的记忆深处，有一件事始终清晰如昨，它让我真正明白了什么是诚实，也让我感受到——原来，诚信真的能让生活变得更美好。 

那天下午，阳光洒在小区的小路上，我正蹦跳着回家，忽然脚边闪过一抹淡绿色。低头一看，竟是一张50元纸币！我左右张望，四周没人。心跳一下子快了起来，我赶紧把钱塞进口袋，转身就想走。可刚迈出一步，心里突然“咯噔”一下：要是失主回来找不着，该多着急啊？也许这钱是用来买文具的，也许是小朋友攒了好久的零花钱……想着想着，我停下了脚步。 

我掏出那张纸币，盯着它看了好久。天啊，50元能买多少支笔、多少本本子呀！这时，我想起曾听过的一个故事：有个孩子捡到钱后主动上交，脸上笑得像花儿一样灿烂。我也想那样笑着，而不是偷偷摸摸地藏起这笔“意外之财”。终于，我下定决心——把钱交给保安叔叔！ 

我慢慢朝保安室走去，脚步沉得像灌了铅。一步，两步，三步……还有三米，两米，一米！我深吸一口气，轻轻推开门。“叔叔，我在1号楼旁边捡到了50元。麻烦您帮忙寻找失主。”我把钱递过去，手心都出汗了。保安叔叔接过钱，笑着摸了摸我的头：“好孩子，你做得对！我马上在业主群寻找失主” 

走出保安室那一刻，我心里的大石头“咚”地落了地。风轻轻吹过脸颊，我的脚步变得轻快起来，整个人像是飞起来了一样。虽然没留下那50元，但我得到了更宝贵的东西——那是内心的坦然，是成长的认可，是诚信带来的温暖与光亮。 

从那以后，我更加懂得：真正的美好，不是拥有多少金钱，而是心中无愧。诚信就像一盏小灯，照亮了别人，也温暖了自己。我相信，只要每个人都守住诚信这份光，我们的生活就会一天比一天更明亮、更美好。

# 铁蛋的愿望  孙雨轩
山脚下的小村庄静悄悄的，月亮挂在漆黑的夜空里，显得格外明亮。家家户户都睡了，只有两盏眼睛还睁着——一个是铁蛋，一个是刚从城里来的表哥。
表哥掏出一本故事书，送给铁蛋当礼物。铁蛋不识字，却好奇地翻了起来。忽然，他看见一页插图上画着一朵七彩的花！“这叫七色花，能实现七个愿望呢！”表哥说。那一夜，铁蛋翻来覆去睡不着。“要是真有七色花，我家就能变好了……”他心里悄悄许愿。
第二天一早，铁蛋就开始找七色花。他在村子里跑了一圈又一圈，可什么也没找到。这时，一个小孩笑着跑过来，手里举着一片涂得五颜六色的三叶草：“看！我找到了！”铁蛋眼睛一下子亮了，一把接过就往家跑。
他兴奋地给表哥看：“快看，是七色花！”  
“你傻啊！这是骗小孩的！”表哥生气地喊。可铁蛋不信，他紧紧攥着那片叶子，跑到草地中央，轻轻撕下一瓣，闭眼许愿：“我希望，家里变得富有，爸爸妈妈不再那么累……”
风轻轻吹过，树叶沙沙响，没人回答他。表哥转身走了，只剩铁蛋孤单地站着。愿望真的会实现吗？他不知道。
后来，铁蛋病倒了，高烧不退。家人咬牙送他去医院。“治这个要很多钱……”他听见大人们低声说话。那些话像石头一样压在他心上。医院里的机器滴滴响，管子缠着手臂，像藤蔓困住了他。他越来越沉默。
一天夜里，他忽然看见一道光。光中浮着一朵七彩的花，还有爸爸妈妈温暖的笑容！“爸！妈！”他猛地起身，冲过去，仿佛挣脱了一切束缚去抓住什么。
也许，他真的抓住了——那朵只在梦里盛开的七色花。

# 那一刻，我为他点赞 孙雨轩

在人生中，总有那么几个瞬间让我忍不住想点赞，也许是朋友的善良，也许是因为自己的坚持。

记得一次学校举行“过河拆桥”比赛，我站在起点，双脚各踩一块砖，右手还拿着另一块。裁判一声令下，我像离弦的箭一样冲了出去，迅速把一班和三班的同学甩在身后。刚开始还不觉得累，

可到了赛道中央，体力开始透支。双腿像灌了铅，每迈一步都像是从泥泞中拔腿而出。心跳咚咚作响，额角渗出细密的汗珠，连呼吸都变得沉重。就在我脚步迟缓的一瞬，对手抓住机会，接连超过我。掌声渐渐不属于我，风也仿佛冷了下来。

我想放弃。反正也追不上了……可就在这时，脑中突然响起一句话：“坚持下去，别给班级丢脸！”那声音像一束光照进灰暗的心底。我咬紧牙关，深吸一口气，重新稳住重心。眼神不再慌乱，而是变得坚定如铁。我加快节奏，一块接一块地铺板、跳跃、回收，动作越来越流畅。一步，两步，三步！我超过了一名选手，又奋力冲刺，终于，在终点前半米处，反超了领先选手！冲线那一刻，欢呼声如潮水涌来。我迎着掌声，也在心底为自己——重重地点了个赞。

除了为自己拼搏点赞，我也曾为他人温暖的举止点赞。

那是一个午后，夕阳斜洒在儿童乐园的滑梯顶上，我和朋友正准备下滑，她忽然停住，指着地面：“你看，有块电话手表！”我们环顾四周，没人认领。她没有犹豫，蹲下身，轻轻捡起手表，拍掉灰尘，认真地说：“失主一定很着急，我们等等吧。”

等了许久仍不见人来，她灵机一动：“也许能联系家长！”她小心翼翼打开手表，拨通了备注“妈妈”的号码。电话接通后，她语气诚恳地说明情况。不到十分钟，一位阿姨匆匆赶来，接过手表时眼眶泛红，连连道谢。那一刻，阳光正好落在朋友身上，她的笑容干净又温柔。我静静看着她，心里悄悄点了一个大大的“赞”。

生活中，总有一些人值得我们点赞——他们或许不张扬，却很真实；不耀眼，却很温暖。从那时起，我也学会了在别人需要时，伸出自己的手，学着成为那个值得被点赞的人。

# 悔 孙雨轩

“悔”，像一道深深的刻痕，留在记忆的年轮上。它不只代表懊恼，更是一种成长的印记。在我还懵懂无知的年纪，有两个瞬间，让“悔”扎进我心里，至今回想，仍觉沉重。

那天早晨，我匆忙地收拾书包，准备上学，却忘了检查蚕宝宝的食盒。下了楼才猛然发现，桑叶已经被吃得干干净净。我焦急地四处张望，眼看时间一分一秒地溜走，上学要迟到了！就在这时，我瞧见路边一株嫩绿的小桑苗，叶子鲜亮，仿佛在向我招手。可细看之下，叶片上泛着一层淡淡的药渍——那是喷洒农药后留下的痕迹。我心头一紧，却又转念一想：也许没事呢？蚕宝宝吃一点不会怎样吧？没再多想，我摘下几片叶子塞进盒子，带去了学校。

刚进教室，蚕宝宝就开始不对劲了。它们扭动的身体渐渐僵直，有的吐出白沫，有的蜷缩成小小的一团，像被冻住了一样。我的心猛地一沉，脑海里突然闪过那片带药的叶子——原来，是我害了它们！那一瞬间，我的眼眶热了。它们那么小，那么弱，只是依赖我活下去，而我，却因为一时的懒惰和侥幸，夺走了它们的生命。我的心像被塞进了一块铅块，沉得抬不起头。那一刻，我真后悔。

还有一件事，也让我久久不能平静。那是个酷热的午后，同学们手里都拿着冰棍，笑声清脆。我站在一边，汗流浃背，心里又羡慕又难过。翻遍书包，连一毛钱也没有。人一多，心一乱，我竟悄悄伸手拿了一根一元的冰棍，假装要买，趁人群拥挤时塞进了口袋。我低着头往外走，心跳快得像要蹦出来。走出店门那一刻，我甚至不敢回头看老板一眼。

可当我咬下第一口，凉意没来，心却烧了起来。脚步越来越沉，仿佛每一步都踩在良心上。我知道，我错了，我也后悔了。

如今，每当我面临选择，总会想起那两条不再蠕动的小蚕，想起那个在烈日下躲闪眼神的自己。悔，不是终点，而是提醒我前行的钟声——它教会我慎重，也教会我诚实。这两个“悔”字，虽苦涩，却让我一步步走向更好的自己。

# 接力赛上的热血与坚持 孙雨轩

那天，阳光像撒了一层金粉，铺满了整个操场。湛蓝的天空一望无际，火红的跑道被晒得微微发烫。全校同学都沸腾了——10×50米接力赛终于开始了！呐喊声、鼓掌声、加油口号此起彼伏，像一首热烈的进行曲，在校园上空回荡。

隔着围栏，各班的啦啦队挥舞着彩旗，跳着喊着。裁判举起发令枪，“砰”的一声清脆响亮，仿佛划破了天际。第一棒选手像离弦的箭，“嗖”地冲了出去！我们班的小温一接到棒就拼尽全力奔跑，汗水顺着脸颊滑落，滴进眼睛也顾不上擦。她紧咬牙关，脸上的肌肉微微颤动，脚步却稳稳向前。一个转身，就把对手远远甩在身后！看台上的我们激动得直跳脚，加油声一阵高过一阵。

前几棒我们咬得很紧，比分交替上升。到了最后一棒，全场气氛紧张得像拉满的弓。小赵站在接棒区，眼神坚定。当第九棒把接力棒交到他手中的那一瞬，他像一头小猎豹猛地冲出！和对手并驾齐驱，谁也不让谁。最后十米！所有人屏住呼吸，心都提到了嗓子眼。就在终点线前的一刹那，小赵咬紧牙关，奋力一跃——率先冲过终点线！

“赢了！我们赢了！”欢呼声如潮水般涌来。同学们冲上去把他团团围住，有的递水，有的塞面包，还有的拍拍他的肩说“太棒了”。那一刻，阳光照在每个人笑出泪花的脸上，仿佛也为我们的团结与拼搏喝彩。

这场比赛让我明白：真正的胜利，不是一个人的冲刺，而是十个人的坚持与信任。那条红跑道，记录了我们的汗水，也点燃了我心中最闪亮的记忆。

# 我的拿手好戏 孙雨轩

宣纸铺开，墨香氤氲，一支毛笔在我手中仿佛有了生命。这，就是我的拿手好戏——毛笔书法。从最初的生涩到如今的从容，每一笔都写着坚持，每一页都浸着汗水。

记得刚开始学写字时，我连笔都握不稳，手腕一抖，墨点就溅上了衣袖。横画歪斜，竖画颤抖，写出来的字像小蚯蚓爬过。可我不服输，每天放学后都挤出时间练习。终于，毛笔书法成了我的拿手好戏。

一次课外书法社举办展示活动，轮到我上场时，心跳不由加快。我深吸一口气，缓缓铺开宣纸，提笔蘸墨，刮去多余墨汁，凝神静气。落笔如风，行笔稳健，笔锋在纸上轻快跳跃。第一个字“红”刚写出，周围便传来低低的惊叹。接着是“豆生南国”，一行行诗句随着笔走龙蛇逐一呈现，墨色流转间引得众人屏息凝视。我运笔时力道均匀稳定，结构饱满舒展，每一个转折都藏着我多年练习的印记。

写到最后一句“愿君多采撷，此物最相思”，我稍稍停顿，再次提笔，笔锋饱蘸浓墨，在纸上轻快跳跃。那“思”字的末一笔舒展飘逸，如风拂柳枝，又似云卷云舒。收锋含蓄，余韵悠长。老师站在一旁连连点头：“进步太大了！这字有骨有肉，更有灵气！”同学们纷纷围上来，眼里闪着光：“你是怎么练的？能教教我吗？”我真诚地向每一位请教的同学分享心得：“起笔要果断，行笔慢慢加力，收笔稍顿再提。但最重要的，是日复一日的练习。”

当掌声落下，墨迹渐干，我望着那幅《相思》，心中涌起的不只是自豪，更是一份沉甸甸的领悟：原来最动人的“好戏”，不在台前的喝彩，而在日复一日伏案练习的静默时光里。毛笔书法就是我的拿手好戏。这一笔一画，不仅写出了字，也写出了我成长的模样。

# 乐（心中有光，便是“乐”） 孙雨轩

你有没有过这样的时刻？一件小事像一颗石子投入心湖，漾起一圈圈温暖的涟漪——那不是惊天动地的大事，却是我心中最清晰的“乐”的印记。

有一回，阳光洒满校园，热风在窗外轻轻游走，教室里弥漫着放学前的躁动。我正准备回家，却看见一位同学仍坐在座位上，眉头紧锁，抓耳挠腮。我走近一问，才知道她因为背不出英语课文，无法离校。看着她焦急的样子，我悄悄坐下来，把我背诵的小技巧告诉了她：“把课文拆成一问一答，先分段记，再连起来背。”她点点头，带着半信半疑走进老师办公室。

我就在门外静静地等，目光追随着她的身影，留意着老师的神情。终于——她出来了！脸上绽开如花的笑容，冲我喊道：“谢谢你！多亏了你的方法！”那一刻，我的心仿佛也开出了一朵花，表面虽平静，内心却早已芬芳四溢。原来，最深的快乐，不是别人给的掌声，而是自己点亮别人的那一刻。

如果说帮助他人是一种无声的喜悦，那么靠自己赢得掌声，则是另一种热烈的“乐”。

记得那次绘画比赛，我格外重视。整整一周，我几乎把所有课余时间都交给了画笔。一笔一划，反复修改，只为在现场画出最好的作品。比赛那天，我心里像揣了只小兔子，跳个不停。画完后回到家，却始终忐忑不安，生怕辜负了大家的期待。直到成绩公布的那一刻，我接过第二名的奖状，手微微发抖——我做到了！那一刻，甜意从心底涌上来，像喝了蜜一般。窗外的鸟儿仿佛在歌唱，天上的云朵好像也在为我鼓掌，老师和同学的笑容，像阳光洒满心田。当我站在领奖台边缘，手中紧握那张沉甸甸的奖状时，我才真正明白，这份“乐”，是汗水浇灌出的果实。

“乐”像一把琴，奏出人心深处的旋律。它不仅是嘴角上扬的弧度，更是心底绽放的一朵花。它藏在伸出援手的瞬间，躲在挥动画笔的坚持里，悄悄告诉我：真正的快乐，是付出时的温柔，也是拼搏后的回响。

# 有你，真好  孙雨轩

记忆像一条静静流淌的小河，而你，是岸边始终守候的树。风吹过时，叶子沙沙作响，仿佛在低语：有你，真好。母亲，这句话，我想轻轻说给你听。

那晚，我伏在书桌前写作业，题目格外难，笔尖在纸上停了又停，心也一点点沉下去。我抓着头发，眉头紧锁，像一只泄了气的皮球，瘫在椅子上。厨房传来锅铲轻响，你在忙碌晚饭，却仍悄悄推开我的房门，轻声问：“怎么了？”可那时我满心焦躁，头也不抬地大声回了一句：“没事啊！”话一出口，空气仿佛凝住了。

你没再说什么，转身离开。我抬起头，看见你轻轻带上门的背影，心里突然空了一下。我以为你会生气，会责怪我不懂礼貌，可你什么也没说。过了许久，门又被推开一条缝，你端着一杯我最爱的苹果汁走了进来，轻轻放在桌上。“喝点吧，别太累。”随后就退了出去。

我捧起杯子，一口一口地喝着，酸甜的滋味缓缓滑过舌尖，像阳光融化了冰霜，连呼吸都变得柔软。那杯果汁，不只是解渴，更像是你无声的拥抱，抚平了我所有的不安。原本紧皱的眉头，终于一点一点舒展开来。

喝完最后一口，我正准备继续写题，你又回来了。妈妈用温柔又略带歉意的语气对我说：“对不起，我不知道你不想被打扰，刚才一定让你更烦了吧？”我猛地抬头，眼眶一下子热了。望着你关切的眼睛，我小声地说：“不……是我对不起你。”那一刻我才明白，真正的爱不是责备，而是理解；不是催促，而是等待。

你坐下来，耐心听我说完难题，提醒我要细心，要冷静，还发现了我自己都没注意到的关键信息。你没有一句批评，只是轻声告诉我：“做任何事，都要静下心来，越急越乱，只有稳住，才能做好。”那一晚，我不只是完成了作业，更学会了一种面对困难的方式。

多年以后，我或许会忘记那天作业的答案，但我永远记得你端来的那杯苹果汁，记得你眼中的温柔。原来最深的爱，不是责备，而是包容；不是催促，而是等待。母亲，有你，真好——这句简单的话，是我一生最想对你说的告白。

# 及时雨 孙雨轩

干旱时的一场雨，寒冷中的一件棉衣，困境里的一句问候——这些都叫“及时雨”。而在我记忆深处，那位默默递来手套的老奶奶，就是我生命中最温柔的“及时雨”。

那天早晨，我去上学。虽然是厦门，可寒冬腊月的风仍像小刀子一样刮在脸上，钻入骨缝的寒意让我不由自主地缩起脖子。更糟的是，我竟忘了戴手套。冷得直打哆嗦，手指僵硬发紫，每走一步都盼着快点到教室。就在我急着往学校跑时，一位老奶奶从街边的小摊后抬起头，皱着眉打量我：“孩子，你脸色都青了，是不是太冷了？”我点点头，低声说忘带手套了，就想赶快赶回学校。

她没再多问，转身从柜子里拿出一双手套，硬塞进我手里。我愣住了，心想：该不会是强买强卖吧？紧张得连连后退：“不……我不买，我没钱。”话还没说完，她就笑了：“傻孩子，送你的，不要钱！天这么冷，别冻坏了手，好好读书最重要。”那一刻，我怔在原地，眼眶一下子热了。

眼看快上课了，我匆匆戴上手套，只来得及说一声“谢谢”，便飞奔向学校。风还在吹，可手心却暖暖的，仿佛有一股暖流涌遍全身。那双手套是用粗毛线一针一线织成的，针脚密实，边缘还有些毛边，摸上去有点扎人，却格外踏实。我不再颤抖，也不再觉得冷，心里沉甸甸的，不是因为沉重，而是被一种从未有过的温情填满了。

放学后，我又悄悄回到那个小摊。老奶奶正低头缝着手套，阳光照在她花白的头发上，手指粗糙却灵巧，戴着顶针一针一针地穿引着毛线。我双手捧着手套还给她，轻声说：“奶奶，谢谢您。”她抬头一笑，温暖又慈祥：“还回来啦？早上没迟到吧？”就这么一句简单的关心，又让我热泪盈眶。

那双手套早已不再使用，可那份暖意却从未褪色。每当寒风再起，我总会想起那位不知名的老奶奶——她不是救世主，却用一针一线织出了人间最朴素的善意。她，就是我心中永不消散的“及时雨”。从那以后，我也成为滋润他人心田的及时雨。

# 一次难忘的讲故事比赛体验 孙雨轩

我人生第一次站上舞台讲故事的时刻，是我最难忘的一次体验，也是一次将永远铭刻在我心中的成长印记。

那天，天空湛蓝如洗，微风轻拂。我参加了一场讲故事比赛。当我被叫到名字时，双腿像灌了铅一样沉重。我缓缓走上台，手心全是汗，话筒都差点滑落。我小声地说：“大……大家好，今天我带来的故事是——《毛毛虫的新衣裳》。”声音轻得仿佛蚊子哼哼。那一刻，我觉得所有人的目光都像钉子一样钉在我身上，仿佛一张张大嘴要把我吞没。

我低着头，手指紧紧掐着衣角，额头上渗出细密的汗珠。就在我几乎想逃下台时，我悄悄抬眼看了看台下——老师正微笑着对我点头，眼神里满是鼓励；前排的小朋友睁大眼睛，专注地等着听故事。我的心忽然一颤：他们不是在等我出丑，而是在等我开口啊！

我深吸一口气，闭了闭眼，再睁开时，努力直视前方。我继续讲道：“毛毛虫把自己吃得胖胖的，它想：我要一件美丽的衣裳！”这一次，声音稳了些。随着故事展开，我渐渐忘了害怕，开始加入手势和表情——说到毛毛虫爬行时，我轻轻摆动手臂；讲到它结茧时，我双手合拢，做出包裹的样子。台下的孩子们发出“哇”的惊叹，还有人忍不住鼓起掌来。

当我讲到毛毛虫破茧成蝶，展开五彩翅膀时，整个礼堂安静极了，仿佛所有人都屏住了呼吸。最后一句说完，我向大家深深鞠了一躬。刹那间，雷鸣般的掌声响起，久久不息。老师笑着说：“你前面有点紧张，可后来越讲越棒，特别自然！”好朋友冲上来抱住我：“你太厉害了！好自信哦！”还有其他班的同学也跑过来说：“你的动作真有趣，我都看入迷啦！”当掌声再次回荡耳畔时，我终于明白：原来勇敢不是没有恐惧，而是带着恐惧依然向前走。 

那一次讲故事比赛体验像一颗种子，在我心里种下了自信与勇气。即使已过去多年，只要站在人群中，我总会想起那束照在我身上的光，和那个终于敢抬起头、大声说话的自己。从此以后，我不再胆怯，而是带着微笑，勇敢迎接每一次挑战。

# 我得到了表扬 孙雨轩

在记忆的星河里，我轻轻划着小船，朝着一颗最亮的星星游去。那光越来越近，渐渐照亮了一件事——那天，我第一次得到了老师的表扬。

清晨，阳光洒进教室，鸟儿在枝头欢快地鸣啭，树叶沙沙作响，像在打着节拍。我们正上语文课，学的是两首现代诗。老师忽然提问：“读了诗里的描写，你们脑海中浮现出怎样的画面呢？”教室一下子安静下来，同学们你看看我，我看看你，有的低头抠笔帽，有的抓耳挠腮，还有的悄悄把书立起来挡住脸，生怕被点名。

就在这时，我的目光落在第一首诗里的一个“云”字上。忽然，我想起一次坐车时，爸爸指着窗外的云说：“你看，这云，多么像是用油画颜料画上去的啊！颜色那么饱满，和天空的边界清清楚楚，真让人心情舒畅！”这句话一下子蹦进脑海。

我心跳加快，手心微微出汗，可还是慢慢举起了手。老师眼睛一亮：“请这位同学来说！”我站起来，声音有点抖，但还是把心里想到的画面说了出来。老师听完，微笑着点头：“说得真好，想象力很丰富，有一种独特的美感！”

那一刻，我脸上装作平静，心里却像开了一朵花，甜滋滋的，像春天里尝到的第一口蜜，从舌尖一直流到心窝里。

更让我惊喜的是，有几个同学也开始小声举手了。看着他们，我心里暖暖的，好像自己也成了点亮别人的光。

那一次，我得到了表扬，也让我迈出了爱上语文的第一步。原来，一句表扬不只是夸奖，更是心里的一颗种子，悄悄发芽，长出勇气和信心。

# 壳里的世界 孙雨轩

我是一只小小的巴西龟，壳上印着鲜艳的图案。可这看似可爱的装饰，却是我一生的枷锁。

从我破壳而出的那一刻起，我就被贴上了“便宜”“好养活”“入侵物种”的标签。我和一群一岁大的伙伴们被固定在一个小框里，只露出脊背。人们在我们的壳上涂颜料、画图案。那个让小朋友开心的图案，却成了我们永远逃不掉的束缚。

我们被关在一个只有小孩拳头大小的塑料盒里，装着一点点自来水。壳上的颜料让我每天都很疼，狭窄的空间让我连四肢都无法舒展。我们像商品一样被摆在地上，没人问过我们愿不愿意，就被强行拉进了一个套圈游戏。

每天都有圈圈从天而降，吓得我胆战心惊。日复一日，我终于等到了那一天——一个小女孩套中了我！她把我带回了家。

在她身边，我原本以为遇见了天使。她帮我洗掉了壳上的颜料，我以为人类并不都是那么坏。可是，她并不真正了解我。她给我买了一个“新手快乐罐”，但我想要的是一个温暖、宽敞、有石头和遮蔽处的家。她总想让我听她的话，让我变成网上那些“听话的小狗龟”。我不喜欢她一直打扰我。有一次，她不停地拍打我的头，说是在我这里找到安慰。我实在忍不住了，就咬了她一口。她尖叫一声，把我摔到了地上。

从那天起，她就再也没管我了。我的家变得又脏又臭，到处都是我的排泄物，石头上长满了青苔。我痛苦地在水里张着嘴，想睁开眼，却睁不开。

我不明白，为什么一出生就被人类标上了价格？我们都生活在地球上，都是生命啊。为什么你们要把我们分成贵和便宜？贵的就珍惜，便宜的就拿来当玩具？生命不是无价的吗？为什么“便宜”的生命就要被折磨，被当成套圈游戏的奖品？

有多少同伴还没被带走就死了，有的吓死了，有的生病死了。不只是我们巴西龟，还有小白兔……它们也一样。

阳光依旧洒进我的小缸，只是我已不再期待明天。曾经的梦想与自由，早已在一次次失望中消散，如今的我，只剩下一具空壳，和一个无法被理解的灵魂。

# 美（心中有光，便是美） 孙雨轩

人们常说，美在山水之间，美在花开花落时。可真正打动我的“美”，却藏在一个陌生叔叔递来的五元纸币里，藏在朋友轻轻捧起一只受伤小鸟的双手间——原来，最美的风景不在远方，而在人心深处。

那天我去买东西，等了好久才轮到我。我伸手往右口袋一摸，心猛地一沉：呀！五元钱不见了！我急得团团转，连忙转身问身后的人：“你们有没有看到一张五元纸币？”没人回应。就在我快要放弃的时候，一位叔叔走了过来，温和地说：“小朋友，我刚才在地上捡到一张五元，是不是你的？”我眼睛一亮，连连点头。他笑着把钱递给我，我连声道谢，付完钱后匆匆离开。

走在回家的路上，我习惯性地摸了摸左边口袋——突然，指尖触到了一张熟悉的纸币。我拿出来一看，正是那张“丢”了的五元！我的心一下子揪紧了：天啊，那叔叔还给我的钱……难道不是我的？我顿时热泪盈眶，心里像被什么狠狠撞了一下。我转身飞奔回去，找到那位叔叔，要把钱还给他。他却笑着说：“只是举手之劳，别放在心上。”那一刻，我忽然明白了，“美”不只是好看的东西，更是藏在善良里的光。

还有一次，兴趣班下课，我和朋友正走着，一只小鸟惊慌地从头顶飞过，几个孩子在后面追着抓它。朋友立刻跑过去拦住他们，轻声哄着小鸟，慢慢把它抱起来。她问我：“要不要先带它回家喂点东西，等它有力气再找主人？”我们小心翼翼地把鸟带回家。它毛茸茸的，比我半个脑袋还大，沉甸甸的，捧在手里暖暖的。朋友用吹风机低档慢慢吹干它的羽毛，还准备了水和小米，又把自己的宠物鸟隔开，怕它们打架。后来她妈妈在小区群里发消息，很快找到了主人。对方想送礼物感谢，全被婉拒了。看着朋友温柔的样子，我心里悄悄说：你真美。

美”是当别人跌倒时伸出手的那瞬间，是默默付出却不求回报的温柔。我想，我也该成为这样的人——不耀眼，却温暖；不张扬，却真实。我要将这份来自平凡生活的“美”继续传递下去。



# 月饼里的团圆味 孙雨轩

“海上生明月，天涯共此时。”每当空气中飘来淡淡的桂花香，夹着一丝暖烘烘的烤饼甜香，我就知道——家乡的中秋节到了。

那年中秋，爸爸系上蓝布围裙，笑着招呼我和弟弟：“今天，咱们自己做月饼！”准备工作就充满烟火气：奶奶提前熬好了红豆沙，红亮油润，舀一勺凑近鼻尖，是绵密的甜香；妈妈调好澄面与麦芽糖熬成的糖浆，琥珀色的汁液缓缓流淌，像凝住的阳光；面粉筛进大盆，雪白轻盈，轻轻一吹，便浮起细雾般的粉尘。

我学着爸爸的样子，把糖浆和油倒入面粉中，再慢慢加水揉团——可这“温柔”的活儿竟不听使唤：水稍多一点，面团软塌塌地黏满手指；水少一点，又干裂得像龟背。我急得直跺脚，额角沁出汗珠，手忙脚乱间还打翻了半罐芝麻，黑亮亮的籽粒滚了一地。弟弟咯咯笑：“姐姐做的不是月饼，是‘芝麻炸弹’！”我撅着嘴，委屈地捏紧衣角，眉头皱成小山包。爸爸却蹲下来，用沾着面粉的大手拍拍我的肩：“别怕，面团和人一样，要多揉几次，才肯听话。”他掌心温厚，话也暖，我深吸一口气，重新挽起袖子，再试一次……第三次，面团终于柔韧光滑，像一块会呼吸的云朵；第五次，我颤巍巍托起一团豆沙馅，轻轻裹进面皮，指尖轻推慢收，圆润如初升的小月亮；第七次，模具“咔哒”一压，花纹清晰浮现——金桂、玉兔、祥云，在饼面上静静绽放。当一盘金黄饱满的月饼排成整齐方阵送进烤箱，滋滋声里升腾起焦糖与坚果的浓香，我踮起脚尖扒着烤箱门，心也跟着暖烘烘地跳。

暮色渐染，圆月悄然攀上梧桐枝头。我们搬出竹榻，摆在院中老桂树下，摆开月饼、蜜桔、清茶。月饼刚出炉不久，咬一口，外皮酥软微韧，内馅温热流沙，红豆沙的醇厚、咸蛋黄的沙香、桂花蜜的清芬在舌尖层层漾开，甜而不腻，香而不燥。

家乡的风俗从不曾只是旧纸上的传说，它是手心的温度，是灶膛的微光，是三代人围坐时碗筷轻碰的脆响。那最浓的滋味，从来不在饼里，而在我们彼此相守的时光里。


# 商场惊魂记 孙雨轩

记忆的夜空里，繁星点点，有的璀璨夺目，有的微光浅淡。而其中一颗，幽暗却灼热——它裹着冷汗、心跳与哽咽，是我六岁那年，在商场迷路时，第一次尝到的“害怕”的滋味。

那天，妈妈牵着我和弟弟的手，穿过旋转门，扑进一片喧闹的海洋：水晶吊灯洒下金粉般的光，自动扶梯嗡嗡地吞吐人流，玩具柜台五彩斑斓，奶瓶货架银光闪闪……我踮脚张望，一眼就相中了角落里那个会眨眼的布偶小熊。妈妈正俯身挑婴儿推车，我悄悄松开她的手，像一滴水滑进人潮，朝小熊奔去。

可等我攥着空空的小手折返，原地只剩晃动的人腿和刺耳的广播声。妈妈不见了！我猛地僵住，耳朵嗡嗡作响，手心湿漉漉的，像攥着两把冰凉的雨。头顶的灯光忽然变得惨白，照得我影子又细又长，孤零零钉在地砖上；货架上的塑料小人咧着嘴笑，仿佛在无声讥讽：“谁让你乱跑？”连空气都凝住了，热闹的笑声、音乐声全被抽走，只剩自己擂鼓般的心跳，“咚、咚、咚”砸在耳膜上。

我蹲在柱子后，眼泪大颗大颗砸在地上，洇开一小片深色水痕。直到一双温柔的手轻轻搭上我的肩——是穿蓝制服的阿姨。她蹲下来，平视着我的眼睛，声音像温热的糖水：“别怕，阿姨陪你找妈妈。”她牵起我汗津津的小手，带我在迷宫般的走廊里穿行。广播里响起清亮的寻人启事，我仰头望着她胸前的工牌，突然觉得那枚小小的金属牌，比所有玩具都亮。

终于，妈妈冲过来，膝盖一弯跪在地板上，一把将我搂进怀里。她发梢沾着汗，声音抖得不成调：“宝贝，妈妈错了……”

回家路上，晚风拂过脸颊，路边的月季摇着红裙，树梢的麻雀叽叽喳喳，仿佛整条街都在为我雀跃。

那一次，我真害怕！如今回想，心口仍微微发紧，可更清晰的，是阿姨掌心的温度、妈妈睫毛上的泪珠、还有那枚在灯光下闪闪发亮的工牌——原来恐惧的尽头，并非深渊，而是无数双伸来的手。成长不是不跌倒，而是学会在迷路时，依然相信光会找到你。


# 未来的家 孙雨轩

小洛一早就盼着去小铃家做客，心里像揣了只小兔子，扑通扑通直跳。刚到空地，她就东张西望：“小铃，你的家在哪儿呀？”话音未落，小铃笑嘻嘻地从口袋里掏出一座迷你小屋，“啪”地往地上一放，清脆喊道：“变大！”——“嗡！”一道淡蓝色光晕闪过，小屋“呼”地舒展成一栋亮晶晶的智能小屋，小洛瞪圆了眼睛，连嘴巴都忘了合上。

推门进去，屋里暖暖的，茶几像云朵般柔软，床铺宽得能打滚。两人刚坐上沙发，一个雪白的机器人管家就滑了过来，头顶的小屏幕一闪：“请问需要什么？”它竟听懂了小洛心里想的“一杯果汁”，转眼就端来两杯冒着泡泡的橙汁，动作轻巧得像跳舞。

更神奇的是装修！只要闭眼想象：粉红墙壁、星星吊灯、会唱歌的地板……再轻轻按下手腕上的“梦想键”，整个房间就悄悄变了样！还有那张“房门贴纸”，薄薄一张，印着木纹门框，往墙上一贴，“咔哒”一声，新房间就诞生啦！出门旅行时撕下来，贴在朋友家墙上，就能“搬”走自己的小卧室呢！

中午到了，小铃和小洛的肚子不争气地“咕咕”叫了起来。话音未落，厨房机器人已经端上了色香味俱全的饭菜，热气腾腾，香气扑鼻。用餐完毕，小洛正想着谁来洗碗，小铃却按下了桌上的“一键洗净”按钮。只见桌面像花瓣一样打开，餐具自动滑入下方的清洁池，一双灵活的机械手迅速挥舞，不一会儿，碗盘就变得光亮如新。这一幕再次让小洛目瞪口呆。

就在这时，外面的天空乌云密布，仿佛沉不住气开始哭泣，狂风也怒号着席卷而来。就在那一瞬间，门窗如同忠诚的卫士般自动紧闭，屋外生成了一层透明的蛋壳状保护罩，将风雨牢牢挡在外面。屋内暖气悄然开启，温度始终恒定在舒适的
24℃至 27℃之间，宛如另一个温暖的春天。

“多有趣啊！”小洛感叹道，“要是我也能拥有这样一个家，该多好呀！它不仅让生活充满便利，更能给那些没有固定住所的人一个温暖的家。”这是小洛经历过的最神奇的一天，科学的翅膀带着她的梦想，飞向了美好的未来。


# 拉着母亲的手 孙雨轩

我紧紧拉着母亲的手走在路上，掌心传来的温度让我感到无比温暖与安定，而这份温暖背后，更藏着我对那件往事深深的愧疚与悔恨。

那是个再普通不过的下午，我和妈妈一起去超市买奶瓶。她蹲在货架前认真挑选，我却悄悄溜开，直奔玩具区。五彩的积木、会唱歌的小熊，一下子把我迷住了。等我抱着新玩具兴冲冲转身，眼前却空荡荡的——妈妈不见了！“呀——”我愣在原地，心跳咚咚响，像要蹦出胸口：妈妈真的把我“丢”了！要是我没贪玩跑开，该多好……

我缩在角落，身子团成小小的一团，连呼吸都轻轻的，生怕自己真被永远留在这里。一位穿蓝制服的阿姨牵起我的手，带我去广播站。我坐在前台椅子上，眼睛一眨不眨盯着墙上的钟：一分钟、两分钟……秒针走得真慢啊！

终于，一个熟悉的身影跌跌撞撞地冲了进来。是母亲！她的头发有些凌乱，额头上布满了细密的汗珠，眼神里满是惊慌与疲惫。看到我的一瞬间，她猛地扑过来，一把将我紧紧搂在怀里，声音颤抖着反复说着：“对不起，对不起，妈妈不该让你走丢……"听着这带着哭腔的道歉，我的眼泪再也忍不住，像断了线的珍珠般滚落下来，小声呜咽着。

回家的路上，夕阳西下，金色的余晖将我们的影子拉得很长，交叠在一起。我偷偷望向母亲，她的眼角还微微泛红，那只大手依旧紧紧地攥着我的小手。我拉着妈妈的手，那手掌宽大而粗糙，却传递着让人安心的力量。路边的草儿轻轻摇动脑袋，仿佛在向我们微笑；树儿沙沙作响，像是在招手致意；空中的蝴蝶翩翩起舞，似乎也在为我们送行。然而，眼前的美景却让我的心情更加沉重。因为我那一时的贪玩，竟让最爱我的人如此担惊受怕。想到这儿，我羞愧地低下了头。

母亲的手很温暖，很安心，拉着它，就像被包裹在柔软的棉花云中，充满了安全感。今后，我再也不会那样任性淘气，绝不会让这双温暖的手再为我增添半分负担。我要一直紧紧拉着母亲的手，走过每一个春夏秋冬。


# 给母亲的信 孙雨轩

亲爱的母亲：

您好！

六年的小学生活，宛如一个五味瓶，装满了酸甜苦辣。那些难忘的瞬间，就像夜空中璀璨的星辰，在我的记忆长河中熠熠生辉，永不褪色。

记得那是一个烈日当空的午后，蝉鸣声声，仿佛在为我们呐喊助威。运动场上，接力赛的运动员们个个神情肃穆，严阵以待。作为班级的一员，我站在跑道旁，手心早已渗出了细密的汗珠，心跳快得仿佛要撞出胸膛。我们班的第一棒小刘，双眼死死盯着前方，身体微微前倾，紧握接力棒的手指因用力而泛白。“预备，跑！”随着裁判一声令下，他如同一只矫健的猎豹冲了出去，风驰电掣般将其他班级的选手甩在身后，顺利完成了交接。

接下来的几棒，大家配合默契，我们与一班、三班始终不相上下，难分伯仲。然而，意外就在第九棒发生时降临了。小徐在递棒给小温的瞬间，脚下一滑，接力棒“啪”地一声脱手落地！那一刻，时间仿佛凝固了，一班和三班的选手趁机飞速超越。看着落后的距离，我的心瞬间沉到了谷底，喉咙像被什么东西堵住了一样，酸涩难忍，那是失败的苦涩与焦急的辛辣交织在一起的滋味。台下的我们屏住呼吸，大气都不敢出，生怕一丝声响都会干扰到场上的同学。

可就在第九棒小徐把棒递向小温时，小温没有片刻慌乱。他迅速弯腰拾起接力棒，眼神中燃烧着坚定的火焰，咬紧牙关，如离弦之箭般飞奔出去。他的每一步都踏得那么沉重又有力，仿佛要将所有的不甘化作前进的动力。观众席上，我们终于爆发出震耳欲聋的呼喊：“小温，加油！”在一班选手即将触线的刹那，小温猛地发力，以身位优势冲过了终点线，奇迹般地扳回了平局！那一刻，紧绷的神经终于放松，喜悦的泪水模糊了双眼，大家蜂拥而上，扶着小温欢呼雀跃，他也自豪地挺起了胸膛，脸上洋溢着胜利的笑容。

母亲，校园里的故事远不止这一件。除了赛场上的惊心动魄，还有平日里训练时挥洒汗水的辛劳，也有遇到挫折时偷偷抹泪的委屈。正是这些酸甜苦辣，交织成了我丰富多彩的童年。无论何时回味，它们都让我感到无比珍贵与快乐。

祝您

天天开心，工作顺利！

您的女儿 ：孙雨轩

# 这一次，我真的很兴奋 孙雨轩

在记忆的长河中，许多往事已随波逐流变得模糊，唯有一件事如同河底璀璨的鹅卵石，至今仍清晰可见。那一次，我真的非常兴奋。

记得那是一个假期，妈妈破天荒地允许我多玩了一会儿平板。当我浏览绘画软件时，一个主题为“绿黄色系”的绘画比赛突然映入眼帘。看着那充满生机的主题，我心中一动：反正时间充裕，不如试一试！于是，我深吸一口气，拿起触屏笔，全神贯注地投入了创作。

我先是用指尖轻轻勾勒轮廓，眼神紧紧锁定屏幕，生怕线条有一丝偏差；接着，我屏住呼吸，细致地勾线、铺色。那一刻，世界仿佛静止了，只有笔尖在屏幕上滑动的细微声响。我将平日里积累的所有功底都倾注其中，每一处光影的过渡，每一抹色彩的晕染，都力求完美。说真的，我从未如此专注过，就连现在的我也难以复刻当时那份忘我的状态。

作品完成后，我满意地提交了画作，转身便去玩贪吃蛇了。虽然对自己的作品颇有信心，但想到参赛高手如云，我心里其实并没抱太大希望，只当是一次普通的尝试。

几天过去，这件事渐渐被我淡忘。忽然，平板屏幕亮起，一条通知弹窗跃入眼帘——我竟然获得了第五十名，还能领取五元奖金！刹那间，一股巨大的喜悦直冲头顶，我兴奋得一蹦三尺高。那一刻，阳台上的花儿仿佛绽开了笑脸为我欢呼，连笼中的鸟儿都在枝头为我歌唱。

我迫不及待地在邮箱中领取了奖励，嘴角怎么也压不住上扬。我在沙发上翻了个身，又跳起来又跑又跳，整个房间都回荡着我的笑声。那一次，我不仅尝到了幸运的滋味，更品到了努力后收获胜利的甘甜。

那一次，我真的很兴奋。它像记忆星空中那颗最耀眼的星辰，永不褪色，令我难以忘怀。更重要的是，它让我明白了一个道理：凡事只要全力以赴，努力的汗水终将浇灌出最美的花朵，结果一定不会让人失望。

# 奔跑中的那束光 孙雨轩

打开相册，回忆如潮水般涌进脑海，我不禁想起了那次难忘的奔跑经历。

那是一个炎热的中午，热辣的阳光炙烤着操场，红色的跑道仿佛都要被晒化了。我们正在进行四百米测试，当我站在起跑线上时，大脑还没完全反应过来，尖锐的哨声便划破长空，所有人如离弦之箭般冲了出去，拼尽全力向前飞奔。起初，我还处在队伍中间，可没过多久，前面的同学便逐渐拉开了与我的距离。我咬紧牙关再次发力追赶，却怎么也追不上。渐渐地，我的速度慢了下来，前方那个身影对我而言变得遥不可及。双腿开始酸痛，仿佛灌了铅一样沉重，每一步都像是在泥沼中跋涉。那一刻，放弃的念头像野草般在心中疯长。我瞥见路旁的三角梅，在烈日下耷拉着脑袋，似乎在嘲笑我的不自量力；就连那只蝴蝶也慌忙乱撞，仿佛在讥讽我此刻狼狈的模样。

就在我意志动摇之际，心底忽然响起了一个坚定的声音：“坚持跑下去，不要放弃！至少，你努力过。”这声音如同一束穿透乌云的阳光，瞬间驱散了心头的阴霾。是啊，结果或许不重要，但拼搏的过程才最珍贵。

忽然，一阵微风吹过，带走了些许燥热，也吹散了我心中的焦躁。耳边的风儿仿佛在轻声呢喃，脚下的草儿似乎在为我鼓掌，连刚才那只蝴蝶也翩翩起舞，像是在为我加油助威。我深吸一口气，调整呼吸节奏，大口喘着粗气，重新摆动手臂，使出全身力气向终点冲刺。我的拳头紧握，牙关紧咬，尽管腿部肌肉阵阵抽搐，但我依然迈着有力的步伐奋力前行。终于，在最后关头，我追上了那个曾经遥不可及的目标，与她并肩冲过了终点线。瘫坐在地上的那一刻，我大口吸气，头晕目眩，双腿也不断向身体发出警报，但我知道，这一切都是值得的。

合上相册，思绪渐渐回笼，脑海中浮现出那张我在终点累得上气不接下气的照片，心中已然做出了决定：今后无论做任何事，都要全力以赴，绝不轻言放弃。

那一次奔跑，不仅定格在照片里，更深深印刻在我的成长道路上，时刻提醒我：唯有努力应对，方能不负韶华。

# 笔尖流淌的暖光 孙雨轩

我书桌上静静插着一支普通的黑色水笔，它虽无华丽的外表，却仿佛在时光中泛着淡淡的金光。每当目光触及，那段温暖的记忆便如潮水般涌上心头，让我的思绪久久不能平静。

那是一次期末考试，教室里弥漫着紧张的气息，同学们的笔尖在纸上沙沙作响。我正埋头答题，笔却突然不出墨了！手心一下子沁出汗水，心里直喊：“糟了！”

我颤抖着手，轻轻敲了敲前桌的椅背，声音小得几乎听不见：“能借我一支黑笔吗？”前桌无奈地回头，低声歉意道：“对不起，我只带了一支。”这句话如同一盆冷水浇灭了我最后的希望，我呆坐在座位上，手足无措，眼眶不禁有些发热。就在这绝望的边缘，左边的林林听到了我们的对话。她几乎没有丝毫犹豫，迅速从笔盒中抽出一支崭新的水笔，转身向我伸出了援手。

“给！”她的动作轻柔而坚定，眼神中满是鼓励与信任。那支黑笔递到我手中时，带着她掌心的温度，握感踏实而温暖。刹那间，我觉得这支普通的黑笔仿佛真的在闪闪发光，那光芒不仅照亮了试卷，更驱散了我心中的阴霾。我深吸一口气，握紧这笔，奋笔疾书，笔下的文字如行云流水般倾泻而出。

随着倒计时归零，考试结束的铃声响起，同学们纷纷涌出教室讨论题目。我郑重地将那支黑笔递还给林林，真诚地道谢。林林却挂着甜美的微笑，轻轻摆手说：“不用还了，这支笔送给你吧！反正我还有很多，况且接下来的科学考试也要用到黑笔呀。”说完，她冲我调皮地眨了眨眼。此时，窗外的阳光柔和地洒在她身上，连飞舞的蝶儿似乎也在为她伴舞。她轻声说道：“加油！相信你能考出好成绩！”那一刻，一股暖流涌遍全身，我用力地点了点头，将这份感动深深铭记。

如今，这支笔静静躺在我的笔筒里，笔身已有些磨损，但每次看见它，那束光仿佛又亮了起来——原来，真正的光不在笔上，而在愿意伸手的人心里。未来，我也要成为那样一束光，悄悄亮起，温暖别人。

# 感恩有你 孙雨轩

那一次，你向我伸出的援手，如同一束光，照亮了我记忆深处最温暖的角落。那段经历令我刻骨铭心，千言万语汇成一句：感恩有你——小林。

那是一个傍晚，放学铃声刚响，老师便委托我将全班厚重的校本抱到办公室。我双手紧紧搂着书堆，哼哧哼哧地挪上楼梯。就在即将抵达二楼转角时，脚下一滑，整个人重重地绊倒在台阶上。膝盖传来一阵钻心的剧痛，怀中的校本更是“哗啦”一声散落一地，凌乱地铺满了阶梯。

那一刻，我的心猛地揪紧了，脑海中一片慌乱：“完了，这么多书怎么捡得完？要是耽误了时间，老师会不会批评我？”无助与焦急像潮水般涌来，我呆呆地看着满地狼藉，手足无措。就在这时，一双温暖的手扶住了我的胳膊。抬头一看，是小林！她关切地问道：“怎么这么不小心？别急，我们一起弄！”原来，她正要离开，听到楼上传来的动静，便特意折返查看。

我急得像热锅上的蚂蚁，小林却二话不说，自告奋勇地帮我整理。只见她熟练地拾起一本本校本，整齐地码放在空地上，很快便堆起了一个小小的“书山”。在她的感染下，我也振作精神，加入其中。不一会儿，散落的书本便被我们集中叠好。

小林细心地将校本分成两份，毫不犹豫地抱起较重的那一摞，向三楼走去。我跟在她身后，望着她的背影，夕阳的余晖洒在她身上，仿佛为她镀上了一层金色的光晕，显得格外美好。她将作业稳稳地放入柜子，又转身帮我把剩下的一份也摆放整齐，这才神气地走出办公室。跟在她身后，我的心里暖流涌动。一路上，路边的小花儿摇曳着身姿，仿佛在向小林鞠躬致谢；墙角的爬山虎鼓着小手掌，似乎在为这份友谊鼓掌喝彩。若不是小林及时出现，我不知要在冷清的楼道里难受多久。

小林，感恩有你。在这六年的时光里，正是因为有你这样并肩同行的伙伴，我的小学生活才如此多彩。今后，我也要像你一样，做一个“雪中送炭”的人，将这份温暖与爱心传递下去，帮助更多需要帮助的人。

# 我的理想 孙雨轩

有的人的理想是成为一名教书育人的老师，有人的理想是成为一位逆火而行的消防员。而我的理想有些特别——我想成为一名异宠兽医，守护那些奇特小生命健康。

这个理想，是从我家那只“电饭煲龟”生病开始的。它圆滚滚、灰扑扑，壳上还带着几道浅浅的纹路，像披着一件小铠甲。可有一天，它总缩在角落，连最爱的虾干都不理了，呼吸也变得又慢又重。爸爸说：“怕是得了肺炎。”对小龟来说，这可是要命的病！

我们赶紧带它去了岛内的宠物医院。那里没有刺鼻的消毒水味，反而飘着淡淡的薄荷香和青草气。我攥着龟盒坐在等候区，心咚咚跳得比乌龟爬得还快。轮到我们时，医生轻轻托起它，一边问：“在水里会伸头呼吸吗？最近爱晒太阳吗？”一边用听诊器贴在龟壳上听。做完检查，果然确诊肺炎。医生开了药，还教我们用针管一点点喂水喂药，把龟放在湿润的苔藓垫上静养。

几天后，小龟第一次探出脑袋，慢悠悠爬向窗台，迎着阳光伸长脖子——那一刻，我忽然下定决心：也要成为一名异宠兽医，帮那些奇特的小生命恢复健康，不让主人难过。

当然，光有理想是不够的，更要付诸行动。从那以后，我开始如饥似渴地探索动物世界的奥秘。在家里，我成了乌龟的“专职观察员”，记录它每一个奇怪的动作，琢磨这些动作背后的含义，甚至尝试用特定的节奏敲击缸壁与它“交流”。在图书馆和网络中，我更是像一块海绵，贪婪地汲取着知识。甚至把零花钱攒起来买了本《小宠健康手册》。

通往理想的道路或许漫长，但我愿用热爱做灯，以努力铺路。我要一步步靠近那个目标，成为一名能听懂“异宠”心声的医生，守护这些小生灵的健康。我相信，只要坚持不懈，总有一天，我会穿上那身洁白的制服，实现我的理想。

# 一项特别的作业 孙雨轩

从小到大，我经历过许多特别的事，它们如同夜空中闪烁的繁星，数也数不清。而在这些璀璨的星辰中，有一颗最为耀眼——那是一项与众不同的作业：亲手包饺子。

记得那是一个暑假的午后，老师在群里布置了一项特殊的实践作业。包饺子？这可是我的“弱项”，以往我包的饺子总是歪瓜裂枣，惨不忍睹。正当我犹豫退缩时，父亲却笑着拉我来到厨房，鼓励我大胆尝试。

厨房里热气腾腾，白雾缭绕，空气中弥漫着面粉和肉馅的清香。桌上摆满了琳琅满目的食材：洁白的面皮、鲜红的肉馅、翠绿的葱花，仿佛在等待一场盛大的演出。我学着样子，拿起一张面皮，沾水、加馅、压紧，手忙脚乱地包出了一大盘“怪胎”。它们一个个挺着圆滚滚的“啤酒肚”，像喝醉了酒的大叔，懒懒散散、歪七扭八地瘫在盘子里，惹得我不禁泄了气。

看着这一盘失败的“作品”，失落感涌上心头，我把擀面杖一扔，想打退堂鼓。这时，父亲走了过来。他没有责备我，而是温和地拿起一张面皮，眼神里满是鼓励与耐心。只见他手指灵活地翻飞，轻轻一捏，一个饱满精致的饺子便诞生了。他看着我，语重心长地说：“孩子，谁都有失败的时候，这没什么大不了。只要多练习，找对方法，总会成功的！”

听了父亲的话，我重拾信心，再次拿起面皮。这一次，我仔细观察父亲的动作，模仿他的手势，小心翼翼地控制馅料的分量。渐渐地，我手中的饺子不再“醉酒”，而是变得精神抖擞。终于，我包出的饺子从“啤酒肚大叔”变身成了一个个昂首挺胸的“标杆兵”，整齐地排列在盘中，仿佛在向我致敬。

当热气腾腾的饺子出锅时，浓郁的香味瞬间填满了整个厨房。咬上一口自己亲手包的饺子，鲜美多汁，我心里甜滋滋的。父亲笑着对我说：“你看，只要肯努力，就没有做不好的事。”我点点头，若有所思。

这项特别的作业，不仅让我学会了包饺子，更让我明白了一个受用终身的道理：无论是学习上的难题，还是生活中的挑战，只有付出努力与坚持，才能收获成功。今后，我也将带着这份感悟，在成长的道路上勇往直前，不轻言放弃。

# 美好的瞬间 孙雨轩

生活中有许许多多的美好瞬间，小林向我伸出的援助之手，不仅解决了我的燃眉之急，更定格成了我记忆中最美好的瞬间。

那是一个寻常的午后，放学铃声刚响，老师便委托我将一摞校本抱到办公楼旁的柜子里。我哼着小曲，脚步轻快地穿梭在楼梯间，心中满是完成任务的轻松。然而，就在转角处，意外突生——我的左脚绊住了右脚，整个人瞬间失去了平衡，“扑通”一声重重地摔在台阶上。怀中的书本也随之“哗啦啦”散落一地，像是一群受惊的白鸽，凌乱地铺满了阶梯。

看着满地的狼藉，我心急如焚，仿佛热锅上的蚂蚁，不知所措。就在这时，原本已经下楼的小林同学听到了动静，循声折返。看到这一幕，她二话不说，放下书包，快步走到我身边。她先是用那双温暖的手将我拉起，眼神中满是关切：“没事吧？疼不疼？”得知原委后，还没等我开口请求，她便自告奋勇地弯下腰：“别急，我来帮你！”我摆手想要拒绝，不想麻烦她，可她已经利落地抓起几本校本，整齐地码放在宽敞的台阶上，埋头干了起来。看着她坚定的背影，我无奈又感动地摇摇头，也赶紧加入其中。

夕阳的余晖透过窗户洒在楼梯间，给整个画面镀上了一层金色的柔光。小林的动作娴熟而轻柔：她先是蹲下身，双手环住一叠书，稳稳地抱起；接着又迅速弯腰，将散落的书页一一归拢。她的额角渗出了细密的汗珠，在金光下闪闪发亮。那一刻，时间仿佛慢了下来，我清晰地看见她专注的神情，听见书本摩擦发出的轻微声响，感受到空气中流淌的暖意。这不仅仅是捡书的过程，更是一幅动人的画卷。不一会儿，零散的书本就重新堆成了一座整齐的“小山”。看着她略显单薄却充满力量的背影，心中的焦虑早已烟消云散，取而代之的是一股暖流。

那个瞬间，小林伸出的手、关切的眼神以及夕阳下的剪影，深深地印刻在我的脑海里。这份美好，源于同学间无私的互助，更源于一颗真诚善良的心。从那以后，我也立志要成为像小林一样的人，在别人需要时伸出援手，将这份温暖与力量继续传递下去。

# 跨越自己 孙雨轩

那一次的经历刻骨铭心，因为它见证了我如何跨越了自己。

记得那是一个烈日当空的上午，体育老师宣布进行四百米测试，并严肃地说道：“成绩不到 1 分 27 秒的同学必须重跑。”这个数字对我而言，简直就是一堵不可逾越的高墙，因为我目前的最好成绩也才 1 分 31 秒。

还没容我平复紧张的心情，哨声骤然响起。同学们瞬间如离弦之箭般冲了出去，队伍很快拉开了距离。看着前方的人影越来越远，我的心跳快得像在打鼓。才跑完一圈，双腿便像灌了铅一样酸痛无比。抬头望向远处的终点，第一名即将撞线，而我却还在弯道挣扎，甚至身后的人也渐渐提速追了上来。绝望感涌上心头，路边的三角梅仿佛在摆手嘲笑我的狼狈，蝴蝶在空中乱撞似在讥讽我的无力，连枝头的鸟儿也在叽叽喳喳地起哄。

喉咙里像着了火，每一次呼吸都带着血腥味，沉重的喘息声在耳边回荡。一个声音在心里疯狂叫嚣：“停下来走两步吧？真的坚持不住了！”但我随即又否定了自己：“不，绝不能放弃！一旦停下就前功尽弃了！”我猛地闭上眼，咬紧牙关，强行调整急促的呼吸，双臂用力摆动，榨干体内最后一丝力气。我超越了刚才反超我的同学，向着终点发起最后的冲锋。老师的手臂高高举起，开始倒计时："10 秒、9 秒、8 秒……"我急得像热锅上的蚂蚁，就在老师的手即将放下的刹那，我拼尽全力冲过了终点线。

我一下子瘫坐在地上，大口贪婪地吸着空气，酸胀的双腿不停地向我抗议。但当我得知自己终于首次跨过及格线时，那股狂喜瞬间淹没了身体的疼痛。休息片刻后，我像一只快乐的小兔子，蹦蹦跳跳地坐到了石阶上。那一刻，我不仅尝到了胜利的滋味，更品到了战胜自我的甘甜。

那一次，我真正地跨越了自己。从那以后，每当我遇到困难想要放弃时，总会想起那个烈日下的奔跑，它赋予我坚持下去的勇气与力量。

# 这就是幸福 孙雨轩

幸福是什么？是困境中伸出的一双援手，是迷茫时送来的一句暖语。那一次，小林在我最无助时挺身而出，让我真切地感受到了——这就是幸福。

那是一个夕阳西下的午后，老师吩咐我将厚重的校本搬至办公室的柜子里。我双手紧抱书堆，哼哧哼哧地挪着步子。刚走到楼梯转角，脚下一滑，“哗啦”一声，我重重地摔在地上，书本散落一地。看着满地的狼藉，我又疼又急，心里像揣了只兔子怦怦直跳，更怕耽误时间被老师责备，简直成了热锅上的蚂蚁。

就在这时，寻声而来的小林看到了这一幕。她二话不说，快步上前将我拉起，关切地问：“摔疼了吗？别急，我们一起收拾。”听着她温柔的话语，我心头的焦急瞬间消散了一半，取而代之的是一股暖流。还没等我开口拒绝，小林已自告奋勇地蹲下身，双臂环抱，熟练地将散落的书本一本本码好。只见她眉头微蹙，眼神坚定，额头上渗出了细密的汗珠，却丝毫没有停歇的意思。看着她忙碌的身影，我也赶紧加入其中。

不一会儿，小林臂弯里的书就堆成了一座摇摇欲坠的“小山丘”。她小心翼翼地将书暂放在宽敞处，又转身去搬剩下的。此时，金色的余晖洒在走廊上，给小林的身影镀上了一层柔和的金边。望着她专注的侧脸，我恍惚觉得她在闪闪发光，那是善良与热心交织出的光芒。

我们将书合力搬运下楼，确认没有遗漏后，小林主动将书分成了两堆，毫不犹豫地抱走了较重的那一份。我不甘示弱，抱起剩下的小堆紧跟其后。到了办公室，她先将大堆书整齐地码进柜子，又转过身，接过我手中的书一并放好。做完这一切，她冲我调皮地眨眨眼，神气地走出了门。望着她离去的背影，我在心底默默为她点了个大大的赞。

那一刻，我明白了幸福的真谛。幸福不仅是被帮助的感动，更是心中种下的善意种子。从那以后，我也渴望成为像小林那样的人，在他人遇到困难时及时伸出援手，让这份温暖传递下去。这，就是幸福。

# 风景这边独好 孙雨轩

小学六年的时光，宛如夜空中璀璨的繁星，数也数不清。而在这些闪烁的记忆中，有一处风景比三潭映月更动人，那便是——风景这边独好。

记得那次 400 米测试，太阳毒辣辣地炙烤着大地，热浪滚滚。随着体育老师一声令下：“预备，跑！”同学们如同离弦之箭般冲了出去，个个拼尽全力。然而，就在第一圈即将结束时，跑在首位的小林不慎左脚绊右脚，重重地摔在地上，膝盖和手掌瞬间擦破了皮，渗出了血丝。此时，刚刚超越几名对手的小文猛地刹住脚步。她回头看了一眼终点，又望向痛苦倒地的小林，眼神中闪过一丝犹豫：是继续冲刺争取好成绩，还是停下帮助同学？仅仅是一刹那的迟疑，她便毅然转身，向着小林跑去。

小文快步来到小林身边，小心翼翼地将她扶起，让小林的手臂搭在自己的肩头，轻声问道：“你怎么样？还能走吗？”小林因剧痛还未缓过神来，直到膝盖火辣辣的疼痛夹杂着肌肉的酸痛直钻心底，她才回过神来。她大口喘着粗气，强忍着痛楚答道：“没事，我没事。”小文没有多言，只是更加用力地搀扶着她，一步一步缓慢而坚定地向终点挪去。向老师说明情况后，她又一路护送小林去了医务室。

到了医务室，当碘酒棉球触碰到伤口时，刺痛感让小林不禁倒吸一口凉气。小文在一旁温柔地安慰道：“忍一忍，马上就好了。”包扎完毕后，小文扶着小林来到石阶上休息。那一刻，阳光洒在小文身上，仿佛给她镀上了一层金色的光晕。她就像一位拯救困境的英雄，连周围的景物都为之动容：鸟儿在枝头为她歌唱，蝴蝶在花丛中为她起舞，花儿竞相绽放笑脸，就连墙角的爬山虎似乎也都在向她招手致意。

这儿的风景独美。它不是夕阳西下的壮丽，也不是昙花一现的惊艳，而是小文搀扶同学时那温暖的身影。这道善良的风景，深深烙印在我的心中。今后，我也要像小文一样，在别人需要帮助时伸出援手，将这份温暖与爱不断传递下去，让生活中处处都有这般独好的风景。
