# 温暖的街道      洪凯跃
傍晚的街道被夕阳染成橘红色，寒风却毫不留情地钻进每一个行人的衣领。人们裹紧大衣匆匆赶路，像一群沉默的影子在冷风中穿行。枯黄的树叶贴在水泥地上，整条街显得灰蒙蒙的。陆天刚放学，双手冻得通红，他不停地向手掌哈气，白雾一缕缕升腾，可寒意依旧从指尖蔓延到全身。他缩着脖子，一边走一边小声抱怨：“作业怎么这么多啊……”
走到路口时，红灯亮起，人群停下脚步。就在这短暂的静止中，一位老奶奶被自己推的购物车绊倒了，重重摔在地上。塑料袋散落一地，苹果滚到了路边。可来往的人流只是匆匆瞥了一眼，便低着头快步走过。
陆天的心猛地揪了一下。他咬了咬嘴唇，犹豫了一瞬——要不要去？可看着老人痛苦地蜷缩着，他再也顾不上寒冷，猛地抽出还暖着的手，冲了过去。
“奶奶，您没事吧？”他蹲下身子，声音有些发抖，不知是因为冷，还是紧张。他用力扶住老人的手臂想把她拉起来，可老人腿上一阵剧痛，根本站不住。陆天使出全身力气，手臂和肩膀都在微微颤抖，却只能让老人稍稍挪动。
就在他几乎要绝望时，一抹熟悉的红色闯入视线——是志愿者徐明！那人穿着红马甲，快步跑来，脸上带着沉稳的笑容。“别急，我来帮你。”他蹲下身，轻声说，“我数一、二、三，我们一起用力。”
陆天用力点头。
“一、二、三——用力！”
两人同时发力，老人终于慢慢站了起来。陆天小心地搀扶着她，徐明则把散落的蔬果一一捡起，放回购物车。他们一起陪着老人来到附近的社区医院。医生检查后说伤势不重，只需休息几天。听到这话，陆天才长长舒了一口气。
走出医院时，夜幕已悄然降临。路灯一盏接一盏亮起，昏黄的光洒在湿冷的地面上。风依旧刺骨，但陆天却觉得手心热乎乎的，他不再把手塞进衣服里，而是自然地垂在身侧。
父子俩并肩走在回家的路上。陆天抬头看了看父亲，嘴角扬起一丝笑意：“爸，我今天帮了人，感觉这条街，好像也没那么冷了。”
徐明轻轻拍了拍他的肩，没说话，眼里却闪着温柔的光。

# 成长的滋味 洪凯跃

在我的记忆里，有些往事像风中的沙粒，轻轻一吹就散了；而有些却如深埋心底的种子，在某个阳光洒落的清晨悄然发芽。那一次，我尝到了成长的滋味。

那天傍晚，夕阳把小路染成金灿灿的颜色，我哼着歌走在回家的路上，脚步轻快得像只蹦跳的小鹿。忽然，一张被风吹起的纸片吸引了我的目光。我定睛一看，竟是一张钱！我赶紧一脚轻轻踩住，左右张望，没人注意到我。我弯下腰，假装系鞋带，悄悄把钱捡了起来。

一开始我以为是一元，可仔细一瞧——天啊，是五十元！我的心“咚咚”直跳，像有只小兔子在胸口乱撞。我可以买一大袋糖果，还能买新笔和本子……想到这儿，我差点笑出声。可就在这时，我看见前面那位阿姨一手拎着一袋菜，一手攥着零钱，正急匆匆地往前走。一定是她掉的！

我攥着钱，手心微微出汗。还？还是不还？“拿去吧，反正没人知道！可这是阿姨买菜的钱啊，她多辛苦！这时，妈妈的话突然在我耳边响起：“做人要诚实，诚信是为人之本”我的心猛地一颤。

我咬咬牙，转身朝阿姨追去。“阿姨，您的钱掉了，还给您！”我摊开手掌，那张皱巴巴的五十元静静躺在手心。阿姨愣了一下，随即露出温暖的笑容，摸了摸我的头：“孩子，你真棒！没被金钱蒙住眼睛。”那一刻，我心里像洒满了阳光，甜滋滋的。

如今每当我面对选择，心里总会浮现出那个拎着菜、匆匆前行的背影，还有我攥着五十元钱时剧烈跳动的心。那一次，我没有让贪念占据上风，而是选择了诚信。原来，是在某个无人看见的角落，你依然选择了光。
