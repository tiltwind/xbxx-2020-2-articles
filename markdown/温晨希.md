# 没想到我如此坚持 温晨希

人的一生总会遇到挫折。面对困难时，有人选择退缩，有人选择放弃，而我却没想到，自己竟然可以如此坚持。

那天阳光炽热，操场上滚烫的空气扑在脸上。我站在起跑线上，哨声一响，我如离弦之箭冲了出去，脚步轻快，风在耳边呼啸。起初的领先让我信心满满，可才跑过半圈，灼热的阳光仿佛压了下来，呼吸开始变得急促，双腿也渐渐沉重起来。就在这时，一个身影从我身旁一闪而过，紧接着又是另一个、第三个……眼看被不断超越，我的心猛地一沉：不行了，真的太累了……要不，就这样算了吧？

还剩六十米时，我的腿像灌了铅，每抬一步都像踩在泥沼里。喉咙干得发烫，胸口像被石头压住，几乎喘不过气来。放弃的念头一次次冒出来，可就在这最疲惫的时刻，耳边突然传来熟悉的声音：“加油！马上就追上了！”“别停下，再拼一下！”那一声声呐喊，像暖流注入冰冷的身体，点燃了我快要熄灭的斗志。

我咬紧牙关，脑海里只剩下一个声音：再迈一步！哪怕慢一点，也不能停！我拼命摆臂，脚掌重重砸在跑道上，一步、又一步地向前跃进。老师的声音清晰传来：“只剩下最后五十米了！坚持住！”那一刻，我仿佛看见终点线上有一道光在召唤。

五十米、四十米、三十米……我咬着牙加速，超过了一个、两个、三个！身体早已不听使唤，可心中的鼓点却越来越响。终于，我大跨一步，冲过了终点线！

整个人瘫软下来，胸口剧烈起伏，汗水滑进眼角，火辣辣的疼。可心里却像被阳光照透一般，明亮又舒坦。原来，真正的胜利不是跑得多快，也不是超过多少人，而是当我想放弃时，却没有停下脚步。

当脚步踏过终点线，世界仿佛静止了一瞬。身体虽已虚脱，灵魂却前所未有地昂扬。原来坚持不是一声呐喊，而是每一次快要倒下时，还肯再抬一次腿。从那天起，我知道了：最亮的光，往往来自咬紧牙关那一刻心底燃起的火。

没想到我如此坚持，从此以后，每当我遇到困难想退缩，眼前总会浮现出那个身影。提醒我：哪怕步履沉重，只要心中的鼓点未停，我就绝不停下脚步。

# 没想到我如此能干  温晨希

夜幕悄悄降临，晚饭后的厨房还弥漫着饭菜的余香。我正想着看会儿动画片，妈妈却笑着递来一条围裙：“试试洗碗吧？”那一刻，我还完全没想到，这个看似平常的小任务，竟让我没想到自己如此能干。

我穿上围裙，套上袖套，站在洗碗池前，心里直打鼓。虽然常看奶奶洗碗，可自己动手还是头一回。我深吸一口气，拿起抹布，挤上一点洗洁精，泡沫立刻冒了出来，像一朵朵小白云。我先拿过自己的不锈钢碗，按照妈妈教的方法，一手托住碗底，另一只手攥紧抹布，细细擦洗。碗里的饭粒黏糊糊的，我轻轻刮、慢慢搓，终于把它们都赶跑了。可当我换到玻璃碗时，手心直冒汗，碗一沾水就打滑，好几次“哐”地掉进洗碗池，吓得我心跳加快。

“别怕，多试几次就好了。”妈妈轻声安慰。我听了妈妈的鼓励，重拾信心，深深吸了口气，再次拿起玻璃碗。这一次，我放慢动作，手指稳稳扣住碗沿，抹布贴着内壁轻轻转动，一圈又一圈，连角落里的油渍也不放过。水流哗哗响，泡沫飞溅，像在为我加油。渐渐地，我的动作熟练起来，碗一只接一只被清洗干净，整齐地摆放在沥水架上，亮晶晶的，映着灯光，像一面面小镜子。

奶奶走过来，笑眯眯地说：“哎哟，这孩子真能干！”妈妈也点点头：“第一次就这么棒，真不简单！”听到夸奖，我心里像灌了蜜一样甜。我不再犹豫，主动把筷子、汤勺、盘子全都收拾过来，一一洗净。直到看到锅太重太难刷，我才停下来。但那一刻，我已经不再是那个只会依赖别人的孩子了。

当我把最后一个碗放进橱柜，手指还带着水珠的清凉，心里却燃起了一团暖火。原来成长不是一声响亮的宣告，而是在一次次“我能行”的尝试中悄悄扎根。我望着闪闪发亮的碗碟，轻轻笑了：没想到，我如此能干。

# 这一精彩时刻带给我的影响  温晨希

在成长的路上，总有一些瞬间如星辰闪烁，虽短暂却照亮了前行的方向。而有这样一个精彩时刻，给我带来了深远的影响。

那天阳光炽热，老师宣布要测试四百米跑。同学们顿时唉声一片，我的心跳早已加快。哨声一响，我像离弦的箭般冲了出去，起步领先，信心满满。可风迎面扑来，像无形的手推着我后退，奔跑变得越来越吃力。

第一圈刚过，身后一个身影迅速逼近，从我身旁一闪而过。我心里一紧：要被超过了！还剩六十米时，双腿像灌了铅一样沉重，呼吸急促，喉咙发烫。又有三位同学接连超过我，我几乎想要停下——太累了，算了吧……

就在这时，耳边传来一声声呐喊：“加油！马上就追上了！”“再加把劲啊！”那声音像一股暖流注入身体。我咬紧牙关，脑海里只剩下一个念头：往前冲！我拼命摆臂，脚掌重重砸在跑道上，一步、又一步地向前跃进。老师的声音也清晰起来：“快点！十八秒，二十秒……”我知道，终点就在前方！

五十米、四十米、三十米……我拼尽全力冲刺，超过了一个、两个、三个！终于，我大跨一步，冲过了终点线。整个人瘫软下来，胸口剧烈起伏，汗水滑进眼角，火辣辣的。可心里却像被阳光照透一般，舒坦极了。

当我跨过终点线的那一刻，身体几乎虚脱，但内心却燃起一团火——那是不屈服的光。从此以后，每当我遇到困难想退缩时，耳边总会响起那一声声“加油”，提醒我：只要再迈一步，就能看见希望。原来，真正的胜利不是超越别人，而是没有放弃自己。

这一精彩时刻带给我的影响，远不止一次跑步的成绩，它让我懂得：坚持，是通往成长最坚实的脚步。

# 诚信让生活更美好 温晨希

“言必行，行必果。”诚信是中华民族的传统美德，也是一笔看不见却无比珍贵的财富。它像一缕阳光，悄悄照亮我们的生活。诚信，真的让生活更美好。

那天下午，我和补习班的同学一起走在去上课的路上。路过一个水果摊时，看见一位头发花白的老爷爷正独自守着摊子，在烈日下擦着汗。忽然一阵风刮过，一张二十元的纸币被吹到了斑马线上。我眼疾手快，跑过去用脚轻轻踩住，假装系鞋带，顺势把钱塞进了口袋。便快步向前走，朋友好奇地问：“你走干嘛那么快？离上课时间还早呢。”我偷偷一笑，小声说：“我捡到钱了，等会儿请你吃好吃的！”她立刻皱起眉头：“应该还给爷爷，诚信最重要！”我愣住了，心一下子乱了。

攥着那张纸币，我的手心直冒汗。拿去买零食多好啊，可转头看见老爷爷弯着腰整理水果的身影，我心里又沉了下来——这钱也许是他的早餐钱，也许是要给孙子买糖的……想到这儿，我咬咬牙，转身朝水果摊跑去。

我站在摊前犹豫不决，老爷爷看出了我的紧张，轻声问：“小朋友，怎么了？”我鼓起勇气说：“爷爷，您的钱掉了。”他一摸口袋，惊喜地说：“哎呀，真是谢谢你！你这么诚实，送你个苹果！”说着，硬是往我和朋友手里各塞了一个红红的大苹果。

咬一口，甜汁在嘴里绽开，心里那块大石头也终于落了地。原来，诚实不只是对别人负责，更让自己踏实快乐。

那个苹果很甜，甜得不只是舌尖，更是心里。原来，守住诚信的那一刻，阳光都变得更暖了。从那以后我明白，不是所有选择都会带来好处，但唯有诚信，能让生活真正变得美好。

# 花开的声音 温晨希
春风拂过校园，丁香花在微风中轻轻摇曳，淡紫色的小花簇拥成团，香气如细丝般缠绕鼻尖。阳光洒在花瓣上，仿佛为这宁静的午后镀上了一层温柔的光晕。可就在这如诗如画的时刻，一声“咔嚓”打破了寂静——那棵陪伴学校几十年的老丁香树，竟被压断了一根枝条。而站在树下的，正是全校闻名的淘气包张明。
那天下午，六年八班正在操场旁打扫卫生。同学们低头认真清扫落叶，唯有淘气包张明悄悄溜向远处那棵最茂密的丁香树。他仰头望着树梢上那朵最大、最饱满的花，心里突然冒出一个念头：要是能摘下来送给生病的妈妈，她一定会开心吧？可就在他伸手的一瞬间，脚下的树枝猛地断裂，整个人重重地摔了下来。
班主任李军老师和班长王寒冰闻声赶来。班主任李军蹲下身子，声音严厉却带着关切：“你为什么要爬树？这棵树陪了我们多少年，你怎么忍心破坏它？”班长王寒冰赶紧扶起张明往医务室走。路上，张明低着头，一句话也没说，只觉得膝盖火辣辣地疼，可心里更沉。
从医务室回来后，他正想悄悄溜回教室，却被班主任李军叫住，带回了那棵断枝的树下。“你看，花苞都散了一地。”老师指着地上零落的花瓣，“它们也曾努力绽放，就像你们一样。可你这一爬，不仅伤了树，也伤了这片安静的美好。”  
张明盯着那些小小的、还没来得及开放的花苞，忽然觉得它们像被自己弄哭的孩子。风轻轻吹过，几片花瓣飘落在他脚边。那一刻，他第一次觉得，原来调皮也会让人难过。
他默默转身，拿起靠在墙边的扫把，把没扫净的地方重新清扫了一遍。接着，他又走到其他同学的卫生区，弯腰拾起纸屑，动作笨拙却认真。班长愣了一下，嘴角悄悄扬起：“嘿，今天太阳打西边出来了？”
没人说话，但每个人的眼神都在发光。从那天起，张明变了。他不再乱跑乱闹，开始帮同学搬书、捡垃圾，上课也举手发言了。有一次，有人看见他在那棵老丁香树旁放了一张小纸条，上面写着：“对不起，我会好好保护你。”
自那以后，每当春风再吹起丁香花瓣时，总有人指着那棵老树说：“看，那就是张明‘摔’出改变的地方。”花依旧年年盛开，而那个曾经顽皮的身影，也悄悄在花香中长大了。
佛被什么悄悄点亮了。陆天知道，那不是路灯，也不是阳光，而是人心深处那一抹永不熄灭的暖意。
# 我为平凡人点赞 温晨希

成长的道路上，有许多人让我由衷地竖起大拇指。他们没有耀眼的光环，却用一个个温暖的举动，在我心里点亮了一盏盏灯。

那天放学，天空忽然下起了大雨。给我打了个电话，说路上堵车，让我先回家。我只好咬着牙把书包顶在头上，一头扎进雨里。谁知跑得太急，被一块翘起的地砖绊倒了，膝盖火辣辣地疼，我坐在地上，看着腿上的伤口，眼泪不争气地流了下来。

就在我最无助的时候，头顶忽然不再有雨——一把红格子的雨伞悄悄为我撑起了一片晴空。我抬头一看，是邻居王阿姨。她蹲下身，轻声问：“小希，怎么摔成这样？”看到我腿上的伤口，她立刻从包里取出创可贴，小心翼翼地帮我清理、贴上。她的眼神温柔极了，像妈妈一样充满心疼与关心。她扶我站起来，搂着我的肩膀往家走。

一路上，风夹着雨扑来，我却发现那把红格子伞总是悄悄向我这边倾斜。王阿姨的右肩早已被雨水浸透，发丝贴在脸颊上，衣服也湿了一大片。我忍不住说：“阿姨，您别往我这边偏了，我没事的。”她只是笑了笑，一句话也没说，却再一次把伞往我这边轻轻挪了挪。那一刻，一股暖流涌上心头，我在心里默默按下了一个大大的赞——为这位平凡却温暖的邻居。

还有一次，我和爸爸准备去公园玩，半路上看见一位老爷爷提着好几袋东西，走几步就要停下喘口气。爸爸转身就想上前帮忙，我急忙拉住他：“我们不是赶时间吗？”爸爸看着我说：“孩子，助人为乐比什么都重要。”说完，他快步走上前，接过老人手中的袋子，一路陪他送到家门口。

就在那一瞬，一缕朝霞映照在爸爸身上，他的影子被拉得又长又高，仿佛一棵屹立风雨中的大树，稳稳地撑起一片安宁。我望着他的背影，脚步慢了下来，心里那个“赞”字，比上次更加响亮。

原来，值得点赞的人，就在我们身边。他们的善良，藏在一把倾斜的伞里，藏在一个弯腰帮扶的身影里。而我也希望有一天，能成为那个让人想点赞的人。

# 暖 温晨希

那把倾斜的伞，那句轻声的“没关系”，像一缕阳光悄悄照进心里——原来，“暖”不只是一个字，它是一次伸手，一句话语，一种藏在生活角落里的温柔。

那天放学，天空飘起细雨。同学们三三两两撑伞走远了，我站在校门口等爸爸，可电话却传来一句：“爸爸还有点事处理，你自己先回家吧。”我的心一下子沉了下去，委屈涌上眼眶。我只好顶着书包冲进雨里。谁知雨越下越大，仿佛要把我困在这条湿冷的小路上。我没看清路，被台阶绊倒，重重摔在地上。雨水混着泪水往下流，我狼狈极了。

就在这时，一把大伞悄悄遮住了头顶的风雨。一位阿姨蹲下来，轻声问：“小朋友，怎么了？我扶你起来。”她把我拉起，拍拍我身上的泥水，又问清我家地址，执意送我回家。一路上，她一直把伞往我这边倾斜，自己的半边肩膀早已被雨水淋湿。我小声说：“阿姨，您把伞往您那边挪一点吧，您都淋湿了。”她只是笑了笑，没说话，却又悄悄把伞再往我这边靠了靠。那一刻，身体是冷的，可心却被一股暖流紧紧包裹着，仿佛有一簇小小的火苗，在我心里悄悄燃起。原来，陌生人的善意，也能照亮一段寒冷的路。

如果说陌生人的关怀让我初识温暖，那么家人的包容则让我懂得它的恒久。

还有一次，我数学只考了七十三分。走在回家的路上，脚步像绑了石头。我偷偷摸摸进门，想让爸爸签字躲过妈妈的责备。可妈妈还是问起了成绩。我低着头，声音小得像蚊子：“……七十三。”我闭上眼，等着批评。可什么也没发生。过了几秒，妈妈轻轻走过来，摸了摸我的头，温柔地说：“一次没考好，没关系，下次再加油。吃完饭，我们一起看看错题。”她的声音像春风拂过心田，吹散了我心中的阴霾。那一瞬间，我心里被温暖填满了，比冬日晒到的第一缕阳光还要舒服。

原来，暖一直都在。它藏在一把倾斜的伞下，躲在一句温柔的话语里，也住在那些默默守护我们的人眼中。只要用心感受，每个人都能遇见属于自己的那束光。

# 风驰电掣的那一刻 温晨希

清晨的阳光洒满操场，彩旗在微风中轻轻摆动，整个校园像被点亮了一样热闹。我站在跑道边，心跳得比鼓点还快——我们班期待已久的4×100米接力赛终于开始了！

“预备——跑！”发令枪一响，第一棒小温像一支离弦的箭，“嗖”地飞了出去。她的脚步轻快得仿佛踩着风，眨眼间就冲出了人群。别的班也不甘落后，眼看对手渐渐逼近，我们的心一下子提到了嗓子眼。就在关键时刻，小温猛地加速，稳稳地把接力棒交到了小魏手中。

小魏像一匹挣脱缰绳的野马，奋力向前疾驰。可跑着跑着，她的速度慢了下来，呼吸也变得急促。这时，啦啦队齐声喊起来：“加油，小魏！你能行！”她听见了，咬紧牙关，双臂用力摆动，脸上写满了坚持。终于，她顺利把棒递给了第三棒小范。

小范接过棒就冲了出去。汗水顺着她的额头滑下，一滴落进眼睛里。我紧张得屏住呼吸，生怕她会停下揉眼睛。可她只是眨了眨眼，头也不回地继续奔跑，像一阵掠过草地的风。

当小刘第一个冲过终点线，欢呼声如潮水般涌来，我忽然明白：那根小小的接力棒，传递的不只是速度，更是我们彼此的信任与坚持。那一刻，我感受到的不仅是胜利的喜悦，更是一种集体的力量，深深扎根在我心中。

林逸城

当小林冲过终点线的瞬间，掌声雷动，欢呼声如潮水般涌来，我们激动地抱成一团，那一刻，我忽然明白：那根小小的接力棒，不只是速度的传递，更是信任与团结的重量。原来，真正的胜利，从来不是一个人的冲刺，而是一群人共同奔向目标的坚定步伐。

# 我的拿手好戏  温晨希

你见过乒乓球在空中划出优美弧线的样子吗？那不只是球的飞行，更是我热爱与坚持的轨迹。三百六十行，行行出状元，而我在球桌上找到了属于自己的舞台——我的拿手好戏，就是打乒乓球。

一天训练结束后，教练叫住我：“区里要举办乒乓球比赛，你这段时间进步很快，要不要代表学校去试试？”我用力地点了点头，心跳不由加快——这是我第一次参赛啊！

日子一天天过去，比赛的日子终于到了。一进赛场，我的心就像要跳出胸口，手心直冒汗。轮到我上场时，紧张得连发球都失误了好几次。但我深吸一口气，在心里默念：我能行！渐渐地，我找回了节奏，动作变得流畅自如，一路凭借稳定的发挥，成功闯入决赛。

决赛那天，对手格外强劲。刚开局，我凭着一个漂亮的下旋球抢得先机，很快领先三分。观众席上传来阵阵掌声，我甚至觉得自己胜券在握。可就在这时，对方叫了暂停。回来后，她像换了个人，攻势猛烈，连续得分，眨眼间就把比分追成九比九平！

时间仿佛静止了。我站在台前，脑中飞速转动。忽然想起平时训练时观察到的细节：她的反手防守比较薄弱！这时，她发球过来，我立刻抓住机会，果断进攻她的反手位。球“啪”地一声落台，她没接到！我拿下关键一分！

最后一球，她将球擦边发出，我迅速侧身扑救，把球稳稳挑回。她挥拍反击，我立马回防，站定位置，看准来球狠狠一抽——球如离弦之箭飞过球网，她来不及反应，球已落地！

赢了！全场爆发出热烈的欢呼声，哥哥姐姐们激动地冲我挥手大喊：“太棒了！”我握紧球拍，眼眶有些发热。这一刻，我知道，这枚奖牌背后，是无数个清晨与黄昏里的坚持与汗水。

当掌声响起，我站在领奖台前，手中握着的不仅是奖杯，还有无数个清晨与黄昏里挥洒的汗水。

原来，真正的拿手好戏，不是天生就会，而是跌倒后一次次爬起，是在紧张中学会冷静，是在逆境中找到反击的力量。这颗小小的乒乓球，打出了我的成长，也打出了我心中的光。

# 星光下的搀扶 温晨希

在我的记忆深处，有一片闪亮的星海，每一颗星星都藏着一个故事。其中一颗特别明亮，像萤火虫轻轻飞舞，又像朋友温暖的手，让我第一次尝到了关心的味道。 

那是一个阳光明媚的上午，体育课要跑四百米。我一听就心里发慌，腿都有点软了。好朋友站在起跑线上，握紧拳头，跃跃欲试。她跑完后气喘吁吁，还不忘回头对我说：“加油！”轮到我时，我一心想跑出好成绩，起跑就像箭一样冲了出去。可跑着跑着，脚步乱了，竟自己绊倒，“啪”地摔在跑道上。膝盖火辣辣地疼，鲜血慢慢流了出来。看着同学们一个个从身边跑过，我心里又疼又委屈，眼眶也红了。 

就在这时，她跑了过来，蹲下身子轻轻扶我起来：“你没事吧？我送你去医务室。”我刚想说不用，她已经小心地架起我的胳膊，一步一步扶我走。我在里面处理伤口，她在门外焦急地等着，一次次探头张望。等我一出来，她立刻迎上来问：“还疼吗？”我摇摇头，不想让她担心。可她还是小心翼翼地陪我走到树荫下，叮嘱我坐着别动，又跑去跟老师说明情况。 

那一刻，我忽然觉得，友谊不再是看不见的东西，它就在她的目光里，在她的动作里，暖暖的，甜甜的，像春风拂过心田。原来，真正的关心不是说出来的漂亮话，而是摔倒时伸来的那只手，是疼痛中默默陪伴的身影。 

那天阳光正好，而她的身影比阳光更暖。原来关心不是一句口号，而是摔倒时的一次搀扶，是等待时的一次次探头，是小心翼翼的问候与守护。这味道，我记住了，也想把它种进更多人的心里。

# 乐（乐在其中） 温晨希

生活就像一本厚厚的书，每一页都写着不同的滋味。而在我心里，“乐”像一束温暖的光，照亮了许多平凡却闪亮的瞬间。它不只是嘴角上扬的笑容，更是心底涌出的满足与感动。

那是一个周末，我和同学一起去商场玩。我们兴高采烈地在超市买了些小零食，准备回家边吃边写作业。就在我们提着袋子准备离开时，忽然听见一阵哭声。我循声望去，看见一个小妹妹坐在地上，眼泪不停地往下掉。我走过去问道：“小妹妹，你怎么了？”她低着头，抽抽搭搭地说不出话来。我蹲下身子，轻轻递给她一包饼干：“先吃点东西，别哭了。”她接过零食，慢慢止住了哭泣。我小心地把她抱到旁边的椅子上，轻声问：“你是不是找不到妈妈了？”她点点头，眼睛红红的，像只受惊的小兔子。

我一时也不知该怎么办，正着急时，同学提醒我：“我们可以去前台帮忙广播找人！”我立刻点头，和同学一起抱着小妹妹来到服务台。工作人员了解情况后，很快通过广播通知了她的妈妈。

没过多久，一位阿姨匆匆跑来，看到孩子安然无恙，激动地对我们说：“谢谢你们，真是好孩子！”听到这句话，我心里像喝了蜜一样甜，比吃了十份零食还开心。虽然零食送出去了，可那份快乐却留在了心里。

除了助人为乐的喜悦，还有一种快乐，来自自己的坚持与成长。

还有一次，周日下午我写完作业，正觉得无聊，忽然看见楼下几个小朋友骑着自行车在转圈。我眼馋极了，立刻叫爸爸把我的自行车推下来教我骑。

一开始，车歪歪扭扭，全靠爸爸扶着。他一松手，我就“啪”地摔在地上，膝盖擦破了皮，火辣辣地疼，瞬间就不想骑了。爸爸走过来拍拍我说：“别放弃，多试几次就会了。”我咬咬牙，又跨上车。这次我记住爸爸的话：看前方，别乱看。一圈、两圈……我终于能自己骑了！风轻轻吹过耳边，像在为我鼓掌。那种从努力中换来的快乐，踏实又骄傲。

原来，快乐不只是被表扬或夸奖，更是帮助别人、克服困难后的满足。这些小小的“乐”，让我的生活更加温暖而明亮。

# 有你，真好 温晨希

有你，伤心时给我安慰的话语；有你，在我遇到挫折时告诉我永不放弃；有你，在我跌倒时第一时间跑来扶我。小卢，有你，真好。

傍晚六点，天边还留着一抹橘红的晚霞，小区里的孩子陆续回家吃饭，只有你一个人坐在那个小亭子里，在等我。风轻轻吹过树叶，发出沙沙的响声，我刚写完作业，一溜烟跑下楼，心里满是欢喜。我们笑着追逐打闹，阳光斜斜地洒在石板路上，映出两个跳跃的身影。

可就在我奔跑时，脚下一绊，重重摔在地上。膝盖火辣辣地疼，我咬着嘴唇，慢慢拉起裤脚，看到伤口正渗出血迹，眼泪忍不住在眼眶里打转。你立刻跑了过来，蹲下身子，轻声问：“摔疼了吗？”我没说话，只摇了摇头，不想让你担心。你却什么也没说，默默打开书包，掏出一包湿纸巾。

你轻轻托起我的腿，一点一点擦拭伤口周围的泥土和血渍。风一吹，伤口像被针扎一样疼，我不由得缩了缩身子。你好似看出了我的痛，手上的动作变得更轻更慢，像怕惊扰一片露珠般小心翼翼。那一刻，我不再害怕疼，因为我知道，有人比我更在意我的伤。

“忍一下，我帮你擦干净。”你终于开口，声音很轻，却让我心头一暖。你扶我站起来，一步一步陪我往家走。你走得很慢很轻，脚步几乎贴着地面，生怕我走得吃力。我一拐一拐地挪着，但你始终没有松开手。夕阳把我们的影子拉得很长很长，仿佛时间也放慢了脚步。

多年以后，或许我会忘记那天作业写了什么，忘了我们原本约好要玩的游戏，但一定不会忘记你蹲在我身边，轻轻为我擦拭伤口的样子。小卢，谢谢你曾那样细致地守护过我的脆弱。你从不只说“加油”，而是用行动告诉我——跌倒了也能走得更稳。有你，真好——这四个字，不只是感谢，更是我心中最温暖的回音。

# 及时雨 温晨希

干旱时的一场甘霖，寒冷时的一件棉衣，苦闷时的一个拥抱，都是“及时雨”。而在我的记忆里，一位穿红衣服的阿姨，撑着伞向我走来——她，就是我的“及时雨”。

那天放学时，天空还只是飘着细雨。我心想：没带伞，等下和同学一起走吧。可刚出校门，雨点就变得密集起来，噼里啪啦打在地上。我赶紧给爸爸打电话：“爸爸，你来接我一下吧！”爸爸说：“你等等，我马上就到。”我站在屋檐下左等右等，雨却越下越大，最后变成了白茫茫的雨幕。我又打了一次电话，爸爸说路上堵车，让我先回家。我只好把书包抱在头上，冒雨往家跑。

跑着跑着，我没注意脚下，“啪”地一声摔倒在地！膝盖狠狠磕在路边的石子上，书包也甩了出去。我低头一看，腿上被划破了，鲜血汩汩流出。雨水打在伤口上，又疼又冷。那一刻，委屈一下子涌上心头，眼泪不争气地流下来，混着雨水滑过脸颊。

就在这时，一把伞悄悄遮住了我头顶的风雨。我抬头，看见一位穿着红色外套的阿姨蹲下来，轻声问：“小朋友，你怎么了？”她看到我受伤的腿，立刻从包里拿出创口贴，小心翼翼地帮我贴好。她的手很暖，声音更暖。“我送你回家吧？”我点点头。她扶我站起来，我们一起走在雨中。

一路上，我发现她的伞总是往我这边偏。明明我全身都湿透了，可她的右肩却完全暴露在雨里，衣服紧紧贴在身上。我小声说：“阿姨，不用往我这边偏了，我没事的。”她笑了笑，什么也没说，只是又把伞往我这边挪了挪。

很快到了我及楼下，阿姨叮嘱了几句，就转身走进雨中。我望着她的背影，那抹红色在灰蒙蒙的雨幕里，像一朵盛开的花，温暖而明亮。

那场雨早已停了，可那位阿姨的身影，却一直留在我心里。她不是亲人，却在我最狼狈的时候送来温暖。原来，“及时雨”不一定来自熟悉的人，有时只是一个陌生人，为你撑起一片晴空。我也要成为别人的及时雨。

# 一次难忘的跑步体验 温晨希

人生中有许多令人难忘的事，就像夜空中闪烁的星星，数也数不清。但有一次跑步，却让我记忆犹新，成为我心中最深刻的一次体验。

那天的风很轻，操场上的阳光却灼热得刺眼。哨声响起，我像一支离弦的箭冲了出去。第一圈，我脚步轻快，甚至一度遥遥领先。风从耳边掠过，带着一丝清凉，仿佛在为我助威。可刚跑完一圈，体力开始下滑，两个同学接连超过我，我的双腿渐渐变得沉重，像是被灌满了铅，每抬一步都格外吃力。

第二圈刚开始，我就感觉呼吸急促，胸口起伏剧烈。心里冒出一个念头：要不放弃吧，反正也拿不到名次。脚步慢慢慢了下来，几乎想停下。就在这时，熟悉的声音从跑道边传来：“加油！再加把劲，马上就到了！”是同学们在喊。那声音像一股暖流，涌进我疲惫的身体，点燃了快要熄灭的火苗。我咬了咬牙，心想：对，不能放弃，坚持到底才是胜利！

我重新迈开步子，拼尽全力向前奔跑。距离终点越来越近，三十米、二十米、十米……老师的声音清晰传来：“一分钟二十秒，继续！最后三十米！”我盯着前方那条白线，眼神坚定，腿虽发软，却不肯停下。嘴巴大口大口地喘着气，肺部像被火灼烧着，感觉自己再也坚持不下去了。可我不甘心，不甘心跑了这么久却半途而废！

我咬紧牙关，用尽全身力气跨出最后几步——冲过终点线的那一刻，时间仿佛凝固了。阳光洒在脸上，不是简单的暖意，而是一种从心底涌出的骄傲。我的成绩刚好是一分二十八秒，刚好及格，却像赢了一场大战。

那一刻，阳光洒在脸上，温暖而明亮，就像我不服输的信念。

这次难忘的跑步体验让我明白：遇到困难时，只要坚持不退缩，就有可能成功。从那以后，每当我想放弃时，都会对自己说：“别放弃，再坚持一下！”

# 成长的滋味 温晨希

成长的滋味，就像厨房里的调味罐，有酸、有苦、也有辣，而我第一次学做西红柿炒鸡蛋的经历，让我真正尝到了成长的滋味。

那是一个阳光洒满厨房的中午，我看着爷爷在灶台前翻炒菜肴，锅铲叮当响，香味扑鼻，觉得特别有趣。我拉着爸爸的手说：“我也想学！”爸爸笑着点头，决定教我做最简单的菜——西红柿炒鸡蛋。

我兴奋地拿出两个鸡蛋，“咚咚”敲进碗里，搅得均匀蓬松。又把红彤彤的西红柿洗得干干净净，切成小块。一切准备就绪，我深吸一口气，打开火，倒油。油热了，我赶紧把蛋液倒进去。“噼里啪啦！”油花四溅，像小鞭炮在跳舞，我吓得往后一缩，不敢动锅铲。结果鸡蛋边缘焦黑，我的心也沉了下来，像被风吹散的灰烬。

“我不想做了……”我小声嘀咕。爸爸轻轻拍拍我的肩：“别怕，谁一开始不是这样呢？只要坚持，一定能行。”他的话像一缕暖阳照进心里，我咬咬牙，决定再试一次。

这一次，油花再响，我不再退缩。我稳稳拿起锅铲，快速翻动金黄的蛋块，听着那熟悉的声音，仿佛在为我鼓掌。接着倒入西红柿，红黄相融，香气慢慢飘了出来。爸爸问我喜欢汤汁多还是少，我说要多一点，他就让我加了点清水。我耐心地翻炒，直到西红柿软软脱皮，才关火装盘。

我把菜端上桌，全家人尝了一口，纷纷笑着说：“真香！晨希做得太棒了！”那一刻，我的心里像灌了蜜。盘子里的不只是西红柿炒鸡蛋，还有我一步步克服胆怯、坚持到底的勇气。

原来，成长的滋味不只是甜，还有烧糊时的苦、害怕时的酸，但只要不放弃，苦和酸都会变成甜甜的收获。

# 我得到了帮助 温晨希

在我的记忆深处，有一片闪亮的星海，每一颗星星都藏着一个故事。其中一颗特别明亮，像萤火虫轻轻飞舞，又像朋友温暖的手，那一次，我得到了帮助。

那是一个阳光明媚的上午，体育课要跑四百米。我一听就心里发慌，腿都有点软了。好朋友站在起跑线上，握紧拳头，跃跃欲试。她跑完后气喘吁吁，还不忘回头对我说：“加油！”轮到我时，我一心想跑出好成绩，起跑就像箭一样冲了出去。可跑着跑着，脚步乱了，竟自己绊倒，“啪”地摔在跑道上。膝盖火辣辣地疼，鲜血慢慢流了出来。看着同学们一个个从身边跑过，我心里又疼又委屈，眼眶也红了。 

就在这时，她跑了过来，蹲下身子轻轻扶我起来：“你没事吧？我送你去医务室。”我刚想说不用，她已经小心地架起我的胳膊，一步一步扶我走。我在里面处理伤口，她在门外焦急地等着，一次次探头张望。等我一出来，她立刻迎上来问：“还疼吗？”我摇摇头，不想让她担心。可她还是小心翼翼地陪我走到树荫下，叮嘱我坐着别动，又跑去跟老师说明情况。 

那一刻，我忽然觉得，友谊不再是看不见的东西，它就在她的目光里，在她的动作里，暖暖的，甜甜的，像春风拂过心田。原来，真正的关心不是说出来的漂亮话，而是摔倒时伸来的那只手，是疼痛中默默陪伴的身影。 

那天阳光正好，而她的身影比阳光更暖。原来帮助不是一句口号，而是摔倒时的一次搀扶，是等待时的一次次探头，是小心翼翼的问候与守护。这味道，我记住了，也想把它种进更多人的心里。

# 我变成了一只小蚂蚁 温晨希

“咦，我怎么变成了一只蚂蚁？”我低头看着自己细小的身体和六条腿，心里既惊讶又好奇。这是我从未想过的生活，而此刻，我正站在一个完全不同的世界里，开始我的新一天。

我是一只出来寻找食物的蚂蚁，其他的伙伴则留在巢穴里照顾蚁后。我走在公园的小路上，突然，一个巨大的阴影从天而降——是人类的脚！我吓得连忙躲开，差一点就被踩到。我环顾四周，发现眼前的一切都变得巨大无比，连小草都像大树一样高耸入云。

就在这时，我发现前方有一块糖，心想：“这可是好东西！”我准备自己一个人把糖搬回去，但试了一下才发现自己根本搬不动。于是，我叫来了别的伙伴一起搬。大家一起努力，没人偷懒，也没有人抱怨。我一边搬一边想：蚂蚁真的好团结啊，不像人类有时候只出工不出力。就这样，我和蚂蚁大军一起把糖搬回了巢穴，献给了蚁后。蚁后开心地吃了起来，没过多久，她就生下了一群小蚂蚁。所有的蚂蚁都围过来帮忙照顾，我也加入了照顾小蚂蚁的队伍中。

由于蚁后很疲惫，我们便负责照顾新生的小蚂蚁。但我不会照顾它们，于是决定再次出去找食物。找食物的过程并不顺利，因为我太小了，很多人根本看不见我，一不小心就会被踩到，所以我必须躲得够快。还有一些不懂事的小朋友，会用水冲我、用手玩弄我，让我非常害怕。

就在我快要放弃的时候，我看见前方又有一块食物。我顾不上危险，立刻冲了过去。终于，我把食物搬到了安全的地方。可是，一个小朋友走过来，把食物拿走了。那一刻，我感到无比失落。我突然想起以前和朋友一起玩蚂蚁时，也经常用水冲它们、用手指拨弄它们。现在轮到自己被这样对待，我才真正明白蚂蚁有多可怜。

从这次变形的经历中，我深刻体会到了蚂蚁的坚韧与团结。它们虽小，却有着令人敬佩的力量。我想，我们人类也应该学习这种精神，真正地团结一心，互帮互助。

# 美（心中有光，处处是美） 温晨希

“美”在我心中，不只是镜子里的笑容，也不只是花儿盛开的模样。它是雨中一把倾斜的伞，是陌生人一句轻声的问候，是爸爸背影里闪动的善良。原来，真正的美，不在眼睛里，而在心里。 

那天放学，天空突然下起了大雨。父亲迟迟没有出现，我望着手机上挂断的电话，心里有些失落。我没带伞，家也不算太远，只好把书包顶在头上，冲进雨幕。雨水像断了线的珠子砸在地上，溅起一朵朵水花。我一路小跑，脚下忽然一滑，重重摔倒在地。膝盖火辣辣地疼，低头一看，破了皮，还渗着血。我咬着嘴唇，眼眶忍不住泛红。 

就在这时，一把红格子伞悄悄移了过来，像一朵盛开的花，为我遮住了雨。“小希？你怎么一个人在雨里？”是楼下的王阿姨。，她关切地望着我，眼神里满是温柔和心疼。她蹲下身，风把她的头发吹乱，雨打湿了她的衣袖，可她毫不在意。他拍了拍我裤子上的脏东西，把我扶起：“别怕，阿姨送你回家。”她牵起我的手，手心温暖柔软，像冬日里的阳光。她把伞往我这边倾斜，雨水顺着她的肩膀滑落，湿了一大片，她却没在意，只是专注地走在雨里，一步步踏着雨声，送我回家。那一刻，雨还在下，可我的心里却暖烘烘的，我忽然觉得，这雨中的场景，这邻居阿姨的关怀，真美。

还有一次，我和爸爸去公园玩。我正哼着歌，忽然看见一位老爷爷拖着好几个袋子，走几步就得停下来喘口气。爸爸停下脚步，转身就要上前帮忙。我急忙拉住他：“我们不是要快点去玩吗？”爸爸轻轻拍拍我的肩：“别人有困难，我们怎么能装作没看见呢？”

他走向老爷爷，接过沉重的包裹。我站在原地，看着爸爸的背影，那身影仿佛被阳光镀上了一层金边。我慢慢走过去，也接过一个袋子。那一刻，我明白了什么叫做“乐于助人”。如果说邻里的善意让我感受到温暖，那么爸爸的行动则教会我如何去传递这份美。 

原来，美不是弯下腰的温柔，是伸出手的善良。它藏在雨中的伞下，也在爸爸的脚步里。只要我们愿意付出一点点爱，美，就会像种子一样，在人间悄悄发芽。
