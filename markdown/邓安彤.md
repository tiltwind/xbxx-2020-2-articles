# 没想到我如此坚持 邓安彤

在成长的画卷中，总有一些瞬间像星辰般闪耀，照亮我前行的路。没想到我如此坚持。

阳光灼热地洒在跑道上，发令枪一响，我如离弦之箭般冲了出去。前100米，我脚步轻快，稳稳领先，耳边风声呼啸，仿佛胜利就在前方招手。可进入后半程，体力一点点被抽走，双腿像灌了铅，每抬一步都像是踩在泥沼里。呼吸越来越急，胸口像被压了块大石头。一个、两个……对手接连从我身旁掠过，我的心也一点点沉了下去。 

“放弃吧，实在跑不动了。”脑海里突然冒出一个声音。 

可另一个声音立刻响起：“你练了这么久，能就这样停吗？” 

我想起每天放学后独自绕着操场一圈又一圈地练习，想起膝盖酸痛时仍咬牙坚持的身影。不能停！为班级，也为那个不肯认输的自己！

就在这时，我听见熟悉的声音：“加油！你能行！”抬头一看，是我的同学们，他们站在跑道边拼命挥手，眼神里满是期待。那一刻，一股力量从心底涌上来。我咬紧牙关，双臂用力摆动，脚步虽沉，却一步步向前挪进。加油声化作风，推着我向前奔跑。30米——20米——10米！我拼尽全身力气，跨出最后一大步，冲过了终点线！

我一下子瘫坐在地，汗水顺着脸颊滑落，浸湿了衣领，胸口剧烈起伏，可嘴角却扬起了笑。我是第一名！ 

更重要的是，我战胜了那个想要放弃的自己。

当欢呼声响起，我仰面躺在跑道上大口喘气，汗水滴落在胸前。那一刻我明白：胜利从不是冲线时的计时，而是当我双腿发软、心志动摇，依然没有停下脚步。原来在我心里，藏着一个从不轻言放弃的自己。没想到我如此坚持——这份力量，正悄然成为我成长路上最闪亮的星火。

从那以后，每当我遇到困难想放弃时，我总会想起那个在红跑道上咬牙奔跑的自己。那次的坚持告诉我：真正的胜利，不是超越别人，而是在想要放弃的时候，选择坚守，挺过极限，听见内心那个微弱却坚定的声音：再坚持一下。

# 没想到我如此坚持  邓安彤

我的记忆深处，有许多事情像繁星一样闪烁。以前我觉得骑自行车是一件很简单的事，可真正试过之后才发现并不容易，更没想到的是，我竟然能如此坚持。

那是一个阳光炙热的下午，爸爸带我在小区里学骑自行车。我一眼就看见了那辆崭新的小车，在太阳光下闪着亮光，好像在对我招手：“快来骑我吧！”我兴奋地跑过去，一屁股坐上车座，嘴角忍不住往上扬。可刚踩上脚踏板，车身就歪了，我“啪”地摔在地上，膝盖火辣辣地疼，渗出了一点血。我坐在地上，看着擦伤的腿，心里第一次冒出念头：算了吧，不学了。

就在我犹豫的时候，一个声音在心底响起：“就这样放弃？一点小伤就打倒你？”我抬起头，看见爸爸站在不远处，并没有急着扶我，只是轻轻说了一句：“再来一次。”那一刻，我忽然不甘心了。是啊，如果现在放弃了，以后遇到更大的困难，是不是也要转身就跑？不行！我要坚持下去！

我咬咬牙，重新站了起来。第二次尝试，我小心翼翼地一只脚先踏上踏板，另一只脚用力一蹬——可车身还是晃得厉害，没骑出两米远，又摔倒了。第三次、第四次……每一次都差那么一点点。汗水顺着额头滑下，手心湿漉漉的，心跳快得像要跳出胸口。但我不再退缩。在我的不懈努力下，一次、两次……第五次、第十次，我不断重复着同一个动作：扶车、上车、蹬脚、保持平衡。

终于，在无数次尝试时，我稳住了车身。双脚飞快地踩了起来，车轮滚动的声音清脆悦耳。风迎面吹来，轻轻拂过我的脸颊，带着夏日的温度，也带来了自由的气息。路边的小树随风摇曳，好像在为我鼓掌；小花在草丛中点头微笑，仿佛也在为我庆祝。那一刻，我笑了，笑得那么灿烂，那么自豪——我成功了！

原来，骑自行车并不难，真正重要的是那份坚持到底的勇气，是跌倒后还能爬起来的决心。虽然过程中有过疼痛，有过动摇，但我没有停下脚步。没想到，我竟然能如此坚持。

这一次的经历告诉我：人生路上，也许会有许多看似简单的事，却需要我们用坚持去完成。而正是这份坚持，让我比想象中更强大。

那一刻，我瘫坐在地，汗水浸湿了衣裳，嘴角却扬起了笑容。我是第一名！更重要的是，我战胜了想要放弃的自己。

# 诚信让生活更美好 邓安彤

诚信是小学生最基本的行为守则。一次诚信，可能赢得别人的信任；一次坚持，会让人真正认可你。它不像彩虹那样耀眼，却像阳光一样，悄悄温暖着每一天的生活。诚信让生活更美好。

那天清晨，太阳高高挂着，小鸟在枝头叽叽喳喳地唱歌。我哼着小曲走进教室，组长正好发数学试卷。我一眼就看见桌上那张写着“90分”的试卷，鲜红的数字像一朵盛开的小花，我心里乐开了花，嘴角忍不住往上扬。老师开始讲题，我听得格外认真，每一道对勾都让我更开心。

可当老师讲到选择题时，我突然发现其中一题我做错了。偷偷瞄了眼同桌的答案，果然不一样。我的心“咚咚”直跳：要不要告诉老师呢？说了，90分就没了；不说，我又不诚实。我皱着眉头，心里乱成一团。“要不……装作不知道？”可刚这么想，耳边就响起同桌的话：“诚信是小学生最基本的守则，你去跟老师说吧！”这句话像一阵清风，吹散了我心头的乌云。

下课后，我慢慢走上楼，脚步沉得像压了千斤石头。到了办公室门口，我来回踱步，手心直冒汗。“到底进不进去？”犹豫了好一会儿，我终于鼓起勇气推开门，小声说：“老师，您改错了一道选择题，能帮我重新改一下吗？”老师先是一愣，随即笑着点点头，改完还轻轻拍了拍我的肩膀：“你能主动来说明，真了不起。”我不好意思地笑了：“这是应该的。”

走在回教室的路上，阳光洒在肩上，暖暖的。我心里像含着一块融化的蜜糖，又甜又舒服。原来，诚信不仅照亮别人的眼睛，也照亮了自己的心。它让生活变得更踏实，更美好。

# 春日的校园  邓安彤
“叮铃铃——”清脆的上课铃在春日的暖阳中响起，校园里樱花轻舞，丁香花开得正盛，空气中弥漫着淡淡的花香。张明慢悠悠地走在石板小路上，书包歪斜地挂在肩上，脚步拖沓。他刚走到教室门口，班主任李军老师就皱着眉头吼道：“张明！你又迟到了！站到外面去！”张明撇了撇嘴，不情愿地站在门外，心里嘀咕：“又不是我一个人迟到……”门口那株紫丁香随风摇曳，花瓣轻轻颤动，仿佛在笑他：“哈哈，张明，你怎么天天迟到呀？”
下课铃一响，张明板着脸走进教室。阳光透过窗户洒在他脸上，暖洋洋的，忽然，他眼睛一亮，像是想到了什么恶作剧，飞快跑出教室，摘了一大把丁香花。他冲回教室，一边撒花一边喊：“下香雨啦！下香雨啦！”花瓣纷纷扬扬，落在同学们的头上、课本上。上课铃响时，他顺手把剩下的花扔在班长王寒冰的桌上，得意地坐回座位，嘴角还挂着笑。
李老师推门进来，看到满地花瓣，一向温和的脸瞬间沉了下来：“谁干的？”教室里一片寂静。张明的心砰砰直跳，手不自觉地捂住了耳朵，不敢抬头。这时，王寒冰站起来：“老师，我来打扫吧。”她默默拿起扫帚，一点一点清理着花瓣。李老师大步走到张明面前：“是你，对不对？”张明低着头，声音像蚊子哼：“没……没有……”
整节课，他一个字也没听进去，心里像压了块石头。下课后，他偷偷溜出去想再摘些花补过，却慌忙中撞倒了一个一年级的小妹妹。小女孩坐在地上哇哇大哭。王寒冰闻声赶来，轻轻扶起她，拍掉她衣服上的尘土，柔声安慰。阳光正好，洒在她们身上，像镀了一层金边。张明愣住了，看着那一幕，心里突然涌上一阵愧疚。
他顾不上上课，冲过去低头说：“对不起，我不是故意的……”这一幕被刚走来的李老师看在眼里。他微笑着点点头：“张明，能道歉，就是进步。”张明回到座位，心里暖暖的，夕阳的光透过窗户照在他身上，他暗暗发誓：以后再也不淘气了。

# 为诚实与坚持点赞 邓安彤

在成长的道路上，或许是一个人，或许是一件小事，甚至是在某个时刻的自己，都值得我们为之点赞。

阳光洒在上学的路上，我的脚步轻快得像踩在棉花糖上。校园里小鸟叽叽喳喳地唱歌，树叶在风中轻轻摇摆，仿佛也在为我高兴。一进教室，我就看见桌上那张写着“100分”的试卷，心一下子飞了起来——真的是我！我小心翼翼地翻开试卷，每一道红勾都像在对我微笑。

可当老师讲到最后一道大题时，我的心猛地一沉：答案错了！那个鲜红的“√”像一根细针，轻轻扎进了我心里。我攥紧了试卷，手心渐渐沁出了汗。说，还是不说？说了就不再是满分了；不说……可我不是一直想做个诚实的孩子吗？脑海里突然响起那句话：“小学生要诚实守信！”那一刻，我咬了咬牙，心里默默做了决定。

# 甜（甜在心间 ） 邓安彤

甜，不只是糖果的滋味，也不只是妈妈递来的热牛奶。有一种甜，是从心里悄悄冒出来的——像春天的小溪，轻轻流过心田。

记得一次考试，我得了100分，高兴得差点跳起来。可就在老师讲评试卷时，我发现有一道题的答案和她讲的不一样。我的心一下子乱了，像有六只小鹿在胸口乱撞，怎么也安静不下来。我偷偷瞄了一眼同桌的卷子——完了，真是我错了！两分一扣，就只剩98分了。那个梦寐以求的满分，就这样从指尖溜走了吗？

我紧紧皱着眉头，头顶仿佛压着一片乌云，怎么吹都吹不散。不说吧，分数还在；说了，就要和100分说再见。可要是靠错的100分拿表扬，心里不亏吗？诚实才是最珍贵的成绩。”

下课后，我朝办公室走去，脚步却像灌了铅一样沉重。到了门口，我在走廊上来回踱步，手刚碰到门把手又缩了回来，仿佛那冰凉的金属被我的紧张烤得发烫。终于，我深吸一口气，推开了门。“老师，有一道题您改错了，能改回来吗？”老师愣了一下，随即笑了，接过试卷认真核对后，不仅改了分数，还抬起头看着我说：“你真棒！在100分和诚信之间，你选择了诚信！”那一刻，我的心像是被阳光照透了，一股说不出的甜，悄悄从心底冒了出来，一直蔓延到嘴角。

甜不仅来自内心的坚守，也藏在日常的努力里。还有一次，我一进教室就看见桌上静静躺着一张试卷，上面鲜红的“100”格外耀眼。我愣了几秒，才反应过来这是我的成绩！原来，上课时不走神、认真听讲、一笔一画写好每一道题，真的能换来这样的结果。上课时，我满脑子都是那个数字，耳边似乎响起了妈妈温柔的声音：“你真棒！”那种甜，不是炫耀的资本，而是努力开花后的果实，踏实又安心。

原来，“甜”不只是味觉的感受，它更是诚信带来的安心，是努力换来的喜悦。甜，藏在选择诚实的勇气里，也藏在认真学习的坚持中。

# 多彩的运动会 邓安彤

操场上人声鼎沸，呐喊声此起彼伏，像潮水一样涌来。原来，我们六年段正要举行最激动人心的4×100米接力赛！随着主持人一声“运动会正式开始”，整个校园仿佛被点燃了。同学们又兴奋又紧张，生怕自己班落后。

几项比赛过后，重头戏登场。红色跑道在阳光照耀下熠熠生辉，运动员们蓄势待发。小温作为第一棒，起跑时如离弦之箭，瞬间冲出起跑线，迅速领先。观众席上，我们拉拉队高喊加油，小温听后，愈战愈勇，双臂快速摆动，奔跑起来如同一阵风，呼啸着穿梭在赛道上，向着终点冲刺。

转眼就到了第二棒——小艾，她接过接力棒，像一匹脱缰的野马冲了出去。可跑到一半时，她渐渐体力不支，脚步慢了下来。我的心一下子提到了嗓子眼。就在这时，全班齐声大喊：“小艾加油！你是最棒的！”她仿佛被注入了力量，咬紧牙关，重新加速冲了出去！

在同学们的呐喊声中迎来了最激动人心的最后一棒，小刘宛如离弦之箭，于起跑线处爆发出惊人的速度，他弓身前倾，双腿似装了弹簧，强劲有力地交替，每一步都似在跑道上踩出风火轮，激起的尘土还未落下，人已疾驰而出，眨眼间便拉开了与身后选手的距离。

看台上，同学们的情绪被瞬间点燃，有的站起身，双拳紧握，青筋暴起，声嘶力竭地呐喊助威，那呼喊声一浪高过一浪，似要穿透云霄；有的手舞足蹈，脸涨得通红，眼中满是钦佩与激动，恨不得化作一阵风，推着小刘向前。其他选手也不甘示弱，奋力追赶，可在这场速度的较量中，他们只能眼睁睁看着小刘的身影渐行渐远。整个操场，瞬间化作了一片热血沸腾的海洋，为这惊心动魄的速度欢呼着。

当小刘第一个冲过终点时，全班欢呼起来！那一刻我明白了：只要团结一心、坚持到底，就一定能迎来属于我们的荣耀。

# 我的拿手好戏  邓安彤

每个人心里都藏着一个“绝活”，有人能画出五彩斑斓的世界，有人能让琴键跳跃出悦耳旋律。而我最骄傲的本领，不在舞台上，也不在运动场，就在那热气腾腾的厨房里——我的拿手好戏，是做一道看似普通却饱含心意的西红柿炒蛋。

那天家里没人，弟弟饿得直嚷嚷：“姐姐，我肚子好饿，有吃的吗？”我也正饿着呢，可爸爸妈妈还没回来。忽然想起自己的拿手好戏——西红柿炒蛋！我立刻系上小围裙，像个小厨师一样忙碌起来。

先挑两个红彤彤的西红柿，洗净切块备用。再拿出三颗鸡蛋，“咚咚咚”敲进碗里，用筷子快速搅拌，直到蛋清和蛋黄完全融合，变得均匀顺滑。点火，倒油，油热了后发出“噼哩啪啦”的声响，像在为我加油鼓劲。我把蛋液轻轻倒入锅中，瞬间，蛋液在热油中膨胀开来，像一朵朵绽放的金花。我挥动锅铲，让蛋液均匀受热，一边煎一边翻动，直到整片鸡蛋变成诱人的金黄色，再撒上一小撮盐，就像春天的第一场细雨，温柔地落在上面。炒好后盛出，接着把西红柿倒进锅里，翻炒几下，酸甜的香气立刻弥漫开来。等西红柿变软出汁，再把鸡蛋倒回去，一起翻炒均匀，最后撒上翠绿的葱花，一盘色香味俱全的西红柿炒蛋就完成了！

香气很快引来了弟弟，他抽动着鼻子跑过来：“哇！好香啊！姐姐你会做饭啦？”他迫不及待夹了一大口，眼睛顿时亮了起来：“好好吃！比外面餐馆的还香！”我也尝了一口，心里美滋滋的，比吃了蜜还甜。就在这时，妈妈推门进来，闻到香味笑着说：“哟，我们家出了个小厨神！”她尝了一口，连连点头：“真不错，比我第一次做的还好吃呢！”

当妈妈竖起大拇指，当弟弟吃得满嘴油光还嚷着“再来一碗”，我知道，我的拿手好戏——西红柿炒蛋早已不只是食物，它是我在烟火中练就的成长滋味。只要用心去做一件事，哪怕是一道家常小菜，也能成为照亮生活的光。

# 乐（乐在坚持，乐在助人） 邓安彤

“乐”，是付出后的回响，是成长中的光芒。它藏在一次次咬牙坚持里，躲在一次勇敢伸手的瞬间。原来，“乐”可以是汗水里的坚持，也可以是善意里的温暖。正如古人所说：“助人为乐，其乐无穷。”

# 我变成了一只小蚂蚁 邓安彤

“睁开眼，我发现自己正站在一片陌生的世界里。头顶是高耸入云的草丛，身边是一片黑压压的同伴。低头一看，自己竟变成了一只小小的蚂蚁。”

那一刻，我明白了生命的脆弱与珍贵。从那以后，我再也没踩过草地，因为我记得，那片绿意之下，有着无数微小却同样渴望生存的生命。

这个世界上，美有千千万万种。花儿绽放是美，晚霞洒满天空是美，可还有一种美，看不见却能感受到——那是藏在心底的善意，像春风轻轻拂过，温暖又明亮。

那是一个原本晴朗的下午。太阳高高挂着，忽然间，乌云悄悄爬上了天边，一道闪电划破长空，大雨倾盆而下。放学后，我站在校门口的雨棚下，望着密密的雨帘，心里慌极了。爸妈没空来接我，伞也没带。我正想着要不要冲进雨里跑回家，邻居姐姐突然出现了：“小安，你怎么还在这儿？”我低着头，小声说：“我……我没带伞。”她二话不说，撑开伞把我拉进怀里：“我送你回家！”

雨越下越大，小小的伞遮住了我，却遮不住她。过马路时，一辆车飞驰而过，溅起一片水花，姐姐眼疾手快把我往里一拉。等车过去，我发现她的裤脚全湿了。到了楼下，我看了一眼姐姐，她半边衣服都湿透了，而我却一点没淋到。我想把伞往她那边推，她却笑着摇头：“没事！我湿了不重要，你感冒了可怎么办？”一句话像暖流涌进心里，我的眼泪忍不住掉了下来，混进脚边的水洼里。我想劝她快回家，可她一直把我送到楼门口才转身离开。

原来，美不只是好看的东西，更是别人为你撑起的一把伞。

小希跑了过来。她蹲下身子，声音轻轻地说：“别怕，我陪你去医护室。”她一手扶着我，一手小心翼翼地护住我的伤腿。走到半路，她还俯下身，对着伤口轻轻吹了吹：“这样会好一点。”那温热的气息，像春风拂过伤口，也拂过了我的心。一路上，她一直陪在我身边，一句话也没多说，却让我觉得无比安心。

原来，美也可以是一双手，一个微笑，一声轻语。

真正的美从不张扬。它藏在一把倾斜的伞下，藏在一次毫不犹豫的搀扶里。我也想成为这样的人，把这份看不见的美，悄悄传递下去。
